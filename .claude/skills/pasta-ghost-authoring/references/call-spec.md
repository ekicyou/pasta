# Call 仕様リファレンス

> Pasta DSL の Call 文に関する詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## 基本構文

```
＞シーン名                    ← 静的ターゲット（リテラルシーン名）
＞expr                        ← 動的ターゲット（式の評価結果をシーン名として解決）
＞＄変数名                    ← 動的ターゲットの代表例（var_ref）
＞シーン名＆key＝value        ← 属性フィルター付き
```

---

## スコープ解決アルゴリズム

Call 文と単語参照（`＠`）は同一のスコープ解決アルゴリズムを使用する。

### 2段階検索

1. **ローカル検索**: 現在のグローバルシーンスコープ内のローカルシーンを、指定プレフィックスで**前方一致検索**
2. **グローバル検索**: すべてのグローバルシーンを、指定プレフィックスで**前方一致検索**（ローカル専用エントリを除外）
3. **マージ**: 両検索結果を結合して候補リストを生成
4. **選択**: 候補リストからランダムに1つを選択（キャッシュベースの順次消費）

### 前方一致検索

部分名でシーンを検索可能。複数候補がマッチした場合はランダム選択。

```pasta
＊挨拶朝
  Alice：おはよう！
＊挨拶昼
  Alice：こんにちは！
```

- `＞挨拶` → 「挨拶朝」「挨拶昼」の両方が候補
- `＞挨拶朝` → 「挨拶朝」のみが候補

---

## 属性フィルター

```
＞シーン名＆key＝value＆key2＝value2
```

ターゲット選択時に属性で絞り込む。現在は将来予約（無視される）。

Call だけでなく単語参照（`＠`）でも同様に使用可能：
```pasta
＠単語名＆category＝food＆season＝summer
```

---

## 特殊 Call

| 構文 | 動作 |
|------|------|
| `＞ゴースト終了（ミリ秒）` | ゴーストを終了させる |
| `＞チェイントーク` / `＞yield` | シーン出力を分割し、次回 OnTalk トリガーで後半を出力 |

### チェイントーク（継続トーク）

```pasta
＊OnTalk
  女の子：今日はいい天気だね！
  ＞チェイントーク
  女の子：明日も晴れるといいな。
```

- `＞チェイントーク` の前のトークンが1回目の出力
- 次回の OnTalk トリガーで後半が再開
- 複数回使用で3分割以上も可能
- OnTalk 等の繰り返しイベントでの使用を前提（OnBoot 等では後半が発火されない）

## 動的ターゲット

コールターゲットには任意の `expr`（式）を指定できる。式の評価結果が `tostring()` でシーン名に変換され、前方一致検索が適用される。

### 変数参照（代表パターン）

```pasta
＄target＝挨拶
＞＄target
```

変数 `＄target` の値「挨拶」をシーン名として解決し、前方一致検索を適用。

### グローバル変数参照

```pasta
＄＊topic＝天気話
＞＄＊topic
```

### 関数呼び出し・式

```pasta
＞＠get_topic（）
```

関数 `get_topic()` の戻り値をシーン名として解決する。

### nil ガード

式評価結果が `nil`（未定義変数参照等）の場合、シーン検索は行わず警告ログを出力して即時リターンする。
