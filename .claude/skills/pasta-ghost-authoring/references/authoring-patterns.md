## 6.1 アクター辞書定義（actors.pasta）

アクターごとの表情をさくらスクリプトの `\s[ID]` で定義する。

```pasta
＃ アクター辞書定義
％女の子
　＠笑顔：\s[0]
　＠通常：\s[1]
　＠照れ：\s[2]
　＠驚き：\s[3]

％男の子
　＠笑顔：\s[10]
　＠通常：\s[11]
```

## 6.2 イベントハンドラ（boot.pasta）

起動・終了系イベントの最小実例。

```pasta
＠終了挨拶：またね～！、お疲れ様！、ばいばーい！

＊OnBoot
　女の子：＠通常　起動したよ～。
　男の子：＠通常　さあ、始めようか。

＊OnFirstBoot
　女の子：＠笑顔　初めまして！\nわたしは女の子、よろしくね。
　男の子：＠笑顔　ぼくは男の子。ちゃんと使ってよね。

＊OnClose
　女の子：＠通常　＠終了挨拶
　男の子：＠通常　また呼んでよね。
　＞ゴースト終了（３００）
```

## 6.3 ランダムトーク（talk.pasta）

同名シーン `＊OnTalk` を複数定義すると、ランダムに選択される。

```pasta
＠雑談：何か用？、暇だなあ...、ねえねえ

＊OnTalk
　％女の子、男の子
　女の子：＠通常　＠雑談

＊OnTalk
　％女の子、男の子
　女の子：＠笑顔　今日はいい天気だね！
　男の子：＠通常　そうだね。
```

## 6.4 時報（hour.pasta / talk.pasta）

4段階フォールバック: `時報{HH}` → `OnHour{HH}` → `時報その他` → `OnHourOther`

### 自動設定される日時変数

OnHour 発火時に `onhour-date-var-transfer` 機能により、以下の変数がシーンのローカル変数（`＄`）として自動設定される。辞書作成者が代入する必要はなく、アクション行内でそのまま `＄変数名` で参照できる。

**数値型（英語キー）**:

| 変数 | 内容 | 例 |
|------|------|----|
| `＄year` | 年 | `2026` |
| `＄month` | 月（1〜12） | `3` |
| `＄day` | 日（1〜31） | `20` |
| `＄hour` | 時（24h, 0〜23） | `14` |
| `＄min` | 分（0〜59） | `0` |
| `＄sec` | 秒（0〜59） | `0` |
| `＄wday` | 曜日番号（0=日〜6=土） | `5` |
| `＄week` | 曜日（英語） | `Friday` |

**文字列型（日本語キー）**:

| 変数 | 内容 | 例 |
|------|------|----|
| `＄年` | 年（接尾辞付き） | `2026年` |
| `＄月` | 月（接尾辞付き） | `3月` |
| `＄日` | 日（接尾辞付き） | `20日` |
| `＄時` | 時（接尾辞付き） | `14時` |
| `＄分` | 分（接尾辞付き） | `0分` |
| `＄秒` | 秒（接尾辞付き） | `0秒` |
| `＄曜日` | 曜日（日本語） | `金曜日` |
| `＄時１２` | 12時間制（和文） | `午後2時` |

**`＄時１２` の変換ルール**:
- `0` → `深夜0時`
- `1〜11` → `午前N時`
- `12` → `正午`
- `13〜23` → `午後N時`（N = hour − 12）

⚠️ **区切り文字の注意**: 日本語キー変数はXID_CONTINUEルール（§3.2 参照）の影響を受ける。後続テキストとの間に全角空白を入れること。

```pasta
❌ ＄曜日だよ       ← 「曜日だよ」全体が識別子に吸収
✅ ＄曜日　だよ     ← 変数参照「曜日」+ テキスト「だよ」

❌ ＄時１２になった  ← 「時１２になった」が識別子に
✅ ＄時１２　になった ← 変数参照「時１２」+ テキスト「になった」
```

### 時報パターン例

```pasta
＃ 時刻別時報（正午専用）
＊時報12
　％女の子、男の子
　女の子：＠笑顔　お昼だよ！お腹すいた～。
　男の子：＠笑顔　もうお昼か、ご飯にしよう。

＃ 汎用時報（他の時刻別シーンがない場合のフォールバック）
＊時報その他
　％女の子、男の子
　女の子：＠笑顔　＄時１２　だよ！時報だよ～。
　男の子：＠笑顔　もう　＄時１２　か、早いね。
```

### 日時変数を活用した応用例

```pasta
＃ 曜日に言及する時報
＊時報その他
　％女の子、男の子
　女の子：＠通常　＄時１２　だよ。今日は　＄曜日　だね。
　男の子：＠通常　＄月　＄日　＄曜日　…覚えておこう。

＃ 数値変数を条件分岐に使う場合は Lua ブロックで処理
＊時報その他
```lua
function SCENE.late_night(act)
    local save, var = act:init_scene(SCENE)
    local h = tonumber(var.hour)
    if h and h >= 1 and h <= 4 then
        return "こんな時間まで起きてるの？"
    end
    return nil
end
```
　％女の子、男の子
　女の子：＠不安　＠late_night()
```

## 6.6 単語ランダム選択（シャッフル＆順次消費方式）

`＠単語名：値1、値2、値3` で定義し、`＠単語名` で参照すると**シャッフル＆順次消費方式**で1つ選択される。純粋なランダム（毎回独立抽選）ではない。

```pasta
＠雑談：何か用？、暇だなあ...、聞いてる？
＊OnTalk
　女の子：＠通常　＠雑談
```

**選択アルゴリズム**:

1. **初回参照時**: 全候補をシャッフル（並べ替え）し、先頭の1つを返す。残りをキャッシュに保持する
2. **2回目以降**: キャッシュから順番に次の値を返す（再抽選しない）
3. **全候補を使い切ったら**: 再度シャッフルして最初からやり直す

**動作例**（`＠雑談：A、B、C` の場合）:

| 呼び出し | 動作 | 返却値 |
|---------|------|--------|
| 1回目 | シャッフル → `[C, A, B]` をキャッシュ | `C` |
| 2回目 | キャッシュから次を返却 | `A` |
| 3回目 | キャッシュから次を返却（使い切り） | `B` |
| 4回目 | 再シャッフル → `[A, C, B]` をキャッシュ | `A` |
| 5回目 | キャッシュから次を返却 | `C` |
| 6回目 | キャッシュから次を返却（使い切り） | `B` |

**サイクル内保証**: 全候補を一巡するまで同じ値は再選択されない。候補が3つあれば、3回の参照で必ず3つとも1回ずつ使われる。

**サイクル境界の注意**: サイクルをまたぐ瞬間（上記の3回目→4回目）では、前サイクルの最後の値と次サイクルの最初の値が偶然一致する可能性がある。これは仕様上の意図的な非保証であり、候補が2個以上あれば実用上は低確率。

**同名シーンにも同じ方式が適用される**: 複数の `＊OnTalk` を定義した場合も、同一のシャッフル＆順次消費で選択される（§3.1 参照）。

**コード生成時のヒント**: 候補数が少なすぎる（1〜2個）と単調になりやすい。バリエーションを持たせたい単語は3個以上の候補を用意することを推奨する。

<a id="s6-7"></a>
## 6.7 継続トーク（チェイントーク）

1つのシーンの出力を途中で分割し、複数回のOnTalkトリガーに分けて返す機能。`＞チェイントーク` または `＞yield`（エイリアス）を記述するだけで利用できる。GLOBAL テーブルに事前登録された関数のため、ユーザー側の定義は不要。

**基本パターン（2分割）**:

```pasta
＊OnTalk
　女の子：＠通常　今日はいい天気だね！
　＞チェイントーク
　女の子：＠笑顔　明日も晴れるといいな。
```

- `＞チェイントーク` の前に蓄積されたトークンが1回目の出力（中間出力）として返される
- 次回の OnTalk トリガーで後半が再開され、2回目の出力（最終出力）として返される
- 後半出力の完了後は通常の OnTalk 選択に戻る

**応用パターン（3分割以上）**:

`＞チェイントーク` を複数回使用することで、3回以上に分割できる。

```pasta
＊OnTalk
　女の子：＠通常　ねえ、聞いて。
　＞チェイントーク
　女の子：＠笑顔　昨日面白いことがあったの。
　＞チェイントーク
　女の子：＠照れ　…やっぱり恥ずかしいからやめとく。
```

**注意**: 継続トークは OnTalk のような繰り返し発火するイベントでの使用を前提としている。OnBoot 等の一度きりのイベントでは後半が発火されないため、使用しないこと。

<a id="s6-8"></a>
## 6.8 ファイル分割ガイド

| ファイル | 責務 |
|---------|------|
| `actors.pasta` | アクター辞書定義（`％名前` + `＠表情：\s[ID]`）。全ファイルで共有 |
| `boot.pasta` | 起動/終了イベント（OnBoot, OnFirstBoot, OnClose） |
| `talk.pasta` | ランダムトーク（OnTalk）、時報（時報その他 / 時報{HH}） |
| `click.pasta` | マウス反応（OnMouseDoubleClick 等） |

全ファイルは `pasta.toml` の `pasta_patterns = ["dic/*.pasta"]` により自動読み込みされる。アクター辞書は `actors.pasta` に集約し、他ファイルから参照する構成を推奨する。

## 6.9 自然言語→シーン変換指針

**変換ワークフロー**:
1. **テーマ理解**: ユーザーの要求（「天気の雑談」「起動挨拶」等）を理解する
2. **シーン名決定**: イベント起因なら §5 マッピングテーブルを参照。自由トークなら `＊OnTalk`
3. **アクター選定**: `％名前1、名前2` でスコープを指定
4. **アクション行構成**: 1シーン内2〜6行程度。会話の流れを意識する
5. **表情選択**: 会話の感情に合わせて `＠表情名` で参照

**変換例**: 「天気について雑談するトークを作って」

```pasta
＊OnTalk
　％女の子、男の子
　女の子：＠笑顔　今日の天気どう思う？
　男の子：＠通常　＠天気予想
　女の子：＠通常　そっかー。＠天気感想
```

上記で `＠天気予想` `＠天気感想` はプロジェクト内で別途定義する単語。表情名（`＠笑顔` `＠通常` 等）は `actors.pasta` のアクター辞書で定義済みのものを使用する。

## 6.10 複数キー単語定義（マルチキー）

同一の値リストを複数のカテゴリ名で参照したいときに使用する。コロン（`：`）の左側にカンマ区切りで2つ以上のキーを指定するだけ。

**基本パターン（グローバルスコープ）**:

```pasta
＠女性、水の妖精：水無灯里、アリス・キャロル
```

`＠女性` でも `＠水の妖精` でも同じ候補リストから選択される。

**アクター辞書内でのマルチキー**:

```pasta
％さくら
　＠通常、普通：\s[0]
　＠笑顔：\s[1]
```

`さくら：＠通常` でも `さくら：＠普通` でも同じ表情（`\s[0]`）が返る。

**ローカルスコープでのマルチキー**:

```pasta
＊水族館話
　＠水族館、アクア：すみだ水族館、かわさき水族館、大阪海遊館
　女の子：今日は＠水族館　に行きたいな。
　男の子：＠アクア　いいね！
```

**3キー以上も可**:

```pasta
＠人物、女性、水の妖精：水無灯里、アリス・キャロル
```

**誤用に注意**: コロン左側（キーリスト）とコロン右側（値リスト）を混同しないこと。

```pasta
＃ NG例（意図と異なる）
＠女性：水無灯里、アリス　＃ 「女性」という1キーに2つの値を登録しているだけ

＃ OK例（2キー定義）
＠女性、水の妖精：水無灯里　＃ 「女性」と「水の妖精」という2キーに同一の値を登録
```

## 6.11 選択肢メニュー（Choice Menu）

`＠？` マーカーで宣言的に選択肢を定義する。`!select(秒数)` でタイムアウトを設定可能。

```pasta
＊OnMouseDoubleClick
　％女の子、男の子
　女の子：＠通常　何をしますか？
　＠？挨拶「挨拶する」
　＠？自己紹介
　＠？終了「さよなら」
　!select(30)

　・挨拶
　　女の子：＠笑顔　こんにちは！

　・自己紹介
　　女の子：＠通常　私は女の子だよ。よろしくね。

　・終了
　　女の子：＠通常　またね！
```

**動作フロー**:
1. `＠？` 行が `\q[表示テキスト,ターゲット名]` さくらスクリプトに変換
2. SSP がバルーンに選択肢を表示
3. ユーザーが選択すると `OnChoiceSelectEx` イベントが発火
4. 選択IDでローカル→グローバルの順に前方一致検索して自動実行
5. タイムアウト時は SSP のデフォルト動作に従う
