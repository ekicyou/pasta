# 辞書制作パターン集

> Pasta DSL 辞書ファイル（`.pasta`）の作例と、ファイル分割・自然言語からの変換の手順をまとめた手書きファイル。
> 本ファイルは [SKILL.md §6](../SKILL.md) の詳細版。
> 文法・実行時の挙動はここでは定義しない。挙動は各節から参照する生成ファイル（マニュアルから生成）を正とする。

---

<a id="s6-1"></a>
## 6.1 アクター辞書定義（actors.pasta）

アクターごとの表情をさくらスクリプトの `\s[ID]` で定義する作例。構文は [actor-dictionary.md](actor-dictionary.md#グローバルアクター辞書定義) を参照。

```pasta
＃ アクター辞書定義
％女の子
　＠笑顔：\s[0]
　＠通常：\s[1]
　＠照れ：\s[2]
　＠驚き：\s[3]

％男の子
　＠笑顔：\s[10]
　＠通常：\s[11]
```

<a id="s6-2"></a>
## 6.2 イベントハンドラ（boot.pasta）

起動・終了系イベントの最小実例。各イベントが送られる時機は [SHIORI イベントとハンドラ](https://ekicyou.github.io/pasta/lua/shiori-events.html#onboot)、`＞ゴースト終了` は [call-jump.md](call-jump.md#ゴースト終了) を参照。

```pasta
＠終了挨拶：またね～！、お疲れ様！、ばいばーい！

＊OnBoot
　女の子：＠通常　起動したよ～。
　男の子：＠通常　さあ、始めようか。

＊OnFirstBoot
　女の子：＠笑顔　初めまして！\nわたしは女の子、よろしくね。
　男の子：＠笑顔　ぼくは男の子。ちゃんと使ってよね。

＊OnClose
　女の子：＠通常　＠終了挨拶
　男の子：＠通常　また呼んでよね。
　＞ゴースト終了（３００）
```

<a id="s6-3"></a>
## 6.3 ランダムトーク（talk.pasta）

`＊OnTalk` を複数書いてランダムトークの候補を増やす作例。同名シーンの選ばれ方は [call-jump.md](call-jump.md#候補の選択)、OnTalk が発生する時機は [SHIORI イベントとハンドラ](https://ekicyou.github.io/pasta/lua/shiori-events.html#ontalk) を参照。

```pasta
＠雑談：何か用？、暇だなあ...、ねえねえ

＊OnTalk
　％女の子、男の子
　女の子：＠通常　＠雑談

＊OnTalk
　％女の子、男の子
　女の子：＠笑顔　今日はいい天気だね！
　男の子：＠通常　そうだね。
```

<a id="s6-4"></a>
## 6.4 時報（hour.pasta / talk.pasta）

時報シーンと日時変数の作例。挙動は次の生成ファイル・マニュアル章を参照する。

- 時報シーンの名前と探される順序: [SHIORI イベントとハンドラ](https://ekicyou.github.io/pasta/lua/shiori-events.html#onhour)
- 時報シーンで使える日時変数（`＄時１２`・`＄曜日`・`＄hour` など）の一覧と値: [variables.md](variables.md#日時変数)
- 変数参照の直後に空白を置く理由: [variables.md](variables.md#変数参照の空白ルール)

### 時報パターン例

```pasta
＃ 時刻別時報（正午専用）
＊時報12
　％女の子、男の子
　女の子：＠笑顔　お昼だよ！お腹すいた～。
　男の子：＠笑顔　もうお昼か、ご飯にしよう。

＃ 汎用時報
＊時報その他
　％女の子、男の子
　女の子：＠笑顔　＄時１２　だよ！時報だよ～。
　男の子：＠笑顔　もう　＄時１２　か、早いね。
```

### 日時変数を活用した応用例

```pasta
＃ 曜日に言及する時報
＊時報その他
　％女の子、男の子
　女の子：＠通常　＄時１２　だよ。今日は　＄曜日　だね。
　男の子：＠通常　＄月　＄日　＄曜日　…覚えておこう。
```

数値の日時変数で条件分岐するときは、Lua ブロックに関数を書き、その戻り値を変数に入れてから台詞で使う。Lua ブロックを置ける位置は [block-structure.md](block-structure.md#lua-ブロックの配置)、関数の呼び出しは [variables.md](variables.md#関数スコープの展開先) を参照。

````pasta
＊時報その他
　％女の子、男の子
```lua
function SCENE.late_night(act)
    local save, var = act:init_scene(SCENE)
    local h = tonumber(var.hour)
    if h and h >= 1 and h <= 4 then
        return "こんな時間まで起きてるの？"
    end
    return "時報だよ。"
end
```
　＄ひとこと＝＠late_night（）
　女の子：＠驚き　＄ひとこと
````

<a id="s6-6"></a>
## 6.6 単語ランダム選択（シャッフル＆順次消費方式）

単語に候補を並べてトークに変化をつける作例。候補の選ばれ方は [words.md](words.md#シャッフル順次消費) を参照。

```pasta
＠雑談：何か用？、暇だなあ...、聞いてる？
＊OnTalk
　女の子：＠通常　＠雑談
```

**コード生成時のヒント**: 候補数が少なすぎる（1〜2個）と単調になりやすい。バリエーションを持たせたい単語は3個以上の候補を用意することを推奨する。

<a id="s6-7"></a>
## 6.7 継続トーク（チェイントーク）

1 つの話を数回のランダムトークに分けて出す作例。`＞チェイントーク`（`＞yield`）の挙動は [call-jump.md](call-jump.md#チェイントーク) を参照。

**基本パターン（2分割）**:

```pasta
＊OnTalk
　女の子：＠通常　今日はいい天気だね！
　＞チェイントーク
　女の子：＠笑顔　明日も晴れるといいな。
```

**応用パターン（3分割以上）**:

```pasta
＊OnTalk
　女の子：＠通常　ねえ、聞いて。
　＞チェイントーク
　女の子：＠笑顔　昨日面白いことがあったの。
　＞チェイントーク
　女の子：＠照れ　…やっぱり恥ずかしいからやめとく。
```

<a id="s6-8"></a>
## 6.8 ファイル分割ガイド

| ファイル | 責務 |
|---------|------|
| `actors.pasta` | アクター辞書定義（`％名前` + `＠表情：\s[ID]`）。全ファイルで共有 |
| `boot.pasta` | 起動/終了イベント（OnBoot, OnFirstBoot, OnClose） |
| `talk.pasta` | ランダムトーク（OnTalk）、時報（時報その他 / 時報{HH}） |
| `click.pasta` | マウス反応（OnMouseDoubleClick 等） |

アクター辞書は `actors.pasta` に集約し、他ファイルから参照する構成を推奨する。どのファイルが読み込まれるかは [pasta-toml.md](pasta-toml.md#pasta_patterns) を参照。

<a id="s6-9"></a>
## 6.9 自然言語→シーン変換指針

**変換ワークフロー**:
1. **テーマ理解**: ユーザーの要求（「天気の雑談」「起動挨拶」等）を理解する
2. **シーン名決定**: イベント起因なら [SKILL.md](../SKILL.md) §5 のマッピングテーブルを参照。自由トークなら `＊OnTalk`
3. **アクター選定**: `％名前1、名前2` でスコープを指定
4. **アクション行構成**: 1シーン内2〜6行程度。会話の流れを意識する
5. **表情選択**: 会話の感情に合わせて `＠表情名` で参照

**変換例**: 「天気について雑談するトークを作って」

```pasta
＊OnTalk
　％女の子、男の子
　女の子：＠笑顔　今日の天気どう思う？
　男の子：＠通常　＠天気予想
　女の子：＠通常　そっかー。＠天気感想
```

上記で `＠天気予想` `＠天気感想` はプロジェクト内で別途定義する単語。表情名（`＠笑顔` `＠通常` 等）は `actors.pasta` のアクター辞書で定義済みのものを使用する。

<a id="s6-10"></a>
## 6.10 複数キー単語定義（マルチキー）

同じ値リストを複数の名前で参照したいときの作例。構文と参照のされ方は [words.md](words.md#複数キー単語定義)、アクター辞書での書き方は [actor-dictionary.md](actor-dictionary.md#グローバルアクター辞書定義) を参照。

**基本パターン（グローバルスコープ）**:

```pasta
＠女性、水の妖精：水無灯里、アリス・キャロル
```

**アクター辞書内でのマルチキー**:

```pasta
％さくら
　＠通常、普通：\s[0]
　＠笑顔：\s[1]
```

**ローカルスコープでのマルチキー**:

```pasta
＊水族館話
　＠水族館、アクア：すみだ水族館、かわさき水族館、大阪海遊館
　女の子：今日は＠水族館　に行きたいな。
　男の子：＠アクア　いいね！
```

**3キー以上の例**:

```pasta
＠人物、女性、水の妖精：水無灯里、アリス・キャロル
```

**誤用に注意**: コロン左側（キーリスト）とコロン右側（値リスト）を混同しないこと。

```pasta
＃ NG例（意図と異なる）: 「女性」という1キーに2つの値を登録しているだけ
＠女性：水無灯里、アリス

＃ OK例（2キー定義）: 「女性」と「水の妖精」という2キーに同一の値を登録
＠女性、水の妖精：水無灯里
```

<a id="s6-11"></a>
## 6.11 選択肢メニュー（Choice Menu）

選択肢を出して、選ばれた項目のローカルシーンへ進む作例。構文は [block-structure.md](block-structure.md#選択肢行)、`!select(秒数)` は [block-structure.md](block-structure.md#キューコマンド行)、選択後に実行されるシーンの決まり方は [SHIORI イベントとハンドラ](https://ekicyou.github.io/pasta/lua/shiori-events.html#onchoiceselectex) を参照。

```pasta
＊OnMouseDoubleClick
　％女の子、男の子
　女の子：＠通常　何をしますか？
　＠？挨拶「挨拶する」
　＠？自己紹介
　＠？終了「さよなら」
　!select(30)

　・挨拶
　　女の子：＠笑顔　こんにちは！

　・自己紹介
　　女の子：＠通常　私は女の子だよ。よろしくね。

　・終了
　　女の子：＠通常　またね！
```
