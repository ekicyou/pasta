# さくらスクリプトリファレンス

> Pasta DSL におけるさくらスクリプト（Sakura Script）の詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## 透過ルール

Pasta はさくらスクリプトのコマンドの種類や意味を**解釈しない**。`\` から始まるコマンドを検出し、そのまま透過して出力する。未知のタグも受理される。

---

## エスケープ文字

**半角バックスラッシュ `\` のみ有効**。全角では機能しない。

---

## タグ一覧

### よく使用するタグ

| タグ | 用途 | 例 |
|------|------|-----|
| `\s[ID]` | 表情変更 | `\s[0]`（サーフェスID指定） |
| `\n` | 改行 | 行内で改行を挿入 |
| `\w数字` | ウェイト（数字×50ms） | `\w8`（400ms待機） |
| `\_w[数字]` | ウェイト（ミリ秒指定） | `\_w[1000]`（1000ms待機） |

### その他のタグ（透過対応）

Pasta は以下を含むすべてのさくらスクリプトタグをそのまま透過する：

| タグ | 用途 |
|------|------|
| `\![...]` | イベント発火・特殊コマンド |
| `\_s` | 同時トーク制御 |
| `\p[N]` | スコープ（バルーン）切り替え |
| `\b[ID]` | バルーン変更 |

---

## 字句構造

```
sakura_command   ::= "\" ~ sakura_token ~ bracket_content?
sakura_token     ::= [!\-+*?&_a-zA-Z0-9]+
bracket_content  ::= "[" ~ bracket_chars ~ "]"
bracket_chars    ::= ( "\\]" | [^\]] )*
```

- `sakura_token`: ASCII英数字 + `_!-+*?&` の連続。先頭が数字でもよい
- 角括弧: 非ネスト前提。最初の非エスケープ `]` で閉じる
- 角括弧内は Pasta が構文解析しない（透過）

---

## 配置ルール

- アクション行のインライン要素としてのみ使用可能
- 変数宣言行や単語定義行では使用不可

```pasta
Alice：＠笑顔　こんにちは\w8。\n返事してください。
Bob：\![happy]了解しました。
```

---

## 複雑なさくらスクリプトの記述

複雑な構文（入れ子、高度なエスケープ等）が必要な場合は、Lua 関数で文字列を生成してアクション行に挿入する：

```pasta
＊複雑な例
```lua
function SCENE.emit_complex(act)
    local save, var = act:init_scene(SCENE)
    return "\\![embed,OnTalk]"
end
```
  Alice：＠emit_complex()
```
