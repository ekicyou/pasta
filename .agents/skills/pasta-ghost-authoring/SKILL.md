# Pasta Ghost Authoring Skill

## §1 Purpose & Prerequisites

**目的**: 自然言語の指示（「こんなトークを作って」等）からPasta DSLコードを正確に生成するサポートを提供する。

**対象**: ゴースト（「伺か」デスクトップマスコット）の辞書ファイル（`.pasta`）の作成・編集。

**前提条件**: ゴーストプロジェクトが既に存在すること（`pasta.toml`、`descript.txt`、`dic/` ディレクトリが揃っている）。

**役割分離**: 本スキルはLLMによるコード生成に特化する。Pasta DSL言語仕様の設計判断やパーサー実装には関与しない。本スキルは自己完結型であり、必要な情報をすべて内包している。

## §2 Quick Reference（マーカー一覧表）

全マーカーは全角・半角の両方を許容する。コード例では全角を使用する。

| マーカー名 | 全角 | 半角 | 用途 | 使用例 |
|-----------|------|------|------|--------|
| グローバルシーン | `＊` | `*` | シーン定義 | `＊OnBoot` |
| ローカルシーン | `・` | `-` | サブシーン定義 | `・選択肢1` |
| 単語/関数 | `＠` | `@` | 単語定義・参照・関数呼び出し | `＠挨拶：こんにちは、やあ` |
| 変数 | `＄` | `$` | 変数宣言・参照 | `＄count＝1` |
| Call | `＞` | `>` | シーン呼び出し | `＞次の会話` |
| 属性 | `＆` | `&` | メタデータ | `＆author：Alice` |
| コメント | `＃` | `#` | コメント行 | `＃ メモ` |
| アクター辞書 | `％` | `%` | アクター辞書定義 | `％さくら` |
| キューコマンド | `！` | `!` | 演出キュー | `！emote(smile)` |
| コロン | `：` | `:` | キー・値の区切り | `Alice：こんにちは` |

## §3 DSL Syntax（構文ルール）

### 3.1 Scenes（シーン定義）

- **グローバルシーン** `＊シーン名`: ファイル全体からアクセス可能。インデントなしで記述
- **ローカルシーン** `・シーン名`: 親グローバルシーン内でのみアクセス可能。インデントありで記述
- **重複シーン**: 同名のグローバルシーンを複数定義すると、実行時にランダム選択される
- **前方一致検索**: `＞挨拶` で「挨拶朝」「挨拶昼」の両方が候補になる

```pasta
＊OnTalk
  女の子：こんにちは！
＊OnTalk
  女の子：やっほー！
```

### 3.2 Action Lines（アクション行）

- 構文: `アクター名：発話内容`（インデントあり）
- アクター名を省略すると、直前のアクターが継続する
- インライン要素として `＠単語参照`、`＄変数参照`、さくらスクリプト（`\s[0]`等）を埋め込み可能
- 行継続: インデント付きの次行で発話を継続できる（マーカーで始まる行は継続しない）

```pasta
＊会話
  Alice：こんにちは、＠weather　ですね。\w8
  Bob：＄player_name　さん、元気？
```

### 3.3 Words（単語定義）

- 構文: `＠単語名：値1、値2、値3`（区切りは `、` `，` `,` のいずれか）
- **グローバル単語**: インデントなしで定義。ファイル全体から参照可能
- **ローカル単語**: インデントありで定義。親シーン内でのみ参照可能
- 参照時 `＠単語名` で値リストからランダムに1つ選択される
- スコープ解決: ローカル → グローバルの順に前方一致検索

```pasta
＠挨拶：こんにちは、おはよう、やあ
＊会話
  ＠天気：晴れ、雨、曇り
  Alice：＠挨拶　今日は＠天気　だね。
```

### 3.4 Variables（変数）

- **ローカル変数** `＄変数名`: 一連のシーンが終わるまで有効
- **グローバル変数** `＄＊変数名`: 永続的に有効
- 代入: `＄変数名＝値` または `＄変数名：値`（リテラル値・単語参照・変数参照・式・関数呼び出しが使用可能）
- 参照: アクション行内で `＄変数名` と記述

```pasta
＊会話
  ＄count＝1
  ＄＊total＝＄＊total ＋ 1
  Alice：＄count　回目の会話だよ。
```

### 3.5 Call Statements（Call文）

- 構文: `＞シーン名` — 指定シーンを呼び出し、実行後に復帰
- 動的ターゲット: `＞＄変数名` — 変数値をシーン名として解決
- 前方一致で候補が複数ある場合はランダム選択
- 特殊Call: `＞ゴースト終了（ミリ秒）` — ゴーストを終了させる
- 特殊Call: `＞チェイントーク` / `＞yield` — シーン出力を分割し、次回 OnTalk トリガーで後半を出力する（§6.7 参照）

```pasta
＊OnClose
  女の子：またね！
  ＞ゴースト終了（３００）
```

### 3.6 Actor Dictionary（アクター辞書）

- **定義**: `％アクター名` でアクター固有の単語辞書を定義する（インデントなし）
- 配下にインデント付きで `＠単語名：値` を記述し、表情等をアクター単位で管理する
- **スコープ指定**: シーン内で `％名前1、名前2` と記述すると、そのシーンでバルーン連動が有効になる
  - SHIORIゴーストでは通常 OnBoot で一度設定して固定する
  - ノベルゲーム用途等ではシーンごとに切り替えることも可能
- 会話行で `アクター名：＠表情名` と記述すると、そのアクターの辞書から優先的に検索される
- アクター辞書に該当単語がない場合、グローバル/ローカル単語辞書にフォールバック

```pasta
％さくら
  ＠通常：\s[0]
  ＠笑顔：\s[1]

＊OnBoot
  ％さくら、うにゅう
  さくら：＠笑顔　おはよう！
```

### 3.7 Sakura Script（さくらスクリプト）

アクション行内にインラインで埋め込む `\` から始まるコマンド。Pasta は内容を解釈せずそのまま透過する。

| タグ | 用途 | 例 |
|------|------|-----|
| `\s[ID]` | 表情変更 | `\s[0]` |
| `\n` | 改行 | 行内改行 |
| `\w数字` | ウェイト（数字×50ms） | `\w8` |
| `\_w[数字]` | ウェイト（ミリ秒指定） | `\_w[1000]` |

さくらスクリプトは必ず半角で記述する（エスケープ文字 `\` は半角バックスラッシュのみ）。

### 3.8 Lua Code Blocks（Luaブロック）

高度なロジックが必要な場合のエスケープハッチ。辞書制作では Pasta DSL 構文のみで十分なケースが大半。

- グローバルシーン直下に ` ```lua ` 〜 ` ``` ` で囲んで記述（インデント不要）
- **関数定義のみ許可**（変数宣言やステートメントは不可）
- 定義した関数はアクション行内で `＠関数名()` として呼び出せる

````pasta
＊計算
```lua
function SCENE.calculate(act)
    local save, var = act:init_scene(SCENE)
    return 10 + 20
end
```
  Alice：結果は＠calculate()　です。
````

### 3.9 Comments & Attributes（コメント・属性）

- **コメント**: `＃` または `#` で始まる行。処理されない。インデントあり・なし両方可
- **属性**: `＆key：value` 形式。シーン定義の直後にのみ配置可能（メタデータ付与）
- 属性はアクション行や変数代入行の後には配置できない

```pasta
＃ これはコメント
＊会話
  ＆author：Alice
  ＆genre：comedy
  Alice：こんにちは！
```

## §4 Project Structure（プロジェクト構造）

### ファイル構成

| ファイル | 役割 |
|---------|------|
| `dic/*.pasta` | 辞書ファイル（トーク・イベントハンドラ等を記述） |
| `pasta.toml` | ゴースト設定ファイル |
| `descript.txt` | ゴーストメタデータ |

### pasta.toml（コード生成に影響する設定）

```toml
[loader]
pasta_patterns = ["dic/*.pasta"]  # dic/ 配下の .pasta を自動読み込み

[ghost]
talk_interval_min = 180  # ランダムトーク最小間隔（秒）
talk_interval_max = 300  # ランダムトーク最大間隔（秒）

[actor."女の子"]
spot = 0  # sakura側（メイン）バルーン

[actor."男の子"]
spot = 1  # kero側（サブ）バルーン
```

- `[actor."名前"]` の `spot` はバルーン割り当て（0=sakura側, 1=kero側）
- `pasta_patterns` により `dic/` 配下の全 `.pasta` ファイルが自動的に読み込まれる
- アクター名は `descript.txt` の `sakura.name` / `kero.name` と一致させる

### descript.txt（必須フィールド）

| フィールド | 説明 | 例 |
|-----------|------|-----|
| `charset` | 文字エンコーディング | `UTF-8` |
| `type` | リソース種別 | `ghost` |
| `name` | ゴースト名 | `hello-pasta` |
| `sakura.name` | メインキャラ名 | `女の子` |
| `kero.name` | サブキャラ名 | `男の子` |
| `shiori` | SHIORIモジュール | `pasta.dll` |

## §5 Event Mapping（SHIORIイベントマッピング）

**核心ルール**: `＊イベント名` のグローバルシーンを定義するだけで、対応するイベント発生時に自動実行される（シーン関数フォールバック）。

| やりたいこと | シーン名 | 備考 |
|-------------|---------|------|
| 起動時の挨拶 | `＊OnBoot` | 通常起動 |
| 初回起動の挨拶 | `＊OnFirstBoot` | 初回のみ |
| 終了時の挨拶 | `＊OnClose` | 末尾に `＞ゴースト終了（ミリ秒）` を付ける |
| ランダムトーク | `＊OnTalk` | 仮想イベント。同名複数定義でランダム選択。継続トーク（§6.7）対応 |
| 時報 | `＊OnHour` | 仮想イベント。`＄時１２` が自動設定される |
| ダブルクリック反応 | `＊OnMouseDoubleClick` | 同名複数定義でランダム選択 |

**仮想イベント**: OnTalk と OnHour は内部タイマーにより自動ディスパッチされる。ゴースト作者は `＊OnTalk` / `＊OnHour` シーンを定義するだけでよい。トーク間隔は `pasta.toml` の `[ghost]` セクションで設定可能。

## §6 Authoring Patterns（辞書制作パターン集）

### 6.1 アクター辞書定義（actors.pasta）

アクターごとの表情をさくらスクリプトの `\s[ID]` で定義する。

```pasta
＃ アクター辞書定義
％女の子
　＠笑顔：\s[0]
　＠通常：\s[1]
　＠照れ：\s[2]
　＠驚き：\s[3]

％男の子
　＠笑顔：\s[10]
　＠通常：\s[11]
```

### 6.2 イベントハンドラ（boot.pasta）

起動・終了系イベントの最小実例。

```pasta
＠終了挨拶：またね～！、お疲れ様！、ばいばーい！

＊OnBoot
　女の子：＠通常　起動したよ～。
　男の子：＠通常　さあ、始めようか。

＊OnFirstBoot
　女の子：＠笑顔　初めまして！\nわたしは女の子、よろしくね。
　男の子：＠笑顔　ぼくは男の子。ちゃんと使ってよね。

＊OnClose
　女の子：＠通常　＠終了挨拶
　男の子：＠通常　また呼んでよね。
　＞ゴースト終了（３００）
```

### 6.3 ランダムトーク（talk.pasta）

同名シーン `＊OnTalk` を複数定義すると、ランダムに選択される。

```pasta
＠雑談：何か用？、暇だなあ...、ねえねえ

＊OnTalk
　％女の子、男の子
　女の子：＠通常　＠雑談

＊OnTalk
　％女の子、男の子
　女の子：＠笑顔　今日はいい天気だね！
　男の子：＠通常　そうだね。
```

### 6.4 時報（talk.pasta 内）

`＄時１２` 変数は自動設定される（12時間表記）。

```pasta
＊OnHour
　％女の子、男の子
　女の子：＠笑顔　＄時１２　だよ！時報だよ～。
　男の子：＠笑顔　もう　＄時１２　か、早いね。
```

### 6.5 クリック反応（click.pasta）

```pasta
＊OnMouseDoubleClick
　％女の子、男の子
　女の子：＠驚き　わっ、びっくりした！
　男の子：＠笑顔　どうしたの？
```

### 6.6 単語ランダム選択

`＠単語名：値1、値2、値3` で定義し、`＠単語名` で参照するとランダムに1つ選択される。

```pasta
＠雑談：何か用？、暇だなあ...、聞いてる？
＊OnTalk
　女の子：＠通常　＠雑談
```

### 6.7 継続トーク（チェイントーク）

1つのシーンの出力を途中で分割し、複数回のOnTalkトリガーに分けて返す機能。`＞チェイントーク` または `＞yield`（エイリアス）を記述するだけで利用できる。GLOBAL テーブルに事前登録された関数のため、ユーザー側の定義は不要。

**基本パターン（2分割）**:

```pasta
＊OnTalk
　女の子：＠通常　今日はいい天気だね！
　＞チェイントーク
　女の子：＠笑顔　明日も晴れるといいな。
```

- `＞チェイントーク` の前に蓄積されたトークンが1回目の出力（中間出力）として返される
- 次回の OnTalk トリガーで後半が再開され、2回目の出力（最終出力）として返される
- 後半出力の完了後は通常の OnTalk 選択に戻る

**応用パターン（3分割以上）**:

`＞チェイントーク` を複数回使用することで、3回以上に分割できる。

```pasta
＊OnTalk
　女の子：＠通常　ねえ、聞いて。
　＞チェイントーク
　女の子：＠笑顔　昨日面白いことがあったの。
　＞チェイントーク
　女の子：＠照れ　…やっぱり恥ずかしいからやめとく。
```

**注意**: 継続トークは OnTalk のような繰り返し発火するイベントでの使用を前提としている。OnBoot 等の一度きりのイベントでは後半が発火されないため、使用しないこと。

### 6.8 ファイル分割ガイド

| ファイル | 責務 |
|---------|------|
| `actors.pasta` | アクター辞書定義（`％名前` + `＠表情：\s[ID]`）。全ファイルで共有 |
| `boot.pasta` | 起動/終了イベント（OnBoot, OnFirstBoot, OnClose） |
| `talk.pasta` | ランダムトーク（OnTalk）、時報（OnHour） |
| `click.pasta` | マウス反応（OnMouseDoubleClick 等） |

全ファイルは `pasta.toml` の `pasta_patterns = ["dic/*.pasta"]` により自動読み込みされる。アクター辞書は `actors.pasta` に集約し、他ファイルから参照する構成を推奨する。

### 6.9 自然言語→シーン変換指針

**変換ワークフロー**:
1. **テーマ理解**: ユーザーの要求（「天気の雑談」「起動挨拶」等）を理解する
2. **シーン名決定**: イベント起因なら §5 マッピングテーブルを参照。自由トークなら `＊OnTalk`
3. **アクター選定**: `％名前1、名前2` でスコープを指定
4. **アクション行構成**: 1シーン内2〜6行程度。会話の流れを意識する
5. **表情選択**: 会話の感情に合わせて `＠表情名` で参照

**変換例**: 「天気について雑談するトークを作って」

```pasta
＊OnTalk
　％女の子、男の子
　女の子：＠笑顔　今日の天気どう思う？
　男の子：＠通常　＠天気予想
　女の子：＠通常　そっかー。＠天気感想
```

上記で `＠天気予想` `＠天気感想` はプロジェクト内で別途定義する単語。表情名（`＠笑顔` `＠通常` 等）は `actors.pasta` のアクター辞書で定義済みのものを使用する。
