# アクター辞書リファレンス

> Pasta DSL のアクター辞書（Actor Dictionary）に関する詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## アクター辞書定義

```
％アクター名
  ＠単語名：値1、値2、...
```

- ファイルレベル（インデントなし）で `％アクター名` を記述
- 配下にインデント付きで `＠単語名：値` を記述
- アクター名には日本語・英語の識別子が使用可能
- 値区切りは `、` / `，` / `,` のいずれも可

### 定義例

```pasta
＃アクター辞書
％ぱすた
  ＠通常　　　：\s[0]、\s[100]
  ＠照れ　　　：\s[1]
  ＠驚き　　　：\s[2]
  ＠ぐんにょり：\s[3]
  ＠怒り　　　：\s[4]

％ラザニア
  ＠通常：\s[10]
  ＠刮目：\s[11]
```

---

## シーン内でのスコープ指定

グローバルシーン内で `％名前1、名前2` と記述すると、そのシーンでバルーン連動が有効になる。

```pasta
＊OnBoot
  ％ぱすた、ラザニア
  ぱすた：＠通常　こんにちは！
  ラザニア：＠刮目　目を見開くラザニア
```

**用途**:
- SHIORIゴースト: 通常 OnBoot で一度設定して固定する
- ノベルゲーム用途等: シーンごとに切り替えることも可能

---

## フォールバック検索順

`actor_name：＠word_name` でアクター付き単語参照する場合：

1. **アクター辞書**: `％actor_name` で定義された単語辞書から `word_name` を検索
2. **ローカル単語辞書**: 現在のシーンスコープ内のローカル単語から検索
3. **グローバル単語辞書**: すべてのグローバル単語から検索

アクター辞書の単語参照もグローバル・ローカル単語定義と同じ**前方一致検索**ルールに従う。

---

## バルーン連動

アクター辞書は `pasta.toml` の `[actor."名前"]` 設定と連動してバルーン（表示先）を制御する。

```toml
[actor."ぱすた"]
spot = 0  # sakura側（メイン）バルーン

[actor."ラザニア"]
spot = 1  # kero側（サブ）バルーン
```

- `spot = 0`: sakura 側（メインキャラ）のバルーンに出力
- `spot = 1`: kero 側（サブキャラ）のバルーンに出力
- アクター名は `descript.txt` の `sakura.name` / `kero.name` と一致させる

---

## 完全なコード例

```pasta
＃ アクター辞書定義
％女の子
  ＠笑顔：\s[0]
  ＠通常：\s[1]
  ＠照れ：\s[2]

％男の子
  ＠笑顔：\s[10]
  ＠通常：\s[11]

＃ シーンでの使用
＊OnBoot
  ％女の子、男の子
  女の子：＠笑顔　おはよう！
  男の子：＠通常　さあ、始めようか。

＊OnTalk
  ％女の子、男の子
  女の子：＠通常　今日はいい天気だね。
  男の子：＠笑顔　そうだね。
```
