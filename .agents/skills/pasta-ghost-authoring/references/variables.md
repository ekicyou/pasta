# 変数リファレンス

> Pasta DSL の変数（Variables）に関する詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## 変数スコープ

| 種類 | 構文 | 有効期間 |
|------|------|---------|
| **ローカル変数** | `＄変数名` | 一連のシーンが終わるまで |
| **グローバル変数** | `＄＊変数名` | 永続的 |

```pasta
＄ローカル変数＝10        ← 一連のシーンが終わるまで有効
＄＊グローバル変数＝100   ← 永続的に有効
Alice：値は ＄ローカル変数 です
Bob：値は ＄＊グローバル変数 です
```

---

## 代入構文

2つの代入形式：

```
＄変数名＝値        ← イコール形式
＄変数名：値        ← コロン形式
```

### 使用可能な値の型

| 値の種類 | 構文例 |
|---------|--------|
| リテラル値 | `＄score＝100` |
| 単語参照 | `＄value＝＠word_name` |
| 変数参照 | `＄new_var＝＄old_var` |
| 式 | `＄result＝＄a + ＄b * 2` |
| 関数呼び出し | `＄result＝＠calculate()` |
| 関数呼び出し（引数付き） | `＄sum：＠add（x：10　y：20）` |

---

## 式サポート

変数代入で算術式を使用可能：

| 演算子 | 全角 | 半角 |
|--------|------|------|
| 加算 | `＋` | `+` |
| 減算 | `－` | `-` |
| 乗算 | `＊` / `×` | `*` |
| 除算 | `／` / `÷` | `/` |
| 剰余 | `％` | `%` |

括弧 `（）` / `()` で優先順位制御可能。

```pasta
＄count＝10 + 5
＄result＝＄a * ＄b
＄nested＝（＄a + ＄b）* 2
```

---

## 変数宣言行 vs 変数参照

| 文脈 | 用途 | 構文 |
|------|------|------|
| **変数宣言行** | 値の代入 | `＄変数名＝値`（専用行として記述） |
| **アクション行内** | 値の参照のみ | `＄変数名`（代入不可） |

**重要**: アクション行内では変数参照のみ可能。変数への代入は専用の変数宣言行で行う。

---

## アクション行内の区切りルール

アクション行内の変数参照にも、空白区切り・最長一致のルールが適用される。

```
❌ ＄nameさん     → 「nameさん」全体が識別子として吸収
✅ ＄name　さん   → 変数参照「name」+ 通常テキスト「さん」
```

日本語文字（平仮名・カタカナ・漢字）は XID_CONTINUE に含まれるため、空白なしでは後続テキストが識別子に吸収される。詳細は [action-line.md](action-line.md) を参照。

## 自動設定される日時変数（onhour-date-var-transfer）

OnHour（時報）イベント発火時に、`onhour-date-var-transfer` 機能によりローカル変数として自動設定される。辞書作成者が代入する必要はなく、アクション行内で `＄変数名` として参照するだけでよい。

### 数値型（英語キー）

| 変数 | 内容 | 値域 | 例 |
|------|------|------|----|
| `＄year` | 年 | — | `2026` |
| `＄month` | 月 | 1〜12 | `3` |
| `＄day` | 日 | 1〜31 | `20` |
| `＄hour` | 時（24時間制） | 0〜23 | `14` |
| `＄min` | 分 | 0〜59 | `0` |
| `＄sec` | 秒 | 0〜59 | `0` |
| `＄wday` | 曜日番号 | 0=日〜6=土 | `5` |
| `＄week` | 曜日（英語） | Sunday〜Saturday | `Friday` |

### 文字列型（日本語キー）

| 変数 | 内容 | 例 |
|------|------|----|
| `＄年` | 年（接尾辞付き） | `2026年` |
| `＄月` | 月（接尾辞付き） | `3月` |
| `＄日` | 日（接尾辞付き） | `20日` |
| `＄時` | 時（接尾辞付き） | `14時` |
| `＄分` | 分（接尾辞付き） | `0分` |
| `＄秒` | 秒（接尾辞付き） | `0秒` |
| `＄曜日` | 曜日（日本語） | `金曜日` |
| `＄時１２` | 12時間制（和文） | `午後2時` |

### `＄時１２` の変換ルール

| 24h値 | 出力 |
|-------|------|
| `0` | `深夜0時` |
| `1〜11` | `午前N時` |
| `12` | `正午` |
| `13〜23` | `午後N時`（N = hour − 12） |

### 使用上の注意

- 日本語キー変数はアクション行でそのまま使える（例: `＄時１２　だよ！`）
- 数値キー変数は Lua ブロック内での条件分岐に便利（例: `tonumber(var.hour)`）
- 後続テキストとの間に全角空白を入れること（XID_CONTINUE ルール）
