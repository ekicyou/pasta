# 単語定義リファレンス

> Pasta DSL の単語定義（Word Definition）に関する詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## 単語定義構文

### 単一キー

```pasta
＠word_name：value1、value2、value3
```

### 複数キー

同一の値リストを複数のキー名に同時登録：

```pasta
＠key1、key2、key3：value1、value2、value3
```

- コロン（`：`/`:`）の左側にカンマ区切りでキーを指定
- キーが1つの場合は従来形式と同一（後方互換）

### 値区切り文字

以下のいずれも使用可能：
- 全角読点 `、`
- 全角コンマ `，`
- 半角カンマ `,`

## スコープ

| スコープ | 定義位置 | 参照範囲 |
|---------|---------|---------|
| **グローバル** | インデントなし | ファイル全体 |
| **ローカル** | インデントあり（シーン内） | 親シーン内のみ |
| **アクター** | アクター辞書（`％`）配下 | アクター指定時に優先参照 |

```pasta
＠挨拶：こんにちは、おはよう      ← グローバル
＊会話
  ＠天気：晴れ、雨、曇り          ← ローカル（「会話」シーン内のみ）
  Alice：＠挨拶　今日は＠天気　だね。
```

---

## 単語参照

```
＠word_name
```

- 値リストから**シャッフル＆順次消費方式**で1つ選択
- 全候補を一巡するまで同じ値は再選択されない
- 全候補使い切り後に再シャッフル

---

## 動的単語参照

```
＠＄var_name
```

- 変数 `＄var_name` の値を単語名として間接参照
- 実装状態: 文法定義済み、実装は将来予定

---

## スコープ解決アルゴリズム

単語参照 `＠word_name` のスコープ解決は Call 文と共通のアルゴリズム：

1. **ローカル検索**: 現在のグローバルシーンスコープ内のローカル単語を**前方一致**で検索
2. **グローバル検索**: すべてのグローバル単語を**前方一致**で検索
3. **マージ**: 両検索結果を結合
4. **選択**: 候補リストからシャッフル＆順次消費で1つ選択

**前方一致の例**:
```pasta
＠挨拶朝：おはよう
＠挨拶昼：こんにちは
```
- `＠挨拶` → 「挨拶朝」「挨拶昼」の両方が候補
- `＠挨拶朝` → 「挨拶朝」のみが候補

**制限（v1）**:
- 多段階参照（`＠＠word`、`＠＠＠word`）は非対応
- `＠＠` はリテラル「＠」のエスケープとしてのみ使用
