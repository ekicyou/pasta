# 文法モデルリファレンス

> Pasta DSL の行指向文法モデル、ブロック構造、マーカー定義、リテラル、属性に関する詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## 行指向文法

Pasta スクリプトは**行指向文法**。行頭の数文字（マーカー）により行の種類が確定する。

**例外**: Lua コードブロック（複数行にわたる唯一の例外）

---

## マーカー定義一覧

全マーカーは全角・半角の両方を許容する。

| マーカー名 | 全角 | 半角 | セマンティクス |
|-----------|------|------|---------------|
| グローバルシーン | `＊` | `*` | グローバルブロックを開始 |
| ローカルシーン | `・` | `-` | ローカルブロックを開始 |
| 単語/関数 | `＠` | `@` | 単語定義・参照・関数呼び出し |
| 変数 | `＄` | `$` | 変数宣言・参照 |
| Call | `＞` | `>` | シーン呼び出し |
| 属性 | `＆` | `&` | メタデータ付与 |
| コメント | `＃` | `#` | コメント（処理されない） |
| アクター辞書 | `％` | `%` | アクター辞書定義・スコープ指定 |
| キューコマンド | `！` | `!` | 演出キュー |
| コロン | `：` | `:` | キー・値の区切り |
| さくらスクリプト | `\` | — | 表情・タイミング制御（半角のみ） |

## 空白・改行・コロンの定義

### 改行（NEWLINE）

```
改行 ::= "\r\n" | "\n" | "\r"
```

### 空白（WHITE_SPACE 文字クラス）

改行を**除外した**空白文字クラス。Pest の自動スキップ対象ではなく、明示的に処理される。

- 半角スペース `U+0020`、タブ `U+0009`、全角スペース `U+3000`
- その他Unicode空白: `U+00A0`, `U+1680`, `U+2000-U+200A`, `U+202F`, `U+205F`

**ルール**: 1つ以上の連続空白は1つの「空白」トークンとして扱われる

### コロン

```
コロン ::= "：" | ":"
```

キー・値ペア形式（`key：value`）の汎用区切り文字。変数代入、単語定義、属性定義、アクション行で使用。

### インデント

```
インデント ::= WHITE_SPACE+
```

- **判定**: インデントの有無のみ（バイナリ判定）。深さの測定・比較は不要
- インデントなし = グローバルレベル
- インデントあり（深さ問わず）= 下層レベル

## 演算子の全角/半角対応表

| 種別 | 全角 | 半角 | 備考 |
|------|------|------|------|
| 加算 | `＋` | `+` | |
| 減算 | `－` | `-` | |
| 乗算 | `＊` / `×` | `*` | `＊` はシーンマーカーと文脈で区別 |
| 除算 | `／` / `÷` | `/` | |
| 剰余 | `％` | `%` | `％` はアクター辞書マーカーと文脈で区別 |

式は変数代入、関数引数、条件式などで使用可能：
```pasta
＄count＝10 + 5
＄result＝＄a * ＄b
＄nested＝（＄a + ＄b）* 2
```

## ブロック構造

### 階層

```
グローバルブロック
├─ グローバル単語行（＠）*
└─ グローバルシーンブロック（＊）+
     ├─ 属性行（＆）*
     ├─ 暗黙ローカル開始ブロック（__start__）
     │    ├─ Luaブロック
     │    ├─ アクション行
     │    ├─ 変数代入行
     │    └─ Call行
     └─ ローカルシーンブロック（・）*
          ├─ 属性行（＆）*
          └─ コンテンツ行（変数代入/アクション行/Call行）
```

### グローバルシーンブロック

1. **グローバルシーン行**: `＊グローバル名`
2. **属性行**: 0個以上の `＆key：value`
3. **暗黙ローカル開始ブロック（`__start__`）**: Luaブロック、アクション行、Call行等
4. **ローカルブロック**: 0個以上の `・ローカルシーン`

### 暗黙ローカル開始ブロック（`__start__`）

- ローカルシーン宣言なしで暗黙的に開始
- Call でグローバルシーンを呼び出す際に `__start__` ブロックが実行される
- Luaブロックはここに格納

## Luaブロック配置ルール

- グローバルシーン直下に ` ```lua ` 〜 ` ``` ` で囲んで記述（インデント不要）
- **関数定義のみ許可**: `function ...` で始まる関数定義のみ記述可能
- 変数宣言（`local`）やトップレベルステートメントは許可されない
- パーサーは内部を解釈せず、トランスパイラーが検証する

````
＊計算
```lua
function SCENE.calculate(act)
    local save, var = act:init_scene(SCENE)
    return 10 + 20
end
```
  Alice：結果は＠calculate()　です。
````

## リテラル型変換ルール

変数、関数引数、属性値で使用可能な型。以下の優先順位で変換：

| 優先度 | 条件 | 変換先 |
|--------|------|--------|
| 1 | `true` / `false` | bool |
| 2 | `「...」` で囲まれている | String |
| 3 | 小数点を含む数値 | f64 |
| 4 | 小数点のない数値 | i64 |
| 5 | その他 | String |

- 引用符 `「」` 内の空白は文字列の一部として保持
- 引用符なしの空白は区切り文字として認識

## 属性の配置ルール

```
属性行 ::= インデント ~ "＆" ~ key ~ "：" ~ value ~ NEWLINE
```

- **配置**: シーン定義（`＊` または `・`）の**直後にのみ**配置可能
- 複数配置可能: 同じシーンに複数の属性を連続して記述
- **制約**: アクション行や変数代入行の後には配置できない（文法エラー）

```pasta
＊会話
  ＆author：Alice
  ＆genre：comedy
  ・選択肢
    ＆priority：high
    Alice：台詞内容
```

### ファイルレベル属性（将来予約）

ファイル冒頭にインデントなしで配置。ファイル内のすべてのグローバルシーンに自動継承される。

```pasta
＆警報レベル：レッド
＊会話１
  ＆温度：暑い
```
→ 会話１は `＆警報レベル：レッド` と `＆温度：暑い` の両方を保持

## キューコマンド構文

```
cue_cmd_line ::= pad ~ cue_cmd_marker ~ cue_cmd_name ~ cue_cmd_scope? ~ cue_cmd_args?
cue_cmd_name ::= 識別子
cue_cmd_scope ::= "@" ~ 識別子 ~ (":" ~ 識別子)?    // actor:name 形式
cue_cmd_args ::= "(" ~ (cue_arg ~ ("," ~ cue_arg)*)? ~ ")"
```

### 引数トークン型

| 型 | 構文例 | 備考 |
|----|--------|------|
| 識別子 | `normal`, `actor:さくら` | XID_START+XID_CONTINUE |
| 文字列 | `「はい」` | 鉤括弧リテラル |
| 整数 | `30`, `-5` | |
| 浮動小数点 | `10.0`, `-5.5` | |
| @参照 | `@名前` | 全角`＠`も可 |

### 全角/半角対応

マーカー（`!`/`！`）、括弧（`()`/`（）`）、@（`@`/`＠`）はいずれも全角/半角の両方を許容。

### 例

```pasta
!emote@普通(normal)          # コマンド + スコープ + 引数
!wait@さくら(500)            # アクター指定スコープ
！bgm(morning.ogg)           # 全角マーカー
!yield(10.0)                 # 数値引数
!clear                       # 引数なし
```

## 行の種類まとめ

### インデント不要

| 行種 | マーカー | 例 |
|------|---------|-----|
| グローバルシーン | `＊` / `*` | `＊会話` |
| グローバル単語定義 | `＠` / `@` | `＠fruits：apple、banana` |
| Luaブロック | ` ``` ` | ` ```lua ... ``` ` |
| コメント | `＃` / `#` | `＃ メモ` |

### インデント必要

| 行種 | マーカー | 例 |
|------|---------|-----|
| ローカルシーン | `・` / `-` | `　・選択肢1` |
| 属性定義 | `＆` / `&` | `　＆author：Alice` |
| アクション行 | （なし） | `　Alice：こんにちは` |
| Call | `＞` / `>` | `　＞シーン名` |
| 変数代入 | `＄` / `$` | `　＄count＝1` |
| ローカル単語定義 | `＠` / `@` | `　＠天気：晴れ、雨` |

コメント行はインデントあり・なしの両方で許容される。
