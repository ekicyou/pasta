# アクション行リファレンス

> Pasta DSL のアクション行に関する詳細リファレンス。
> 本ファイルは完全な情報を内包しており、外部ファイルへの参照は不要。

---

## 基本構文

```
actor ： action [NEWLINE continuation_line*]
```

- **actor**: コロン前のテキスト。キャラクター名を指定する
- **action**: コロン後のテキスト。通常テキストとインライン要素の組み合わせ
- アクター名を省略すると、直前のアクターが継続する

---

## インライン要素一覧

アクション行内に埋め込み可能な要素：

| 要素 | 構文 | 説明 |
|------|------|------|
| 通常テキスト | `こんにちは` | 任意の文字列 |
| 単語参照 | `＠word_name` | 登録済み単語からランダム選択 |
| 動的単語参照 | `＠＄var_name` | 変数値を単語名として間接参照 |
| ＠エスケープ | `＠＠` | リテラルの「＠」を1文字出力 |
| 変数参照 | `＄var_name` | 変数値を展開 |
| 関数呼び出し | `＠func_name()` | Lua関数を呼び出し |
| 関数呼び出し（引数） | `＠func（x：10）` | 名前付き引数で呼び出し |
| さくらスクリプト | `\n`, `\w8`, `\s[0]` | 表情・タイミング制御 |

---

## インライン判定ルール

行を**左から右へ走査**し、マーカー文字列で分岐して各インライン要素を切り出す。

1. `\`（半角バックスラッシュ）→ さくらスクリプトコマンド
2. `＠＠` → リテラル「＠」
3. `＠＄` → 動的単語参照
4. `＠` → 単語参照 or 関数呼び出し（括弧の有無で判定）
5. `＄＊` → グローバル変数参照
6. `＄` → ローカル変数参照
7. 上記のいずれにも一致しない → 通常テキスト

---

## 識別子定義（Identifier）

```
識別子 ::= XID_START ~ XID_CONTINUE*
```

- **XID_START**: Unicode Identifier Start — `a-z`, `A-Z`, `_`, 平仮名, カタカナ, 漢字 等
- **XID_CONTINUE**: XID_START + ASCII digits + 結合記号

**切り出し規則（最長一致）**:
- 識別子は「識別子に含まれない文字」が現れるまでを最長一致で切り出す
- **日本語文字**（平仮名・カタカナ・漢字）はすべて XID_CONTINUE に含まれる

---

## インライン要素の区切り文字

### 空白による区切り

空白はトークン区切りとして機能し、出力に含まれない。空白数は無関係（1つ以上で1トークン）。

```
＠挨拶　みんな！       → 単語参照「挨拶」+ 通常テキスト「みんな！」
＠挨拶　　　みんな！   → 同じ出力（空白数は無関係）
＄name　さん          → 変数参照「name」+ 通常テキスト「さん」
```

### 空白なしの場合（最長一致）

空白で区切られない場合、識別子として認識できない文字が現れるまでを最長一致で切り出す。

```
＠挨拶、みんな！   → 単語参照「挨拶」+ 通常テキスト「、みんな！」
  （読点「、」はXID_CONTINUEに含まれないため区切りになる）

＄name!          → 変数参照「name」+ 通常テキスト「!」
  （半角「!」はXID_CONTINUEに含まれない）
```

### 意図しない吸収の例

```
❌ ＠weather_wordsですね
  → 最長一致により「weather_wordsですね」全体が識別子として吸収される
  → 日本語文字（で・す・ね）はXID_CONTINUEに含まれるため

✅ ＠weather_words　ですね
  → 空白で区切ることで正しく分離

✅ ＠weather_words、ですね
  → 読点「、」はXID_CONTINUEに含まれないため自然に区切られる
```

### ＠＠エスケープ

リテラルの「＠」を出力したい場合は `＠＠` と記述する。

## 行継続（Continuation Line）

```
continuation_line ::= INDENT ~ !(statement_marker) ~ content
statement_marker ::= "＄" | "＠" | "＞" | "＆" | "＊" | "・"
```

- インデント付き行は前行の続きとして連結される
- **制約**: 継続行は行マーカー（`＄＠＞＆＊・`）で始めてはならない
- マーカーで始まる行は別の行種として解釈される

```pasta
Alice：長い台詞は
  複数行に分けて
  記述できます
```

---

## 改行セマンティクス

- **正規の改行**: さくらスクリプト `\n` で改行を挿入
- **糖衣構文**: 行継続領域内の空行（インデントのみ）は改行として解釈される
- **連続空行**: 連続する空行は、その数に応じた連続改行として出力される
- **非継続領域の空行**: レイアウト目的として無視される

```pasta
Alice：１行目。
  １行目の続き。
  
  ２行目。
```
→ 出力：「１行目。１行目の続き。\n２行目。」（空行が1改行として解釈）
