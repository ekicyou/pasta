# Pasta DSL文法ステアリング

## このドキュメントの役割

**対象**: AI開発支援ツール（Claude Code・GitHub Copilot等）

**役割**:
- 開発時に参照する**非規範の要約**（マーカー早見表・よくある間違い）と、マニュアルの管轄外である開発者向け情報（IR 出力）だけを持つ
- 文法の**権威はマニュアル** [`book/src/grammar/`](../../book/src/grammar/index.md)（公開: https://ekicyou.github.io/pasta/grammar/index.html）である
- このファイルとマニュアルが食い違う場合は**マニュアルが正**。このファイルを直すか削る

ゴースト辞書（`.pasta`）の作成支援は `pasta-ghost-authoring` スキルを使う。

## マーカー一覧（早見表）

マーカー・演算子・括弧は全角と半角を同等に扱う（例外: さくらスクリプトの `\` は半角のみ。ローカルシーンは `・` と半角 `-` で、全角 `－` は使えない）。詳細は [キーワード・マーカー](../../book/src/grammar/markers.md)。

| マーカー         | 全角   | 半角 | 用途                                                       |
| ---------------- | ------ | ---- | ---------------------------------------------------------- |
| グローバルシーン | `＊`   | `*`  | シーン定義                                                 |
| ローカルシーン   | `・`   | `-`  | サブシーン定義                                             |
| アクター辞書     | `％`   | `%`  | アクター辞書の定義・アクター指定行                         |
| 属性             | `＆`   | `&`  | メタデータ（構文は受理されるが処理には反映されない）。式の中では連結演算子（[属性マーカーと連結演算子](../../book/src/grammar/markers.md#属性マーカーと連結演算子)） |
| 単語/関数        | `＠`   | `@`  | 単語定義・参照・関数呼び出し（`＠＄変数名` は変数の値による動的参照） |
| 選択肢           | `＠？` | `@?` | 選択肢行（ジャンプ先＋表示テキスト）                       |
| 変数             | `＄`   | `$`  | 変数の代入・参照                                           |
| 代入             | `＝`   | `=`  | 変数代入の区切り（アクター指定行の番号指定にも使う）       |
| Call             | `＞`   | `>`  | シーン呼び出し                                             |
| キューコマンド   | `！`   | `!`  | 演出指示。`!select` だけが選択肢の制限時間を設定し、他は何もしない |
| コメント         | `＃`   | `#`  | コメント                                                   |
| コロン           | `：`   | `:`  | キー：値の区切り（変数代入には使わない）                   |
| さくらスクリプト | （なし） | `\` | さくらスクリプトのコマンド（半角のみ）                    |

## よくある間違いパターン

| #   | パターン                 | ❌ まちがい                          | ✅ ただしい                                         | 理由                                                                 |
| --- | ------------------------ | ----------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| a   | ＠空白なし               | `＠地名からおらんようなってもた`    | `＠地名　からおらんようなってもた`                 | 識別子は最長一致。日本語文字も識別子に含まれる（区切りの空白は出力されない） |
| b   | ＄空白なし               | `＄nameさん`                        | `＄name　さん`                                     | 同上                                                                 |
| c   | コロンで代入             | `＄score：100`                      | `＄score＝100`                                     | 代入は `＝` だけ。コロンはパースエラー                               |
| d   | 継続行のコロン抜け       | インデントしたテキストだけの行      | インデント＋`：` で始める（`：続きの台詞`）        | `：` の無い行は継続行にならずパースエラー                           |
| e   | アクション行の行末コメント | `さくら：本文 ＃メモ`              | コメントは独立した行に書く                         | アクション行・継続行では `＃` 以降も台詞として出力される             |
| f   | 属性行の配置位置         | ローカルシーン直下・コンテンツ行の後の属性行 | グローバルシーン初期部・ファイルレベル・アクター辞書配下の属性行、またはシーン宣言行への付記 | それ以外の位置の属性行はパースエラー                                 |
| g   | 一度きりイベントでのチェイントーク | `＊OnBoot` で `＞チェイントーク` | 続きを起動時に出したいなら分割しない               | 残りはそのイベントではなく次の OnTalk の機会に出力される             |

## IR 出力（act トークン列）

開発者向け情報（マニュアルの管轄外）。旧 Rune 実装の `ScriptEvent` は現行実装に無い。

現行の流れ: Pasta DSL → パーサー（`pasta_dsl`）→ トランスパイラー（`pasta_lua`）が Lua のシーン関数を生成 → シーン関数が `act` のメソッドでトークンを蓄積 → `act:build()` → さくらスクリプト文字列。

`act`（`crates/pasta_lua/pasta_scripts/pasta/act.lua`）が `self.token` に積むトークン:

| トークン `type`  | フィールド         | 生成元                       |
| ---------------- | ------------------ | ---------------------------- |
| `talk`           | `actor`, `text`    | `act:talk`（発言テキスト）   |
| `sakura_script`  | `actor`, `text`    | `act:sakura_script`          |
| `raw_script`     | `text`             | `act:raw_script`（アクター未指定の生スクリプト） |
| `surface`        | `id`               | `act:surface`                |
| `wait`           | `ms`               | `act:wait`                   |
| `newline`        | `n`                | `act:newline`                |
| `clear`          | （なし）           | `act:clear`                  |
| `choice`         | `target`, `display`| `act:choice`（選択肢行）     |
| `choice_timeout` | `seconds`          | `act:choice_timeout`（`!select`） |
| `spot`           | `actor`, `spot`    | `act:set_spot`（アクター指定行） |
| `clear_spot`     | （なし）           | `act:clear_spot`（アクター指定行の先頭） |

- `ACT_IMPL.build()` はトークンを取り出してリセットし、アクター切り替え境界で `type = "actor"`（`actor`, `tokens`）にグループ化し、連続する `talk` を結合して返す（0 件なら `nil`）。
- `pasta.shiori.act` の `build()` は上の結果を `pasta.shiori.sakura_builder` でさくらスクリプト文字列に変換する（0 件なら `nil`）。
- `act:yield()` は `build()` の結果を `coroutine.yield` する。
