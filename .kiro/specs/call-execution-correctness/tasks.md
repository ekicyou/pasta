- [ ] 2. ランタイム: 失敗表記・文脈の復元・動的キーの判定
- [ ] 2.1 失敗表記の唯一の出口と、文脈を戻す口を追加する
  - 失敗の出口は、警告があればログへ出し、`【…】` で囲んだ文字をアクター無しの発言トークンとして積む
  - 文脈を戻す口は、実行中のシーンを指定の値に戻し、残りの戻り値（複数を含む）をそのまま返す
  - 「呼んで戻す」口は、`act:call` と同じ引数で呼び、戻った後に呼び出し前の実行中のシーンへ戻す（呼ばれた側がシーン・Lua の関数・見つからない場合のいずれでも戻す）
  - 失敗表記のトークンがアクター集約とさくらスクリプト組み立てを通ったとき、発言の後でも出力の先頭でも切替タグが増えずに文字が出ることを単体テストで確かめる
  - 完了状態: 新しい単体テストで、呼ばれた側が別シーンを初期化しても戻った後の実行中のシーンが呼び出し前のものであり、戻り値が保たれることが成功する

- [ ] 2.2 動的コールの値を検索キーにする判定と、`act:call` の失敗表記を追加する
  - 空でない文字列（文字列 `nil` を含む）はそのまま、数値は現行と同じ表記の文字列をキーとして返す
  - nil・空文字列・使えない型は、変数の経路があれば動的単語参照と同じ警告、関数の表記があれば被演算子の表記の警告、値 nil で説明が無ければ警告なし、とし、いずれも失敗表記を積んで「呼ばない」印を返す
  - `act:call` は印なら検索も警告もせずに nil を返し、見つからないときは現行の警告に加えて `【Call失敗：「名前」が見つからない】` を積む。nil キーの直接呼び出しは現行どおり警告だけで失敗表記を出さない
  - 見つからない Call の出力やトークンを見ている既存のテスト（シンボル名検索・動的参照・アクタープロキシの委譲のテストなど）を、失敗表記の分だけ更新する
  - 完了状態: 設計の判定表の各行（戻り値・警告の文言と件数・積まれるトークン）と、`act:call` の 3 つの分岐を確かめる単体テストが成功する
