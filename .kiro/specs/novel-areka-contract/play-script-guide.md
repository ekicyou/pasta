# 演劇の台本の書き方（骨子の写し。2026-11-19）

`/kiro-discovery`（ノベルゲームの深掘り）で決まった骨子を、台本を書く人の目線で 1 か所にまとめた。決定の本文は各 brief の「決定（2026-11-19）」の節に、議論の経緯は `discovery-2026-11-19.md` に在る。**命令の名前は、どれも仮である**（取り決めの文書を作る `novel-areka-contract` の要件定義で確定する）。まだ実装は無い。

## 1. 演劇の始めと終わり

- `＞演劇開始` を呼ぶと、その流れは「字を出すアクション行ごとに、さくらスクリプト 1 本を返して、クリックを待つ」走り方になる。`＞トーク開始` で、ふつうのゴーストの走り方に戻る。
- 演劇は、さくらスクリプトの切り方の状態である。シーンに種類は無い。ふつうのゴーストの途中から始められる。
- 舞台の窓を開くことは、別の制御である（4 章）。舞台を開かない演劇は、デスクトップのゴーストのまま、1 行ずつ進む。

```pasta
＊物語の入口
    ＞演劇開始
    ＞第一章
```

## 2. 区切り（さくらスクリプト 1 本に入る物）

- 1 本は「前の区切りの次から、字を出すアクション行（と、その継続行）の末尾まで」。
- 間のト書き（`！` 行）・字の無いアクション行（表情だけ）・柱・アクター指定行は、その 1 本に、書いた順で入る。**ト書きは、直後のアクション行を修飾する。**
- 継続行の前に書いたト書きは、字の途中の、書いた位置で効く。

```pasta
＊嵐の教室　＆曲：雨音
    ％教室、さくら
    教室：＠雨
    さくら：降ってきたね。
    ！効果音（雷）
    ！揺らす（強く）
    教室：＠稲光
    さくら：＠驚き　きゃっ！
```

1 本目は「降ってきたね。」まで（柱・並び・教室の表情が入る）。2 本目は、雷・揺れ・稲光と「きゃっ！」。

## 3. ト書きと柱

- `！名前＠対象（引数…）` は、`\![名前,対象,引数…]` になる。対象はアクターの名前。日本語の名前は、`pasta.toml` の別名表でタグに置き換わる。
- 柱（`＆名前：値`）は、シーンに入ったときに自動で打たれるト書きである。曲のように、場面の間ずっと成り立つことは柱に書く。同じ値なら何も起きない。
- 命令には「残る」と「瞬間」が在る。
  - **残る**: 値を置く命令。pasta が最後の値を覚え、戻る・ロード・出し直しのときに打ち直す。
  - **瞬間**: その行が再生されるときだけ起きる。
- 引数の決まり: 数字で始まる文字は「」で囲む（`！待つ（「３秒」）` か `！待つ（３）`）。引数に変数は書けない。

| 区分 | ト書き（仮） | 値 | ゴール |
| ---- | ------------ | -- | ------ |
| 残る | `！舞台（開く）`・`！舞台（閉じる）` | 開く・閉じる。形（ウィンドウ・全画面・ボーダーレス）は遊ぶ人の設定。書けばそれが勝つ | 1 |
| 残る | アクター指定行 `％教室、さくら` | 並び。並びに無いアクターは消える | 1 |
| 残る | `！位置＠さくら（窓際）` | 席の名前か数値。席の名前は舞台の定義に書く | 1 |
| 残る | `！重ね順＠`・`！大きさ＠`・`！透明度＠` | 数 | 1 |
| 残る | 表情（`さくら：＠驚き`） | サーフェスと着せ替え | 1 |
| 残る | `＆曲：雨音`・`！曲（雨音）`・`！曲（）` | 曲の名前。引数なしで止める | 1 |
| 残る | `＆環境音：雨`・`！環境音（雨）` | 音の名前 | 1 |
| 残る | `！色調（琥珀）` | 色の名前 | 2 |
| 残る | `！カメラ（窓へ寄る）` | 寄り・位置 | 2 |
| 瞬間 | `！転換（暗転、１０００）`・`！転換（明転、１０００）`・`！転換（移動、５００）` | 種類と時間 | 1 |
| 瞬間 | `！転換（クロスフェード、８００）`・ルール画像 | 種類と時間 | 2 |
| 瞬間 | `！効果音（雷）`・声 | 音の名前 | 1 |
| 瞬間 | `！揺らす（強く）`・`！フラッシュ` | 強さ | 1 |
| 瞬間 | `！待つ（３）` | 字の前に間を置く | 1 |
| 瞬間 | `！時間で次へ（３）` | この行は、クリックを待たずに次へ進む | 1 |

- 転換は、転換のト書きから「次の字・次の転換・1 本の終わり」のどれか早い所までの変更を、1 まとめにして見せる。字は、それが終わってから出る。時間を付けるのは転換だけ。

```pasta
    ！転換（暗転、１０００）
    教室：＠夜
    ！転換（明転、１０００）
    さくら：もう夜だ。
```

## 4. 舞台と箱

- 舞台が開いている間、デスクトップの窓とバルーンは隠れる。閉じると戻る。
- 画面の部品は、全部アクターである（人物・背景・小道具・台詞の箱・ボタンを載せた「システム」）。
- 台詞は、ふつうに話者の行で書く。舞台に「トークの場所」の役のアクター（台詞の箱）が居れば、字はその箱に出る。話者の名前は、並びの名前が出る。
- 箱のアクター自身の行で書いた字は、その箱に出る（地の文・チャット）。縦書きか横書きかは、箱の定義で決まる。
- トークの場所が居ないときは、話者自身のシェルの箱に出る（キャラのそばのふきだし）。

```pasta
    ぱすた：＠横目　‥‥今日は、窓が大きいでしょう。
    地の文：ビルの隙間に、ひとつ。
```

## 5. 遊ぶ人の操作

- **進める**: 台詞の箱を押す。当たり判定の無い所を押す。
- **小道具を押す**: 条件の属性で書いたシーンが走る。終わると、待っていた行が自動で出し直される。読ませたい台詞は、行の末尾にクリック待ち（`\x`）を書く。

```pasta
＊OnMouseClick　＆＄ｒ４＝「冷凍庫」
    ぱすた：＠笑顔　無事です。\x
```

- **選択肢**: `＠？飛び先「表示」`。条件を付けられる（文法に足す）。時間切れの飛び先も書ける（`！select` の 2 つ目の引数。足す）。

```pasta
    ！select（２０、時間切れ）
    ＠？明かりを消す「明かりを消す」
    ＠？手を振る「手を振ってみる」　＆＄＊スロット訪ねた数≧３
```

- **セーブとロード**: `＞スロット保存（１）`・`＞スロット読込（１）`。続きの場所は、シーンの名前と行の番号。
- **覚える所**: セーブと一緒に戻る物は `＄＊スロット〜`。ロードしても消えない物（見た結末）は、ふつうの `＄＊〜`。後者は、デスクトップのトークの条件にも使える。
- **バックログ**: 行を選ぶと、その行へ戻る。行は、ト書きごと再生される（雷が鳴り、揺れる）。
- **オートと高速再生**: 遊ぶ人の設定。台本には書かない。

## 6. ゴールの分け方（開発者の決定）

開発者: 「ゴールを分けてよい。最低限実現に必要なもの → 実装が重いが後回しでもよいもの、は分けるべきですね。」

| ゴール | 中身 |
| ------ | ---- |
| **1（最低限）: 正典だけで動く層** | 1 行ずつ進む・選択肢と条件・変数・セーブとロード・寄り道と出し直し・高速再生（`\_q`）・バックログに貯めない（`\__v[disable]`）・3 人以上と表情と着せ替え・曲と効果音と環境の音（`\![sound,…]`）・字の前の待ち。**SSP でも動く見込み**（実機は未確認） |
| **1（最低限）: `play` の命令の層** | バックログの行へ戻る（目印）・オート（`\x` の時間）・出し直しの印・舞台の窓（ウィンドウと全画面）・並び・位置（席）・重ね順・大きさ・透明度・転換（暗転・明転・移動）・揺れとフラッシュ・台詞の箱（話者の名前・縦書きと横書き）・設定の値。ベースウェアの対応が要る |
| **2（重い。後回しでよい）** | 色調・クロスフェード・ルール画像・カメラ・舞台の外（画面いっぱいの透明の舞台・デスクトップ全体の暗転・枠の外へはみ出す絵・窓が広がる）・カーソル（付いて動く絵・目で追う・視差）・掴んで動かせるアクター・全画面に文を流す形・曲をフェードで替える・セーブの画面の縮小・動画 |

ゴール 2 の物も、書き方の形は 3 章の表で決めてある。色調は、ゴール 1 の間、半透明の色のアクターを重ねて代えられる。

企画の段で挙がって、まだ語彙に無い物: ぼかし・ピント・ビネット／選択肢をボールの周りに輪で出す／下から積み上がるチャットの吹き出し／字が震える・字の音／音の向き。台本の検証で、足りない物の一覧に入れる。

## 7. 確かめていないこと

- ベースウェアの側の見立て（areka）は、読むだけの調査である。SSP の仕訳は ukadoc を読んだだけで、実機では確かめていない（`research-ssp-capabilities.md` の B 節の 10 項目）。
- 継続行の前にト書きを挟む書き方が、今の検査を通るか。
- 高速再生で `\x` を出さないと、行が画面に出る前に次の行で置き換わるおそれ（areka の指摘。起きるなら、pasta が行の末尾に短い待ちを入れる）。
