# Brief: novel-areka-contract

`/kiro-discovery` で起票（2026-10-10・main `88c4bc0e`）。0.5.0「areka でノベルゲームが作れる」の道筋の 1 番目で、**areka に依頼を出すための spec** である。コードは書かない。

## Problem

0.5.0 の目標は、別リポジトリで開発中の areka で、市販品の体裁のノベルゲームが作れるようになることである。画面と音を出すのは areka で、pasta は台本を返すだけである。ところが、pasta が台本に何を載せ、areka がそれをどう受け取るかの取り決めが、どこにも無い。

- areka には、音の層・複数のシェルを 1 つの窓に並べる仕組み・場面転換の演出・スクリプトへ届くキーボード入力が無い。どれも brief すら無い。
- areka には、ほかのプロジェクトからの依頼を受ける窓口が無い。areka の新しい作業は、areka のリポジトリでの `/kiro-discovery` から始まる。
- pasta の側の spec（`cue-command-runtime` ほか 7 本）は、語彙の名前とイベントの名前が決まらないと、既定値と見本を書けない。

areka の側の作業が一番重い。依頼が遅れるほど、0.5.0 が遅れる。

## Current State

### 決まっていること（2026-10-10 の discovery での開発者の決定）

- **合格ライン**: 市販品の体裁。遊ぶ人は、クリック送り・セーブとロード・バックログと巻き戻し・既読スキップ・オート・設定・タイトル画面を使える。
- **通り道**: SHIORI/3.0 とさくらスクリプトのまま。演出は `\![名前,引数…]` に載せる。pasta 専用の通り道（`pasta_novel` アダプタ、SHIORI4）は作らない。
- **画面**: 複数のシェルの組み合わせで作る。背景・登場人物・トークの出る場所が、それぞれシェルである。普通の窓と全画面の両方を areka に依頼する。
- **アクター**: 背景もトークの場所も、キャラと同じく pasta のアクターとして扱う。状態はサーフェスで表す（例: アクター「教室と窓」に `＠稲光` を引かせると、雷の絵に替わる）。
- **システム画面**: areka が出すのは部品だけである（エレメント単位のクリック、シェルの中のバルーン、サーフェスの階層）。タイトル・セーブ・ロード・設定の画面は、シェルとして組み、pasta の場面が動かす。
- **バックログ**: 一覧（顔・話者・文）は areka が持つ。pasta は台本に目印の ID を埋める。バックログの行が選ばれたら、areka はその行の直近の ID をイベントで知らせる。ID の中身は pasta だけが知る。
- **表示の進み具合に関わる機能**（クリック送り・早送り・オート・既読とスキップ）は areka が持つ。どこまで表示したかを知っているのは areka だけだからである。

### areka の現在地（2026-10-10・areka main `b3650b68`・v0.0.2 を読み取りで調べた）

- 伺か互換のベースウェア。描画は Windows.UI.Composition と Direct2D・DirectWrite。1 スコープに 1 枚の透明な窓で、2 体まで。areka の土台（`wintf`）は普通の窓も作れるが、areka の本体は使っていない。
- pasta は、32 ビットの `pasta.dll` を別プロセス（`shiori-host32-helper.exe`）で動かして使っている。本番の通り道はこれだけである。
- さくらスクリプトは、areka の中で台本（`CueSheet`）に直されて再生される。`\![名前,引数…]` は、すべて `Custom{command, params}` の 1 本で運ぶ決まりで、命令ごとの型は増やさない。areka 独自の拡張は `\![…]` の中に置く。
- **もうある物**: サーフェスの階層（エレメントが別のサーフェスを呼べる）、シェルの中のバルーン、縦書き、1 字ずつの表示、選択肢、アンカー、`\_w` の待ち。
- **brief だけある物**: クリック待ち `\x` と早送り（`areka-P0-talk-fast-forward`）、ルビ、禁則、フェードで現れる文字、3 体目以降（`areka-P0-extra-character-windows`）、`OnMouseClick`（`areka-P0-mouse-click-wheel-events`）、文字入力。
- **何も無い物**: 音（BGM・効果音・声）、動画、複数のシェルを 1 つの窓に並べること、場面転換の演出、キーボード入力、ボタンなどの部品。
- areka が SHIORI へ送るイベントは、許可した名前だけである（`areka-kanade` の `ALLOWED_EVENT_IDS`）。新しいイベントは、ここへ足してもらう必要がある。
- areka は「自動の改ページ待ち」を採らない方針である（デスクトップマスコットは勝手に喋るもの、という理由）。クリック待ちは、台本に書いた `\x` だけで起きる。
- areka の作業の進め方: Kiro の spec 駆動。`/kiro-discovery` が `.kiro/specs/areka-P0-<名前>/brief.md` を書く。1 spec は 20 タスクまで。spec をまとめて量産しない決まりがある。文書は日本語。`.kiro/MEMO.md` は人間専用で、LLM は読まない。

### pasta の現在地（2026-10-10 に確かめたこと）

- 知らない `\![…]` は、日本語の引数を含めて、そのまま台本に残る。待ちも改行も挟まれない。
- NOTIFY のイベントに、pasta は台本を返せない（DLL が Lua を走らせる前に 204 を返す。`crates/pasta_shiori/src/actor/marshaling.rs` 232 行付近）。**ノベル用のイベントは、すべて GET で送ってもらう必要がある。**
- GET の応答が 5 秒を超えると、DLL は 204 を返す（同ファイル 71 行）。

### 調査ノート（このフォルダ）

- `research-jp-engines.md` — 国産エンジン 10 系統（KAG3・NScripter・TyranoScript・Artemis・Suika2・宴ほか）のスクリプト仕様。共通コア 30 項目、セーブと実行位置の方式、スクリプトとエンジンの役割分担。
- `research-western-engines.md` — 欧米 9 系統（Ren'Py・Ink・Yarn Spinner・Naninovel ほか）。ホストとの取り決めの 3 つの型、コルーチン実行でのセーブと巻き戻し、ホストに前提される最小の演出語彙。

どちらも、記述ごとに「取得したページで確かめた／記憶」の印がある。記憶の印の記述は、根拠にする前に原典で確かめる。

## Desired Outcome

- pasta と areka の取り決めが、1 つの文書になっている。版の番号を持つ。
- その文書から起こした areka への依頼書が、areka のセッションへ渡っている。areka の側でどの brief になったかの対応表が、pasta の側に残っている。
- 0.5.0 に要る物と、後へ回す物の線引きが、依頼ごとに書いてある。
- 後続の spec が、語彙の名前・イベントの名前・設定の値の名前を、この文書から引ける。

## Approach

### 取り決めの文書に書くこと

何が出来てほしいかだけを書く。作り方は書かない。areka の言葉（シェル・サーフェス・スコープ・バルーン・エレメント・台本）で書く。下は、discovery の時点での要求の一覧（要件定義のたたき台）である。

**画面**

- 複数のシェルを、1 つの窓の中に組み合わせて出す（背景・登場人物・トークの場所・上に重ねる画面）。
- 普通の窓と全画面。その切り替え。画面の大きさが違う環境での拡縮。
- シェルごとの位置（名前の付いた席と数値）、重ね順、出す・消す。3 体以上。

**映像**

- サーフェスの替わり方。瞬間・クロスフェード・ルール画像によるワイプ。時間の指定。複数の変更をまとめて 1 回で替える。
- 位置・大きさ・不透明度を、時間をかけて変える。
- 画面の揺れ、フラッシュ、色調（暗転・セピアなど）。
- 動画は、要るかどうかから決める。

**文章**

- トークの出る場所は、シェルの中のバルーン。話者名の欄。名前を指定してバルーンへ書く。
- クリック待ち（`\x`）と早送り。行末の待ちと改ページの待ち。窓を出す・隠す。
- 文字の速度、色、大きさ、ルビ。下に窓を置く形と、全画面に文を流す形。

**音**

- 曲: 再生・停止・ループ・フェード・曲から曲への移り変わり。同じ曲は鳴らし直さない。
- 効果音: 重ねて鳴らす。ループ。
- 声: 台詞に結び付ける。次の台詞で止める。バックログから聞き直す。
- 区分ごとの音量。演出のための音量と、遊ぶ人の設定の音量を分ける。再生の終わりを待つ。

**時間と入力**

- 時間の待ち（飛ばせる・飛ばせない）。演出が終わるまでの待ち。
- クリック送り。キーボード（送り・スキップ・画面を開く）。
- エレメント単位のクリックを、名前つきで知らせる。
- オート（声が終わるのを待つ）。スキップ（既読だけ・全部）。

**目印・バックログ・既読**

- 目印の ID を台本に書ける。areka は、通り過ぎた ID を、バックログの行に結び付けて覚える。
- 目印を通り過ぎた時点の画面と音を控え、ID を指定されたら、演出なしで即時に再現する。
- バックログの行が選ばれたら、その行の直近の ID をイベントで知らせる。
- 「ここは記録しない」の印（タイトル画面など）。
- 既読は、台本を直さない限り変わらない ID で覚える。全セーブ共通。

**セーブ**

- スロットごとに、areka の側の控え（画面と音・直近の ID）を持つ。
- 画面を画像に撮る（縮小画像）。エレメントの絵を差し替える。

**設定の値**

- 文字の速度、区分ごとの音量、全画面か窓か、オートの待ち時間、スキップの対象。これらを、スクリプトから読み書きできる値として出す。

**イベント**

- 巻き戻し、エレメントのクリック、「読み終えたので次の場面へ」、セーブとロード。名前を決め、areka の許可した一覧へ足してもらう。**すべて GET で送る。**

**配布**

- ノベルを 1 本の配布物として起動する形（ゴーストとして入れるのか、専用の起動か）は、決めていない。

### 依頼の出し方（開発者の指示・2026-10-10）

- この spec の最後のタスクで、areka のリポジトリ（`C:\home\maz\git\areka`）のセッションへ依頼書を渡す。areka の側の `/kiro-discovery` が、それを areka の brief にする。
- pasta のセッションから、areka のリポジトリを直接書き換えない。
- 依頼は、areka の決まり（1 spec は 20 タスクまで・まとめて量産しない）に合う大きさの束に分けて出す。0.5.0 に要る束と、後でよい束を分ける。
- 後続の spec が、要件定義や実装の途中で依頼を足す・変えるときも、同じ手順を踏む（取り決めの文書を直す → areka のセッションへ知らせる）。そのとき、areka のセッションを立てて、同時に説明してもよい。各 brief の「areka への依頼」の節が、その入口である。

### 依頼に添える訂正

- areka の `doc/PASTA_PROFILE.md` §5 は、「pasta が出す `\w[N]` は上流の欠陥」と書いている。2026-10-10 に確かめた所、pasta のエンジンは `\w[` を出していない（出す待ちは `\_w[ミリ秒]`）。出どころは、同じ文書の作例にある手書きの `\w[500]` である。作例を `\_w[500]` に直してもらう。

### 要件定義で最初に決めること

1. 取り決めの文書をどこに置くか（マニュアルの内部設計の部か、リポジトリの `doc/` か）。
2. 語彙の名前の付け方。areka の拡張は SSP の流儀（英語）である。日本語の名前は、pasta の別名表（`cue-command-runtime`）で足す見込み。
3. 依頼の束の分け方と、0.5.0 に要る物の線引き。
4. 動画・配布の形のように、要るかどうかから決める項目の扱い。

## Scope

- **In**: 取り決めの文書。areka への依頼書と、その受け渡し。areka の brief との対応表。語彙・イベント・設定の値の名前。0.5.0 に要る物の線引き。
- **Out**: areka の側の設計と実装。pasta の側の実装（後続の spec）。pasta の文法の変更。

## Boundary Candidates

- 取り決めの文書（項目ごとの節）。
- areka への依頼書（束ごと）。
- 対応表と、依頼を足す・変えるときの手順。

- さくらスクリプトそのものの仕様（ukadoc が正典）。

## Constraints

- areka のリポジトリを、このリポジトリのセッションから書き換えない。
- areka の決まりに沿う。拡張は `\![…]` の中に置く。命令ごとの型を増やす依頼をしない。
- ノベル用のイベントは GET で送ってもらう。応答は 5 秒以内に返す。
- 調査ノートの「記憶」の印の記述を、根拠にしない。
- この spec はソースを触らない。0.4.0 の作業と並んで進められる。マニュアルに章を足す場合だけ、目次（`SUMMARY.md`）と章の数を決め打ちする検査が、ほかの spec と重なる。
