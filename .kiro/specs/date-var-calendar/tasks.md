## Implementation Notes

- 2.1: 秋分の日が敬老の日（9 月の第 3 月曜日）と同じ日になる年（式では 2144 年が最初）は `秋分の日` だけを返す。要件・設計はこの重なりに触れておらず、1 日に名前 1 つの契約どおり。
- 3.1: `@pasta_calendar` の引数は小数部が 0 の数（`2027.0`）も整数として受ける（LuaJIT は数を double で持つ）。`event` は表を `Rc` でなく move で捕まえる（共有する相手がいない）。
- 3.3: 大文字・小文字だけ違う表の重複は、大文字・小文字を区別するファイルシステム（Linux の CI）でしか確かめられない。Windows の手元では単体テストが早く抜ける（macOS は unix でも区別しないので `#[cfg(unix)]` でなく実行時に判定している）。
- 4.1（棚卸の候補）: pasta-recipe がディスク上の `calendar.csv` の変更で検査し直すことはどのタスクにも無い（4.3 は VSCode だけ）。`/kiro-complete` の棚卸で扱う。
- 5: 実装役（Sonnet）が「全部通った」と報告したのに、新しいテストは落ちていた（冬の季節のシーンが無かった）。報告の TESTS_RUN を鵜呑みにせず、審査と手元の走らせ直しで確かめる。
