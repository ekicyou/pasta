# Implementation Plan

- [x] 1. クレート依存関係の追加
  - `pasta_lua` の依存関係に `budoux` と `unicode-width` を追加する
  - ワークスペース全体のビルド成功を確認する
  - _Requirements: 1.1, 1.2, 1.3_

- [x] 2. 改行挿入コアロジックの実装
- [x] 2.1 タグ透過の改行挿入アルゴリズムを実装する
  - 入力文字列を正規表現で走査し、平文1文字ごとに直後のタグ群を紐付けたトークン列を構築する
  - トークン列から平文を連結し、budoux 日本語モデルでワード分割する
  - ワードごとに CJK 幅を加算し、行幅閾値を超過した位置を改行候補として記録する
  - 行ごとに異なる閾値を適用し、スライス末尾の値を3行目以降に繰り返す
  - 閾値を超過する単一ワードは強制分割せずそのまま出力する
  - タグを元の位置関係で保持しつつ、改行候補位置にさくらスクリプト改行タグを挿入した出力を組み立てる
  - 空入力・空幅スライスでは入力をそのまま返す
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 3.1, 3.2, 3.3, 4.1, 4.2, 4.3, 4.4, 4.5_

- [x] 2.2 ユニットテストで正確性を検証する
  - 平文のみの日本語テキストに対する改行挿入を検証する
  - ウェイトタグを含むテキストでタグが幅計算から除外され出力に保持されることを検証する
  - 複数行幅閾値で1行目・2行目・3行目以降にそれぞれ正しい閾値が適用されることを検証する
  - 空入力・空幅スライスで入力がそのまま返ることを検証する
  - 閾値超過ワードの各パターンを検証する（先頭のみ超過、超過＋後続、連続超過、通常→超過→通常）
  - 入力に既存の `\n` タグが含まれる場合の透過処理を検証する
  - _Requirements: 8.1, 8.2, 8.3_

- [x] 3. Lua API 公開と共有ステート拡張
