## 概要

シーンの実行中に起きる辞書の書き間違い（値の無い変数、見つからない単語・関数・シーン、登録していないアクター、数や文字列にできない値など）を、すべて同じ出口から報告するようにした。1 件の失敗について、バルーンのその場所に `【何が起きたか：対象（説明）】` の形の失敗表記が 1 つ、ログに警告が 1 行出る。シーンは止まらずに続き、失敗した後の続き方（空として続ける・Call を飛ばす・0 や空文字列として計算する）は変わらない。

表記の読み方・種類の一覧・出る位置・重ねて出さない規則・切り替えは、マニュアルの [実行時の失敗の出力](https://ekicyou.github.io/pasta/reference/runtime-failures.html) にまとめた。

## 破壊的変更

### 空で展開していた箇所に失敗表記が出る

これまで何も出さずに空で展開していた次の失敗で、その位置に失敗表記が出る。

| 辞書の例 | これまで | これから |
| -------- | -------- | -------- |
| `さくら：今日は＄話題。の話`（`＄話題` に値が無い） | `今日は。の話` | `今日は【値の無い変数：＄話題】。の話` |
| `さくら：前＠挨拶。後`（単語が無い） | `前。後` | `前【単語が見つからない：＠挨拶】。後` |
| `さくら：前＠計算（１）後`（関数が無い） | `前後` | `前【関数が見つからない：＠計算（）】後` |
| `さくら：前＠＊計算（１）後`（グローバル関数が無い） | `前後` | `前【関数が見つからない：＠＊計算（）】後` |
| `さくら：前＠＄未代入。後`（動的参照の値が無い） | `前。後` | `前【名前にならない値：＄未代入（値なし）】。後` |
| `＄y＝＄x＋１`（`＄x` が `「abc」`） | 何も出ない | `【数にできない値：＄x（"abc"）】` |
| `＄c＝＄t＆「後」`（`＄t` が真偽値） | 何も出ない | `【文字列にできない値：＄t（true）】` |

- アクション行以外（代入行・Call の引数・式の中・Lua ブロックから呼んだ act のメソッド）で起きた失敗も、その時点までの出力の後に出る。
- 他に出力の無いシーン（毎秒のイベントなど）でも、書き間違いがあれば失敗表記だけのバルーンが出る（空の出力として扱わず 200 で返す）。
- ログの警告の文言は変わらない。ただし次の 2 つは出なくなった。
  - 登録していないアクターの行で出ていた立ち位置の警告（`actor_spots fallback: '…' -> spot=0`）。未登録アクターの警告と重なるため。
  - 関数の参照や変数がすでに報告した動的な Call（`＞＠無い関数（）`、`＞＠＄未代入（）`）で出ていた `act:call - key is not a string or number: …`。重ねない規則により、参照の側の警告 1 行だけになる。

### 既存の 2 種の表記が変わる

Call の失敗は、文言が種類ごとの新しい形になった。

| 辞書の例 | これまで | これから |
| -------- | -------- | -------- |
| `＞会話２`（シーンが無い） | `【Call失敗：「会話２」が見つからない】` | `【シーンが見つからない：＞会話２】` |
| `＞＄行き先`（値が無い） | `【Call失敗：var.行き先 が nil】` | `【名前にならない値：＄行き先（値なし）】` |
| `＞＄空`（空文字列） | `【Call失敗：var.空 が空文字列】` | `【名前にならない値：＄空（空文字列）】` |
| `＞＄真`（真偽値） | `【Call失敗：var.真 が boolean】` | `【名前にならない値：＄真（真偽値）】` |
| `＞＠値なし（）`（関数が値を返さない） | `【Call失敗：@値なし() が nil】` | `【名前にならない値：＠値なし（）（値なし）】` |
| `＞＠無い関数（）`（関数が無い） | `【Call失敗：@無い関数() が nil】` | `【関数が見つからない：＠無い関数（）】` |

動的な Call で、行き先を決める関数の参照や変数がすでに失敗を報告したとき（`＞＠無い関数（）`、`＞＠＄未代入（）`）は、Call の側は表記も警告も重ねて出さない。表記は参照の側の 1 つだけになる。

未登録アクターの目印 `【未登録アクター：名前】` は、文字は同じだが、台詞ではなく失敗表記として出る。他の失敗表記と同じく、句読点のウェイトと自動の改行が入らない。目印は話者がその名前に切り替わるたびに 1 回、そのアクターの発言の先頭に出る。

### 表記の中身はエスケープされる（`act:failure` の text も）

失敗表記の中の名前や値に含まれるさくらスクリプトのタグは実行されず、書いた文字のとおりに出る（`\` → `\\`、`%` → `\%`、改行は空白）。Lua から呼ぶ `act:failure(text, warning)` の `text` も同じ置き換えを受けるようになった。これまで `text` にタグを書いて実行させていた場合は、タグが文字のまま表示される。

### 中身の無い raw_script だけのシーンは 204 になる

Lua から `act:raw_script("")` だけを積んだシーンは、これまで中身の無い応答（`\e` だけ）を 200 で返していたが、何も出さないシーンと同じく 204 を返す。

## 失敗表記を消すには

`pasta.toml` に次を書くと、失敗表記（未登録アクターの目印とシーンが見つからない場合を含む）をバルーンに出さない。ログの警告はこの設定にかかわらず出る。書かなければ `true`（出す）。配布するゴーストで利用者の画面に表記を出したくないときに使う。

```toml
[logging]
balloon_warning = false
```

この設定では、表記だけだった出力は 204 になり、バルーンの出力は失敗表記を除いたものと同じになる（[[logging]（ログ出力）](https://ekicyou.github.io/pasta/reference/pasta-toml.html#loggingログ出力)）。

## 主な変更

- 失敗の報告の出口 `pasta/failure.lua` を新しく置き、act の 11 か所・proxy の 2 か所・`WORD.dynamic_key`・`PASTA.num`／`PASTA.str` の失敗をここから出す。表記の形・エスケープ・Lua の書き方から辞書の書き方への名前の変換（`var.x` → `＄x`、`save.x` → `＄＊x`、`args[1]` → `＄０` など）を 1 か所で定める
- 1 つの原因に表記 1 つ・警告 1 行（内側が報告したら外側は重ねない）。同じ書き間違いでも別の行・別の回ではそれぞれ報告する
- `act:failure` は引数の互換を保ったまま、この出口の入口にした。後続の spec（`runtime-error-balloon` など）が種類の名前を足して使える
- 生成する Lua の形は変えていない。サンプルゴースト（hello-pasta）は既定の設定で失敗表記を 1 つも出さず、失敗の無い辞書の出力とログは変わらない
- 特性化テストで 14 か所の挙動を固定してから 1 種類ずつ載せ替え、既存テストの期待値を新しい文言に合わせた。重ねない規則・位置・切り替えを DSL から通しで確かめる
- マニュアルに「実行時の失敗の出力」の章を足し、失敗時の挙動を書いていた各章と pasta.toml の説明を直して、スキルの references を再生成した
