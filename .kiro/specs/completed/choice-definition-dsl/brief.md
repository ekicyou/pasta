# Brief: choice-definition-dsl

## Problem
ゴースト作者が選択肢メニューを実装するには、現在さくらスクリプトの`\q[表示テキスト,選択ID]`を手書きし、`OnChoiceSelectEx`イベントハンドラをLuaで個別に記述して選択結果を処理する必要がある。さとり（里々）のような「選択肢＝トーク名で自動ルーティング」という簡便さがなく、対話分岐という頻出パターンのたびにDSLとLuaの往復が発生している。

## Current State
- **`\q[...]`直書き**: さくらスクリプトはDSLからそのままパススルー出力されるため、`\q[表示,ID]`を手書きすれば選択肢表示は可能
- **`＞`Call文**: シーンジャンプ（4段階優先順位＋前方一致検索）は実装済み（`act-impl-call`完了）
- **`!cue`コマンド**: `!command(args)`形式のキューコマンドはDSLパーサーで汎用的にパース可能（`pasta-cue-dsl-extension`完了）
- **OnChoiceSelectEx**: SHIORI DLLでイベントは受信可能だが、選択IDからシーンへの自動ルーティング機構は存在しない
- **`\![*]`メニューマーク**: 選択肢行への自動挿入は非対応（手動記述のみ）

## Desired Outcome
Pasta DSL内で`＠？`マーカーを使い、選択肢を宣言的に定義できる。トランスパイラが`\![*]\q[表示テキスト,選択ID]`を自動生成し、ランタイムが`OnChoiceSelectEx`受信時に選択IDと同名のシーンを前方一致検索して自動実行する。

## Approach
**＠？ 選択肢マーカー方式** — 既存の`＠`（単語マーカー）に`？`修飾子を追加し、選択肢専用行を導入する。

### 構文

```pasta
＠？target                ＃ 省略形: 表示テキスト = target名
＠？target「表示テキスト」  ＃ 括弧形: カスタム表示テキスト
```

### 使用例

```pasta
＊メニュー
  Alice：何をしましょうか？
  ＠？お茶                    ＃ → \![*]\q[お茶,お茶]
  ＠？散歩「散歩しに行く」      ＃ → \![*]\q[散歩しに行く,散歩]
  !select(30)                  ＃ 30秒タイムアウト

＊お茶                         ＃ 選択時に自動ルーティング
  Alice：ほうじ茶を淹れますね。

＊散歩
  Alice：いい天気ですからね。
```

### 選定理由
- **既存マーカー体系との調和**: `＠`（単語）`＄`（変数）`＞`（Call）`！`（キュー）に続く自然な拡張
- **`＠key：value`パターンの延長線上**: ただしコロン形式は不採用。選択肢は「1つの表示テキスト」のみを持ち、単語定義の「複数値リスト」とはセマンティクスが異なるため
- **`「」`括弧引用の再利用**: 空白を含む表示テキストにはPasta既存のリテラル引用構文をそのまま活用
- **省略形の直感性**: `＠？お茶` だけで「お茶」という選択肢が定義でき、クリック時に`＊お茶`シーンが実行される

### 自動ルーティング機構
1. ユーザーが選択肢をクリック → SSPが`OnChoiceSelectEx`を送信（Reference0=表示テキスト, Reference1=選択ID）
2. Luaランタイムが`OnChoiceSelectEx`を受信
3. 選択IDをシーン名として前方一致検索（既存の`ACT_IMPL.call`/`SCENE.search`を再利用）
4. マッチしたシーンを自動実行（複数候補時はシャッフル＆順次消費で選択）
5. マッチなし → フォールバック動作（無視 or デフォルトシーン、要設計判断）

## Scope
- **In**:
  - `＠？target` / `＠？target「displaytext」` DSL構文の文法定義（Pest PEG拡張）
  - AST拡張（`ChoiceDefinition`ノード型 — target識別子 + オプション表示テキスト）
  - トランスパイラ拡張（`＠？` → `\![*]\q[displaytext,target]` Lua文字列生成）
  - `OnChoiceSelectEx`イベントの自動ルーティングLuaハンドラ
  - `!select(timeout)` キューコマンドのトランスパイル対応（タイムアウト付き選択待ち）
  - `\![*]`メニューマーク自動挿入（`＠？`行ごとに先頭付与）
  - サンプルゴーストへの選択肢デモ追加
  - テスト（パーサー・トランスパイラ・ランタイム統合テスト）
- **Out**:
  - 条件付き選択肢表示（`＠？target if condition`）— 将来拡張
  - 選択肢のスタイリング（色、フォント等）— areka層の責務
  - 入れ子選択肢（選択肢内選択肢）— 複雑性が高く初期スコープ外
  - `＞`Call文の条件分岐拡張 — 別spec
  - コロン形式（`＠？target：displaytext`）— 不採用（単語定義の複数値セマンティクスとの混同回避）
  - LSP対応（選択肢マーカーの補完・ジャンプ先候補表示）— 別spec
  - OnChoiceSelect（Ex無し）の対応 — OnChoiceSelectExのみ対応

## Boundary Candidates
- Pest文法 + AST拡張（パーサー層: pasta_dsl）
- トランスパイラのコード生成（Lua生成層: pasta_lua）
- OnChoiceSelectEx自動ルーティング（Luaランタイム層: pasta_lua）
- `!select(timeout)`トランスパイル（Lua生成層: pasta_lua）
- サンプルゴースト辞書（pasta_sample_ghost）
