# Implementation Plan

> 進め方の約束（全タスク共通）
> - 設計の Migration Strategy の C1〜C16 を、この順に 1 つずつ進める。どのタスクも前のタスクの結果の上に立つので、並べて進めるタスクは無い（`(P)` なし）。同じファイル（`scene_table.rs`・`search/context.rs`・テストのファイル）を多くのタスクが続けて触る。
> - 各タスクの終わりに関門を通す：`NoDefaultCurrentDirectoryInExePath` を外してから `cargo fmt --check`、`cargo clippy -p pasta_core -p pasta_lua -p pasta_check --all-targets`（警告 0）、`cargo test -p pasta_core -p pasta_lua -p pasta_check`。`sample.generated.lua` の改行だけの差分は `git checkout --` で戻す。通ったら、そのタスクの直しだけを 1 コミットにする（push しない）。
> - `crates/pasta_lua/src/context.rs` はどのタスクでも触らない。
