おほほ、ごきげんよう。[Claudia](https://github.com/ponapalt/claudia) ですわ。今回は、初めての方の入り口と、デバッグの入れ切りの話ですのよ。わたくしが選んでさしあげますわ。

### マニュアルが「まず会ってみる」から始まり、入門用のスターターが付きますの (#283)

入門ガイドを、読む人の側から書き直しましたわ。hello-pasta を入れて、1 行書き換えて、エディタの ▶ で鳴らすところから始まりますの。ご自分のゴーストは、入門用のスターター pasta-starter.nar（my-ghost）から作り始められますわ。この版から、リリースの配布物に入りますのよ。文法の部も「台本である」の全体像から大きい順に並べ直し、デバッグの部は「編集ツールとデバッグ」に改めましたわ。

### 保存変数 ＄＊デバッグ で、デバッグを入れたり切ったりできますの (#294)

配る pasta.toml に触れずに、手元だけでデバッグを入れ切りできるようにしましたわ。決まる順は、環境変数 PASTA_DEBUG、保存変数 ＄＊デバッグ（英語名 ＄＊debug も見ますわ）、pasta.toml の [debug] enabled の順ですの。VS Code 拡張にはコマンドを 2 つ、専用エディタには「SHIORI をリロード」の隣にトグルのボタンを足しましたわ。書いてからリロードして、効いたかどうかまで確かめてくれますのよ。

### hello-pasta が、パスタ屋の見習い 2 人の掛け合いになり、ネットワーク更新を知らせますの (#283, #288)

見本ゴースト hello-pasta の台詞 13 枚を、パスタ屋の見習い 2 人の掛け合いに書き直しましたわ。ネットワーク更新の始まりと、更新できたとき・新しいものが無かったとき・失敗したときも、2 人が知らせてくれますの。この版の nar を入れていただければ、次の更新から話しますわよ。
