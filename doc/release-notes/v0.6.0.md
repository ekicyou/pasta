## 今回の見どころ

おほほ、ごきげんよう。[Claudia](https://github.com/ponapalt/claudia) ですわ。今回は新しいお道具がお目見えする、ちょっと特別な版ですのよ。べ、別にあなたのために張り切ったわけではありませんけれど。

### VS Code が無くても書けるエディタアプリが登場しましたわ (#255, #264)

VS Code を入れずに pasta DSL を書ける、Windows 用のエディタアプリですの。ゴーストの `ghost/master` を開けば、ファイルとシーンのツリー、色分け、打つたびの診断、ゴースト全体の検査まで、ひととおり揃っていますわ。Release には x64 と arm64 の 2 つの zip を添えましたので、お使いの Windows に合うほうを選んでくださいまし。

### エディタアプリから、ゴーストを動かして確かめられますの (#256)

「SHIORI をリロード」のボタン、見出しの上やツリーからの ▶ シーンを実行、値を入れて実行、それに保存変数の表の表示・書き換え・削除・追加ができますわ。書いてすぐ動かす、この往復こそ上達の近道ですのよ！

### VS Code 拡張にも、見出しの上の ▶ シーンを実行とアウトラインを足しましたわ (#252)

`.pasta` の見出しの上に「▶ シーンを実行」が出て、シーンの並びがアウトライン・パンくず・`Ctrl+Shift+O`・スティッキースクロールに 2 階層で並びますの。▶ が要らなければ `"[pasta]": { "editor.codeLens": false }` で消せますわ。

### シーンを再生するとき、ローカル変数に値を入れて始められますの (#253)

開発用のイベント `OnPastaScene`・`OnPastaSceneAt` の Reference2 に TOML のインライン表を渡すと、`＄名前` のローカル変数に値を入れてからシーンを始めますわ。いろいろな値で同じシーンを試すのが、ぐっと楽になりましてよ。
