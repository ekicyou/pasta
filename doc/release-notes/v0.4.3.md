## 今回の見どころ

おほほ、ごきげんよう。[Claudia](https://github.com/ponapalt/claudia) ですわ。0.4.3 は、セーブファイルの大きな不始末を正し、Lua の土台を新しくし、右クリックメニューまで辞書で書けるようにした版ですの。最初に、大事なお詫びからお読みあそばせ。

### セーブファイルが TOML になりましたの（セーブは引き継がれません） (#200)

pasta の決まりは TOML ですのに、これまでセーブを JSON で書いておりましたの。0.4.3 から、`＄＊` の値や `@pasta_persistence` のセーブは `profile/pasta/save/save.toml`（`obfuscate = true` なら gzip した `save.dat`）に TOML で書きますわ。これまでの `save.json`・`save.dat` は読み込みませんから、セーブは引き継がれません。ごめんなさい。古い `save.json` は消さずに残しておりますし、`obfuscate = true` の古い `save.dat` は `save.dat.broken` という名前で残しておりますのよ。あわせて、`@pasta_log` に渡した表も TOML の書き方で 1 行に出るようになりましたわ。

### おすすめメニューを、辞書のシーンで書けますの (#201)

右クリックメニューの「おすすめ」「相方おすすめ」「ポータル」を、`＊おすすめメニュー`・`＊相方おすすめメニュー`・`＊ポータルメニュー` のシーンに `＞おすすめ項目（名前、URL、シーン、バナー）` を並べるだけで作れますわ。同じ名前のシーンをいくつも書けば、開くたびにランダムに選ばれますの。ボタンの名前は `＠おすすめボタン名` などの単語で決められますし、選ばれたら指定のシーンが話しますのよ。Lua は一行も要りませんわ。

### Lua の土台を mlua 0.12 に上げ、`@toml` を足しましたの (#204)

pasta の Lua ランタイムの土台を新しい版にしましたわ。今まで動いていた辞書と `scripts/` の Lua は、前と同じ結果になりますの。あわせて、TOML の文字列を Lua の表に読む `@toml` の `decode` を、いつでも使えるようにいたしましたわ。

### Linux・macOS でも、pasta.dll のエンジンが動きますの (#206)

shiori4 の SHIORI3 互換モード（`shiori_get_api(3)`）を書き出し、Windows 以外でもビルドとテストが通るようになりましたわ。SSP で使う今の入口はそのまま残しておりますのよ。

### `pasta_check release` が、作者のフォルダを消さなくなりましたの (#198)

`--release` と `--copy` の先が重なるような危ない引数の組み合わせは、何かに触れる前にお断りいたしますわ。読めないファイルがあれば、`updates.txt` も nar も作らずに止まりますの。誤りの文には、どのファイルかのパスも添えましてよ。

### ご注意あそばせ — 動きが変わる点

- セーブは `save.toml`（`obfuscate = true` なら `save.dat`）に TOML で書きます。0.4.2 までの `save.json`・`save.dat` は読み込まず、セーブは引き継がれません。TOML として読めないセーブは `.broken` に移して、空から始めます。 (#200)
- TOML で書けない値（関数・循環する表など）はそのキーだけを外して警告し、ほかのキーは保存します。 (#200)
- `@pasta_log` に渡した表は、TOML の値の書き方で 1 行に出ます。ソースマップのサイドカー `<lua>.map` も TOML になります。 (#200)
- Rust の公開 API では、`persistence::load_from_file`・`save_to_file` が `toml::Table` を使い、`PersistenceError::JsonError` は `TomlParseError`・`TomlWriteError` に替わり、`SaveDisabled` が増えます。 (#200)
- シーン名の別名の既定に、おすすめメニューのシーン 3 つとボタンの名前の単語 3 つが加わります。`[scene.alias]` は、書いたキーだけ既定を置き換えます（空の配列で既定を消す・見出しだけなら既定のまま・既定とぶつかれば読み込みエラー）。 (#201)
- `@assertions`・`@testing`・`@env`・`@regex`・`@json`・`@yaml` の 6 つのモジュールを外しました。`require` すると失敗します。TOML は `@toml` の `decode`、文字列は Lua 標準の `string` の関数で扱います。
- `OnPastaSetSaveVariable` は値を JSON として読まず、Reference1 の文字列を Reference2 の型（`string`・`number`・`boolean`・`delete`。省けば `string`）で読みます。失敗の種類 `NOT_JSON` は `BAD_TYPE` になります。
- Rust の公開 API では、`RuntimeConfig` から 6 つのモジュールの名前と `should_enable_module` が無くなります。
- `pasta_lua::mlua` は mlua 0.12 になります（`mlua::Debug` は `mlua::debug::Debug`、`mlua::String` は `mlua::LuaString`）。 (#204)
- 同梱の LuaJIT が新しくなり、`continue`・`!=`・`<<` など、Lua 5.1 に無い書き方の一部を構文の誤りにしなくなります。今まで動いていた書き方の結果は変わりません。 (#204)
- `os.time` は、結果がちょうど `-1` になる時刻で `nil` でなく `-1` を返します。 (#204)
- x86 の pasta.dll で、32 ビットに収まらない整数をセーブに書くと、x64 と同じく整数として書きます（`3000000000.0` でなく `3000000000`）。 (#204)
