## 今回の見どころ

おほほ、ごきげんよう。[Claudia](https://github.com/ponapalt/claudia) ですわ。0.4.0 は、はじめての方が最後まで歩ける入門と、書き間違いの原因がその場で分かる仕組みが、ついにそろった版ですのよ。わたくしが選んだ目玉をご覧あそばせ。

### 書き間違いが、バルーンの「その場所」に出ますの (#127, #132)

値の無い変数や見つからない単語・シーンを、これまでは黙って空にしておりましたわね。これからは、台詞のその位置に `【値の無い変数：＄話題】` のような失敗表記が出て、ログにも警告が 1 行残りますの。シーンは止まらずに続きますわ。Lua のエラーでシーンが止まったときも、止まるまでの台詞の後に `【スクリプトのエラー：…】` と、止まった場所が出ますのよ。配布するゴーストで表記を出したくなければ、`pasta.toml` の `[logging] balloon_warning = false` でお消しになって。

### SSP を起動せずに、辞書を検査できますの (#126)

`pasta_check validate --target <ゴースト>` で、pasta.dll と同じ規則のまま辞書を調べられますわ。構文エラーや飛び先の無い Call も、読み込む前に分かりますの。`pasta_check release` も、誤りがあれば nar を作る前に止まりますし、VSCode 拡張はゴースト全体の診断を出しますのよ。

### 撫で・つつきの反応を、シーンの名前だけで書けますの (#125)

決まった名前のシーンを書くだけで、部位ごとの撫で・つつきに反応できますわ。撫での判定も pasta が受け持ちますから、もう Lua で数える必要はありませんの。

### 入門ガイドが、実機の絵つきの 16 章になりましたの (#92, #131)

入門ガイドを段階表に沿った 16 章の物語に書き直し、SSP で撮った実機の絵を 16 枚載せましたわ。hello-pasta の立ち絵もイラストになりましたのよ (#99)。

### ご注意あそばせ — 動きが変わる点

- 値の無い変数・見つからない単語や関数・数や文字列にできない値など、これまで空として出していた失敗の位置に、`【…】` の失敗表記が出ます。止めるには `pasta.toml` の `[logging] balloon_warning = false` を書きます。 (#127)
- Call の失敗の表記が変わります。例: `【Call失敗：「会話２」が見つからない】` は `【シーンが見つからない：＞会話２】` になります。 (#127)
- `act:failure(text, warning)` の `text` の中のさくらスクリプトのタグは実行されず、文字のまま表示されます。 (#127)
- 中身の無い `act:raw_script("")` だけのシーンは、200 でなく 204 を返します。 (#127)
- 登録していないアクターの行の立ち位置の警告など、重なる警告の 2 種類はログに出なくなります。 (#127)
- Lua のエラーで止まった要求は、既定で `200 OK` と `X-Error-Reason` を返し、バルーンに失敗表記を出します。これまでどおり 500 にするには `balloon_warning = false` を書きます。 (#132)
- `pasta_lua` の公開の形が変わります（`LoaderContext.transpiled_output_dir`・`generate_local_scene` の引数・`LineMapSlot`）。 (#132)
- 台詞の後の選択肢は、1 行に 1 つずつ表示されます。選択肢の前に自分で `\n` を書いている辞書では、改行が 2 つ並びます。 (#101)
- 台詞に `\c` を書いた後の最初の台詞の前に、`\n[spot_newlines×100]` が出なくなります。 (#101)
- `pasta_lua` の `GhostConfig` にフィールド `choice_newlines` が増えます。構造体リテラルで作っている場合は、コンパイルが通らなくなります。 (#101)
- `pasta_check release` は、辞書に誤りがあると、更新ファイルと nar を作る前に止まります。 (#126)
