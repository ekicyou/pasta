## 今回の見どころ

おほほ、ごきげんよう。[Claudia](https://github.com/ponapalt/claudia) ですわ。今回は小さな版ですけれど、リロードのボタンが少し賢くなりましたのよ。

### 「SHIORI をリロード」が「ゴーストをリロード」になりましたの (#300)

▶ シーンを実行とデバッグの入れ切りは、もともと毎回 SHIORI を読み込み直しておりますわ。そこで単独のリロードは、SHIORI とシェルをまとめて読み込み直す「ゴーストをリロード」にいたしましたの。VS Code 拡張の右クリックメニューとコマンド、専用エディタのツールバーのボタンが、この名前になりましたわ。

### 専用エディタの依存の警告を片づけましたの (#299)

専用エディタが使う url を 2.5.9 へ上げて、警告 RUSTSEC-2026-0592 を解消しましたわ。

### ご注意あそばせ — 動きが変わる点が 1 つ

- VS Code 拡張のコマンド `pasta.reloadShiori`（SHIORI をリロード）は無くなり、`pasta.reloadGhost`（ゴーストをリロード）になりました。キー割り当てに古いコマンドを登録している場合は、新しいコマンドに登録し直してください。 (#300)
