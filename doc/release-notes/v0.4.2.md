## 今回の見どころ

おほほ、ごきげんよう。[Claudia](https://github.com/ponapalt/claudia) ですわ。0.4.2 は、自動トークの手綱を作者の手に渡し、外からゴーストを動かす口を開き、配布物まで増やした、たいへん実りの多い版ですのよ。わたくしが選んだ目玉をご覧あそばせ。

### シーンから、自動トークを止めたり再開したりできますの (#170)

`＞自動トーク停止` と書くだけで、ランダムトーク・時報・止まっているシーンの続き・つつき・撫でが静かになりますわ。`＞自動トーク再開` で元どおり。止めている間に過ぎた時報をまとめて出すような無粋はいたしませんし、待っている続きも捨てませんのよ。Lua からも同じ関数で呼べますわ。

### MCP などの外から、シーンの再生も呼び出しも変数の代入もできますの (#171, #174)

`OnPastaScene` に名前を、`OnPastaSceneAt` にファイルと行を渡せば、そのシーンを再生いたしますわ（デバッグを有効にしたときだけですの）。`OnPastaCallFunction` は辞書の `＞名前` と同じ探し方で呼び出し、`OnPastaSetSaveVariable` は JSON の値を `＄＊名前` に代入いたしますのよ。SSP の MCP の `raise_event` から、書いたトークをすぐに確かめられますわ。

### 1 つのイベントに、ハンドラを重ねて登録できますの (#176)

`REG:register(id, fn)` で、同じイベントにいくつでもハンドラを重ねられますわ。新しい順に呼び、真を返したところで止まり、全部見送れば今までどおり `REG` の値か同じ名前のシーンが動きますの。登録は外す関数を返しますから、後片付けも優雅にできましてよ。

### チェイントークの続きが、台詞の無いイベントで消えませんの (#177)

表情だけを変えるイベントや何も言わない `＊OnMouseMove` が、待っている続きを消してしまう不具合を直しましたわ。台詞を出して割り込んだときに `＊チェイントーク中断` を書いておけば、反応の代わりにその台詞を出しますのよ。

### pasta_check と、AI 向けのスキルを、Release から落とせますの (#169, #183)

Rust を入れていなくても、`pasta_check.zip` を落とせば辞書の検査とゴーストのリリースができますわ。さらに `pasta-skills.zip` には、ゴーストを書くためのスキル 3 本を詰めましたの。AI にゴーストを書かせるときの置き場所は、マニュアルの「はじめに」に書いてありましてよ。

### ご注意あそばせ — 動きが変わる点

- 台詞の自動ウェイトと budoux の改行を、見た目の 1 文字（書記素クラスタ）ごとに入れます。絵文字や結合文字の途中には入らなくなり、半角カナの濁点・半濁点つき（`ｶﾞ` など）は 1 文字として数えます。台詞にそのまま入った CRLF のウェイトは 1 つになります。 (#175)
- Rust の公開 API では、`CharSets` の各フィールドが `HashSet<String>` になり、`CharSets::classify` は `&str` を取ります。`insert_waits` は 1 トークンにウェイトを 1 つ入れます。Lua からの呼び方は変わりません。 (#175)
- チェイントークの続きを捨てるのは、台詞を出した割り込み・キックやシーンの指名再生・エラーのときだけになります。表情だけのイベントや何も出さないシーンは、続きを残します。 (#177)
- 台詞を出して割り込んだイベントは、`＊チェイントーク中断` があれば、そのシーンの台詞に差し替わります。 (#177)
