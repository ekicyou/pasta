# 撮影の手順の記録

## この文書の役目

- 入門ガイドの 16 枚の絵（`book/src/img/getting-started/`）を、同じ手順で撮り直せるようにする記録である。
- 撮影は手作業で行う。自動検査の中で絵を撮る・撮り直す仕組みは置かない。撮影のスクリプトも置かない（ffmpeg の 1 行とプロパティの読み方は本文に書く）。
- 絵を章に置く決まりは、執筆規約（[AUTHORING.md](AUTHORING.md) 第 8 節の「画像の行」）にある。
- この文書は `book/src/` の外に置く。mdBook のビルドとリンク検査の対象には入らない。

## 準備

- 作業用の複製: `crates/pasta_sample_ghost/ghosts/hello-pasta/` をリポジトリの外の `<作業フォルダ>` へ複製し、`ghost/master/descript.txt` の `name` を変える（例 `hello-pasta-shot`）。SSP に入っている同じ名前のゴーストとぶつかるためである。名前は画面に写らない。
- 起動: `ssp.exe --ghost <複製の絶対パス>` で起動する。
- 段の辞書: 段 N を撮るときは、複製の `ghost/master/dic/` を `01-boot.pasta`〜N 段目のファイルだけにして、ゴーストを読み込み直す（MCP の `reload`）。
- 画面の倍率: 立ち絵が 1:1 で出ること（`currentghost.scope(0).rect` の幅が 333、高さが 500）。外れたら、SSP の側の拡大率（右クリックメニューの「シェル倍率」「バルーン倍率」）を変えて合わせ、立ち絵と吹き出しの配置を調整し直す。Windows の表示の拡大は変えない。合わせた拡大率は「撮る環境」に書く。Windows の倍率が 200% だと、SSP は両方 200% で始まるので、両方 100% にする。この設定は複製の `profile/ghost.dat` に入る。
- バルーン: SSP の既定の `ssp`（「SSPデフォルト+」）を使う。読者が SSP を入れたときと同じである。
- 背景: ゴーストの後ろに、無地の白の全画面の窓を置く（例: ブラウザーで空のページを全画面表示。マニュアルの明るいテーマの地と同じ色。今回は、別のプロファイルの Edge をキオスクの全画面で主画面に開き、白の HTML を表示した）。吹き出しの縁が白に溶けて見えにくいときだけ、薄い灰色にする。
- 写す前に、ゴーストと吹き出しが手前にあることと、開発用パレットなどのほかの窓が範囲に入っていないことを確かめる。
- 位置: 画面の縁には、デスクトップ操作の間だけ色付きの光が出るので、2 人を画面の中ほどへ動かす（`sakurascript` で `\![set,alignmenttodesktop,free]` と `\![move]`）。今回は女の子の左・上を 1500,800、男の子を 1240,800 にした。試し撮りで決めた位置から立ち絵を動かさない（ドラッグしない）。SSP を起動し直すと立ち絵が画面の下に戻るので、毎回同じ位置へ動かし直し、範囲を読み直して同じであることを確かめる。

## 範囲の決め方

- 2 人が話した直後（吹き出しが 2 つとも出ている間）に、MCP の `get_property` で次の 4 つを読む。
  - `currentghost.scope(0).rect`
  - `currentghost.scope(1).rect`
  - `currentghost.balloon.scope(0).rect`
  - `currentghost.balloon.scope(1).rect`
- 範囲は次のとおりに決める。

  | 辺 | 決め方 |
  | -- | -- |
  | 左 | 4 つの左の最小 − 8 |
  | 上 | 4 つの上の最小 − 8 |
  | 右 | 4 つの右の最大 + 8 |
  | 下 | 立ち絵の下（タスクバーを入れない） |

- 幅は 900 px までにする。本文の幅 750 px に縮めて表示しても、吹き出しの文字が 10 px 以上残るためである。
- 超えたら、男の子を女の子に寄せて（読者のドラッグと同じ操作）読み直す。それでも超えたら、開発者に報告する。
- ffmpeg の `-offset_x`・`-offset_y` は主画面の左上が原点である。2 台目の画面が左にあっても、その幅を足さない。
- 16 枚とも同じ範囲で写す。

## 写し方

台詞を出す直前に、次の 1 行で連番を写し始め、話し終わってから止める。

```text
"C:\Program Files\ShareX\ffmpeg.exe" -hide_banner -f gdigrab -framerate 10 -draw_mouse 0 -offset_x <左> -offset_y <上> -video_size <幅>x<高さ> -i desktop -t 30 -pix_fmt rgb24 <作業フォルダ>\%03d.png
```

- 連番から「写す瞬間」の 1 枚を選び、名前を変えて `book/src/img/getting-started/` に写す。
- 選んだ 1 枚は加工しない（切り抜き直し・減色・縮小・合成をしない）。
- `-t`（秒）は待つ長さに合わせる。外から起こす絵は 30、自然なおしゃべりや正時を待つ絵は、待ち始めから 120 などにする。
- 写した後の連番は、選んだ 1 枚を除いて消す。
- 吹き出しは話し終わった後もしばらく残る。話し終わった直後に、同じ範囲を 1 枚だけ写してもよい（上の 1 行の `-t` の代わりに `-frames:v 1` を付け、出力を 1 つのファイル名にする）。
- `-draw_mouse 0` で、マウスのカーソルを写さない。
- `-pix_fmt rgb24` で、透過の無い PNG にする（可逆）。

## 狙った台詞を出す方法

- 台詞のきっかけ: MCP の `sakurascript` で `\![raise,イベント名,Reference0,…]` を送る（7 段目でも、読者が同じさくらスクリプトをスクリプト入力で使う）。
- 最初の試し撮りを関門にして、`sakurascript` の raise と `raise_event` の両方を試し、送り主の表示が出ないほうを使う。両方とも出るなら、起動・自然なおしゃべり・実際のマウスで出す方法に切り替え、作業時間が延びることを開発者に報告する。
- 同じ名前のシーンは、一巡するまで同じものが出ない。狙った掛け合いが出るまで、同じきっかけを繰り返す（最大で、その名前のシーンの数の回数）。
- 表示される台詞を書き換える方法は使わない。
- 6 段目は、開発用パレットの「現在時刻の仮想的変更」で、撮りたい時の 59 分 30 秒を入れて Apply し、仮想の正時に出る時報を写す（読者と同じ手順。実際の正時を待ってもよい）。撮り終えたら Reset する。
- 11 段目は、寄り道も続きも自然なおしゃべりを待つ。寄り道の後に外から起こしたおしゃべりが挟まると、続きが出ない。台詞が出たかは、複製の `pasta.log` で見張る。
- 10 段目の数は保存された値に左右される。複製の `profile/pasta/save/` を消してから始め（`profile/` ごと消すと、`profile/ghost.dat` の拡大率も消える）、数が「1回目」のうちに SSP を終了して起動し直す。
- 8 段目の触る場所: 女の子の `Head` は頬の横の髪、`Face` は顔の真ん中である。
- 8 段目のつつき: 実際のマウスでダブルクリックする。
- 8 段目の撫で: 話し終わってから、同じ所の上でボタンを押さずに 2 秒以上ゆっくり動かす。2 秒たった後の最初の動きで 1 回だけ反応し、トーク中は反応しない。
- 9 段目の辞書では、女の子の体のつつきは、8 段目の `その他` と選択肢が一緒に抽選される（2 つで一巡）。

## 写す前の確かめ

次のどれかが外れたら、その絵を章に載せず、開発者に報告する。

- 台詞が、章の成功の目印と一字一句同じである。
- 表情が、辞書のとおりである。
- 送り主の表示が写っていない。
- 開発用パレット・エラーの表示・ほかのゴースト・デスクトップ・タスクバー・カーソルが写っていない。
- 吹き出しが顔にかかっていない。
- 1 枚が 1 MB を超えていない。

## 後片付け

撮影の作業は SSP の設定にものを残す。作業の前に値を控え、終わったら次のとおりに戻す。

| SSP に残るもの | 戻し方 |
| -- | -- |
| `data/profile/app.dat` の `Ghost.0` が作業用の複製を指す | 作業の前に `Ghost.0` を控える。終わったら、メニューからそのゴーストに切り替えてから SSP を終了する（終了のときに書き戻される） |
| 準備の章の確かめで `ghost/` の下に置いたフォルダ | フォルダを消す |
| 本体設定の「開発者用機能を有効にする」・「フォルダをドロップした際に更新ファイルやNARを作成」 | 作業の前の値に戻す |
| 開発用パレットの「`\-` タグで終了しない」 | OFF に戻す（設定はゴーストごと） |
| SSP の拡大率（シェル・バルーン）と立ち絵の位置（変えたとき） | 複製の `profile/ghost.dat` に入るので、複製を消せば戻る。立ち絵の位置（`\![move]`）はゴーストの終了まで |
| 作業用の複製と連番のフォルダ | 消す（リポジトリの外） |

## 撮り直す決まり

- 段の辞書・シェルの絵・吹き出しの位置・既定の起動の見え方を変えて画面が変わるときは、影響する絵を撮り直す。
- 同じ変更で撮れないときは、`.kiro/steering/roadmap.md` の「人手の確認が残っている項目」に、撮り直しが要る絵（ファイル名）と理由を足し、後で撮る。台詞と辞書を機械で照合する検査は置かない。
- 影響を受ける絵は、変えたものによって決まる。

  | 変えたもの | 撮り直す絵 |
  | -- | -- |
  | 段 N の辞書 | 段 N 以降の辞書で撮った絵（一覧の「辞書」の列で決める） |
  | シェル・`descript.txt`・バルーン | 16 枚すべて |

- 撮り直したら、「撮る環境」の表を書き換える。
