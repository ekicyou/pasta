# VS Code で書く

> 【むらさき】拡張ひとつ入れるだけで、いつもの VS Code が辞書書きの道具になるんやて。

> 【エモ：静観】番号を合わせたり、設定を書いたりは？

> 【むらさき：笑顔】いらんいらん！ うちらが動いとる SSP は、拡張が自分で見つけてくれるねん。

---

## 3 手で最初の ▶

1. **入れる** — VS Code の拡張機能（`Ctrl+Shift+X`）で「Pasta DSL」を検索し、発行元が `ekicyou` の拡張の「インストール」を押す。
2. **開く** — SSP でゴーストを起動し、VS Code でそのゴーストのフォルダを開いて、`ghost/master/dic` の `.pasta` を開く。
3. **鳴らす** — シーンの見出しの上に出る「▶ シーンを実行」を押す。

- 成功の目印: ゴーストがそのシーンをしゃべり、出力のパネル「Pasta 開発」に `スクリプト:` と、しゃべった中身が出る。
- 拡張に、送り先を指定する設定は無い。編集中の `.pasta` のゴーストが動いている SSP（か areka）を、拡張が見つけて送る。

> 【エモ】▶ を押されたらしいけど、僕たちの所まで届いてないよ。

> 【むらさき：不安】それ、合言葉を書き忘れとるやつや‥‥。

▶ は、デバッグを有効にしたゴーストでだけ働く。ゴーストの `ghost/master/pasta.toml` に次の 2 行を書き足してから、▶ を押す（保存と読み込み直しは ▶ が行う）。

```toml
[debug]
enabled = true
```

## 拡張がしてくれること

| 機能 | 中身 |
| ---- | ---- |
| 色分け | `.pasta` に色が付く |
| 書きながらの診断 | 書き間違いに波線が付き、「問題」のパネルに並ぶ |
| ゴースト全体の診断 | 保存のたびに、ゴースト全体を [`pasta_check validate`](./validate.md#エディタの診断) と同じ規則で検査する |
| 3 つのコマンド | ▶ シーンを実行・SHIORI をリロード・保存変数を表示 |
| シーンの並び | アウトラインやパンくずに、シーンが並ぶ |

## 3 つのコマンドの出る場所

| コマンド | 見出しの上 | 右クリックのメニュー | コマンドパレット（分類 `Pasta`） |
| -------- | ---------- | -------------------- | -------------------------------- |
| ▶ シーンを実行 | 出る | `.pasta` で出る | 出る |
| SHIORI をリロード | — | `.pasta`・`.lua`・`pasta.toml` で出る | 出る |
| 保存変数を表示 | — | `.pasta`・`.lua`・`pasta.toml` で出る | 出る |

- 見出しの上の ▶ は、その見出しのシーンを鳴らす。右クリックのメニューとコマンドパレットの ▶ は、カーソルの行のシーンを鳴らす。
- 見出しの上に ▶ が出ないときも、右クリックのメニューとコマンドパレットからは選べる。
- 結果は、出力のパネル「Pasta 開発」に時刻の順に積まれる。止まったときは通知でも知らせる。
- それぞれが何をして、何を返すかは、[▶・リロード・保存変数](./dev-actions.md) にある。

### 見出しの上の ▶ を消す

`settings.json` に次を書くと、`.pasta` のエディタで見出しの上の ▶ が出なくなる。

```json
{
    "[pasta]": {
        "editor.codeLens": false
    }
}
```

### シーンの並び（アウトライン）

`.pasta` のシーンの並びは、VS Code の次の場所に出る。

- エクスプローラーの「アウトライン」
- エディタの上のパンくず
- `Ctrl+Shift+O`
- スティッキースクロール

並びは グローバルシーン ＞ ローカルシーン の 2 階層である。続きのグローバルシーン（`＊` だけの行）は、前のグローバルシーンと同じ名前の、別の項目として並ぶ。項目を選ぶと、そのシーンの見出しへ移る。

## Marketplace を使えないとき

[ダウンロード](../download.md#vs-code-の拡張) のページから辿れる最新のリリースの Assets に、`pasta-vscode-<版>.vsix` がある。拡張機能のビューの右上のメニューから「VSIX からのインストール…」を選んで、このファイルを指定する。
