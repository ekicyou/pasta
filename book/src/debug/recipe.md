## 3 手で最初の ▶

1. **入れる** — [ダウンロード](../download.md#pasta-recipe) のページから `pasta-recipe.x64.zip` を落として、好きなフォルダに展開する。
2. **開く** — SSP でゴーストを起動し、そのゴーストのフォルダを `pasta-recipe.exe` の上へドロップする。
3. **鳴らす** — 左のツリーでシーンを押し、エディタの見出しの上に出る「▶ シーンを実行」を押す。

- 成功の目印: ゴーストがそのシーンをしゃべり、下の欄の「出力」に `スクリプト:` と、しゃべった中身が出る。
- ARM の PC では `pasta-recipe.arm64.zip` を使う。
- 初めての起動で「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押す。

> 【エモ】▶ を押されたらしいけど、僕たち何も聞いてないよ。

> 【むらさき：不安】あ、合言葉がまだなんや‥‥。`pasta.toml` に 2 行だけ書き足してもろて！

▶ は、デバッグを有効にしたゴーストでだけ働く。ツリーの `pasta.toml` を開き、次の 2 行を書き足してから ▶ を押す（保存と読み込み直しは ▶ が行う）。

```toml
[debug]
enabled = true
```

## デモ：書いて、鳴らして、直す

書いて、鳴らして、直す流れの、約 1 分の画面録画（音声なし）である。動画の見出しは次の番号と同じである。

1. ▶ シーンを実行：動いているゴーストで、その場で鳴らす。
2. 書き換えて ▶ シーンを実行：台詞を直して、もう一度鳴らす。
3. 値を入れて実行…：値を渡して鳴らす。
4. SHIORI をリロード：保存して読み込み直す。
5. 保存変数を表示・書き換え…：保存変数の値を直す。
6. もう一度 ▶ シーンを実行：直した値で鳴る。

## 画面

| 場所 | 出るもの |
| ---- | -------- |
| 左 | ファイルとシーンのツリー |
| 右 | タブで開いたエディタ |
| 上 | ツールバー（開く・保存・SHIORI をリロード） |
| 下「診断・検査」 | 書き間違いの一覧と、ゴースト全体の検査の一覧 |
| 下「出力・保存変数」 | 保存変数の表と、▶ などの結果 |

欄の境はドラッグで動かせる。並びは次に開いたときにも残る。

## ゴーストを開く

pasta-recipe は、1 つの窓で 1 つのゴーストを開く。開き方は次のどれでもよい。

| 開き方 | 操作 |
| ------ | ---- |
| exe へドロップ | ゴーストのフォルダを `pasta-recipe.exe`（かそのショートカット）へドロップする |
| 窓へドロップ | ゴーストのフォルダを pasta-recipe の窓へドロップする |
| 選ぶ | 開始の画面の「フォルダを選ぶ…」「ファイルを選ぶ…」、ツールバーの「フォルダを開く…」「ファイルを開く… (Ctrl+O)」 |
| 最近開いたもの | 開始の画面かツールバーの「最近開いたもの」から選ぶ（新しい順に 10 件） |

渡すのは、ゴーストのフォルダでも、その中の `ghost`・`ghost/master`・辞書のファイルでもよい。どれを渡しても同じ `ghost/master` が開き、ファイルを渡したときはそのタブも開く。

```text
hello-pasta\                ← どれを渡してもよい
  ghost\
    master\
      dic\
        01-boot.pasta
```

- `.pasta` を pasta-recipe に関連付けると、ダブルクリックでそのゴーストが開く。「送る」に入れても開ける。
- pasta-recipe が動いている間に渡したゴーストは、新しい窓ではなく今の窓で開く。
- 未保存のファイルがあるときは、開き直す前に「保存する・保存しない・取り消す」を確かめる。
- `ghost/master` が見つからないときは理由を出し、開いているゴーストは変えない。

## 書く

> 【むらさき：笑顔】書き間違えても大丈夫やで。波線がその場で教えてくれるねん。

> 【エモ：冷笑】むらさきの台詞は、波線だらけになりそうだね。

- **色分け** — `.pasta` と、その中の Lua のコードブロック、`.lua` に色が付く。画面の明暗は Windows の設定に合う。
- **書きながらの診断** — 書き間違いに波線が付く。手を止めて 1 秒ほどで、書き換えた後の中身に合う。下の「診断・検査」の一覧の項目を押すと、その位置へ移る。
- **ゴースト全体の検査** — ゴーストを開いたときと、`.pasta`・`pasta.toml` を保存したときに、ゴースト全体を検査し直す。結果は [`pasta_check validate`](./validate.md) と同じである。
- **保存** — `Ctrl+S` で保存する。自動では保存しない。未保存のタブには `●` が付く。改行の種類と BOM の有無は、開いたときのまま変えない。
- **ほかのファイル** — `pasta.toml` などの UTF-8 のテキストも、色分けなしで開いて編集できる。

### ツリー

各 `.pasta` の下に、そのファイルのシーンが グローバルシーン（`＊`）＞ ローカルシーン（`・`）の 2 階層で並ぶ。シーンを押すと、その見出しへ移る。

行を右クリックする（か、行を選んで `Shift+F10`）と、メニューが出る。

| 行 | メニュー |
| -- | -------- |
| フォルダ | 新しいファイル・新しいフォルダ・名前の変更 |
| ファイル | 名前の変更（`F2` でもよい） |
| シーン | ▶ シーンを実行・値を入れて実行… |

ファイルとフォルダの削除は、エクスプローラーで行う。

### 外でファイルが変わったとき

- ファイルが増えた・消えた・名前が変わったときは、ツリーが追いつく。
- 開いているファイルが外で変わったときは、中身を読み直す。未保存の書き換えがあるときは、「読み直す」か「今の中身を残す」かを選ぶまで書き換えない。

## 鳴らす

| 操作 | 押す場所 | 保存 | 読み込み直し | デバッグ |
| ---- | -------- | ---- | ------------ | -------- |
| ▶ シーンを実行 | エディタの見出しの上・ツリーのシーンのメニュー | する | 毎回する | 要る |
| 値を入れて実行… | 同じ | する | 毎回する | 要る |
| SHIORI をリロード | ツールバー | する | する | 要らない |
| 保存変数を表示 | 保存変数の表の上 | しない | しない | 要る |
| 書き換え…・消す…・追加… | 保存変数の表 | しない | しない | 結果を表で見るには要る |

- 結果は、下の欄の「出力」に時刻の順に積まれる。前の結果は消えない。
- 止まったときと誤りは、行の頭に `誤り:`・`警告:` を付けて出る。
- 操作は一度に 1 つずつ進む。進んでいる間に次を始めると、「このゴーストへのコマンドが進んでいます」と出る。
- ▶・リロード・保存変数の表示が何をして、何を返すかは、[▶・リロード・保存変数](./dev-actions.md) にある。VS Code の拡張と同じ動きである。

### 値を入れて実行

> 【エモ】雨の日の台詞を確かめたいのに、今日は晴れだね。

> 【むらさき】ほな、雨にしてまえばええねん！ 「値を入れて実行…」で、変数に好きな値を入れてから鳴らせるで。

シーンのローカル変数（`＄名前`）に値を入れてから鳴らす。たとえば `＄天気` で台詞が変わるシーンを、`雨` にして鳴らすには次のとおりにする。

1. 「値を入れて実行…」を押す。
2. 「組を足す」を押し、名前に `天気`、型に「文字列」、値に `雨` を入れる。
3. 「鳴らす」を押す。

- 名前は `＄` を除いて入れる。型は「文字列」「数」「真偽」から選ぶ。
- 入れた組は、シーンごとに、pasta-recipe を終えるまで覚えている。「▶ シーンを実行」は、覚えた組を使わずに鳴らす。

次の組があるときは鳴らさず、組のそばに理由が出る。

| 組 | 出る理由 |
| -- | -------- |
| 名前が `＄名前` と書けない | `＄<名前> と書ける名前ではありません（空・数字だけ・__名前__・空白や記号を含む）` |
| 前の組と同じ名前 | `同じ名前の組があります: <名前>` |
| 型が数で、値が数として読めない | `数として読めません: <値>` |

### 保存変数の表

「保存変数を表示」を押すと、動いているゴーストの保存変数（`＄＊名前`）が、名前・型・値の表で出る。読み込み直しをしないので、動いている間の値がそのまま見える。

| 操作 | すること |
| ---- | -------- |
| 行の「書き換え…」 | 型と値を選んで「書き換える」を押す |
| 行の「消す…」 | 確かめて「消す」を押す |
| 表の下の「追加…」 | 名前・型・値を入れて「足す」を押す |

- 書き換えた値は、その後に読む `＄＊名前` にすぐ見える。ファイルへは、ゴーストの終了か読み込み直しのときに書かれる（[グローバル変数の保存先](../grammar/variables.md#グローバル変数の保存先)）。
- 型が「表」の行は見るだけである。
- デバッグが無効のゴーストでは、表は出ない。出力の欄に案内が出る。

- `.nar` の作成（[配布の章](../getting-started/14-nar.md) を参照する）
