# 文法リファレンス概要

> 【考え中】台本というものを、お手に取ったことはございまして？ 場面の見出しがあって、誰が何を言うかが順に並んでいる、あの冊子ですわ。

> 【アンソニー】お芝居の稽古で、役者が手にしているものでございますね。

> 【したり顔】ええ。Pasta DSL の辞書は、その台本そのものですの。まず 1 冊まるごと眺めてから、細かな決まりへ下りて参りますわよ。

---

Pasta DSL の辞書（`.pasta`）は**台本**である。根にあるのは日本の台本の書式で、場面の見出しである**柱**、人物が話す**台詞**、台詞以外の指示である**ト書き**の 3 つで書く。Pasta DSL はこれをゴーストとノベルゲーム向けに整理したもので、紙の台本と一対一には対応しない。

このセクションは、まず台本 1 冊の全体を見てから、柱・台詞・登場人物・細部の順に下りる。各章は、書き方を引く参照としても使える。

## 台本として読む

次の辞書は、暇なときのおしゃべり（ランダムトーク）を 1 つ書いた台本である。女の子がおやつをねだり、選択肢で続きが分かれる。

```pasta
％女の子
　＠笑顔：\s[0]
　＠困惑：\s[5]

％男の子
　＠通常：\s[11]
　＠困惑：\s[15]

＠おやつ：プリン、ドーナツ、たいやき

＊会話
　％女の子、男の子
　女の子：＠笑顔　ねえ、今日は＠おやつ　が食べたいな。
　男の子：＠困惑　きのうも食べたよね。
　＠？食べる「それでも食べる」
　＠？がまん「がまんする」
　！select（10）

　・食べる
　　女の子：＠笑顔　やった！
　　＞後片付け

　・がまん
　　女の子：＠困惑　……あしたは、ぜったい食べるからね。

　・後片付け
　　男の子：＠通常　お皿は、自分で洗ってね。
```

| 台本の言葉 | 上の例の行 | Pasta DSL の構文 | 詳しい章 |
| ---------- | ---------- | ---------------- | -------- |
| 登場人物 | `％女の子`・`％男の子` と、その下の `＠笑顔：\s[0]` | アクター辞書。人物ごとに、表情などの言葉を持たせる | [アクター辞書](actor-dictionary.md) |
| 柱 | `＊会話` と `％女の子、男の子`、`・食べる`・`・がまん`・`・後片付け` | グローバルシーン `＊`・ローカルシーン `・`。柱には、この場面に出る人を並べるアクター指定行 `％` と、属性 `＆` が付く | [行とブロック構造](block-structure.md) |
| 台詞 | `女の子：…ねえ、今日は…`・`男の子：…きのうも食べたよね。` | アクション行 `アクター：台詞` | [アクション行](action-line.md) |
| ト書き | `＠笑顔`（表情を変える）・`＠？食べる「それでも食べる」`（選ばせる）・`！select（10）`（選択肢の制限時間）・`＞後片付け`（別の場面を呼ぶ） | シーンの中の、台詞以外のほとんど全部。台詞の中の表情、選択肢行 `＠？`、キューコマンド行 `！`、Call `＞`、変数の代入 `＄名前＝式` | [アクション行](action-line.md)・[行とブロック構造](block-structure.md)・[Call](call-jump.md)・[変数・スコープ](variables.md) |
| 台本に無いもの | `＠おやつ：プリン、ドーナツ、たいやき` と、台詞の中の `＠おやつ` | 単語。候補から 1 つが選ばれる言葉の引き出し | [単語定義](words.md) |

ト書きは、台本の流れと演出を指示する行である。選択肢と Call も、話をどこへ進めるかを決めるト書きに入る。キューコマンド行（`！`）のうち、今働くのは `!select` だけである。

### 紙の台本と違うところ

- **柱は名前で呼ばれる。** 上から順に演じられるのではない。`＊会話` は暇なときのおしゃべり、`＊OnBoot` は起動というように、出来事（イベント）に合う名前の柱が呼ばれる。ローカルシーン `・` は、同じグローバルシーンの中の選択肢と Call から呼ばれる。
- **同じ名前の柱を何本も書ける。** 呼ばれるたびに、候補から 1 本が選ばれる。上の例の隣にもう 1 つ `＊会話` を書けば、おしゃべりの種類が増える。
- **単語は選ばれる。** `＠おやつ` は、出るたびに「プリン」「ドーナツ」「たいやき」のどれかになる。
- **変数と式がある。** 値を覚えておき、台詞に入れたり、柱を選ぶ条件にしたりできる（[変数・スコープ](variables.md)）。
- **Lua を書ける。** 台本で書ききれない処理は、Lua ブロックに書く（[Lua ブロックの配置](block-structure.md#lua-ブロックの配置)）。

## 文法の原則

- **行で書く**: 1 行が 1 つの意味を持ち、行頭の文字（マーカー）で行の種類が決まる。複数行にわたるのは Lua ブロックだけである。
- **全角・半角は同じ**: マーカー・演算子・括弧は、全角でも半角でも同じに読まれる（`＊` と `*`、`（` と `(`）。
- **インデントは有無だけ**: 行頭に空白があるかないかで、柱の行か、その中の行かが決まる。深さは見ない。
- **式を書ける**: 変数の代入と関数の引数に、算術の式と文字列の連結を書ける（[変数・スコープ](variables.md)）。
- **宣言で書く**: `if`・`while` のような制御の構文は無い。話の流れは、柱の書き分けと Call で表す。

マーカーと演算子の一覧は [キーワード・マーカー](markers.md) にある。

## ファイルの形

1 つのファイルは、登場人物（アクター辞書）・柱（グローバルシーン）・ファイルレベルの行を、任意の順に並べたものである。

```text
ファイル
├─ ファイルレベル属性行 (＆)
├─ グローバル単語定義 (＠)
├─ アクター辞書 (％名前)
│   ├─ 単語定義 (＠)
│   ├─ 属性行 (＆)
│   ├─ 変数代入 (＄)
│   └─ Lua ブロック
├─ グローバルシーン (＊名前、または ＊ 単独行)
│   ├─ 初期部: 属性行 (＆)・ローカル単語定義 (＠)・アクター指定行 (％)
│   ├─ Lua ブロック
│   ├─ 暗黙の開始ブロック
│   │   ├─ アクション行 (アクター：内容)・継続行 (：内容)
│   │   ├─ 変数代入 (＄)・Call 行 (＞)
│   │   ├─ 選択肢行 (＠？)・キューコマンド行 (！)
│   │   └─ Lua ブロック
│   └─ ローカルシーン (・名前)
│       ├─ アクション行・継続行・変数代入・Call 行・選択肢行・キューコマンド行
│       └─ Lua ブロック
└─ コメント行 (＃)・空行（どこにでも置ける）
```

各行の置き方は [行とブロック構造](block-structure.md) で扱う。
