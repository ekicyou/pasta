# アクション行

さあ、いよいよキャラクターたちが口を開きますわ。
「誰が、何を話すか」――それを書くのがアクション行ですの。
ここがゴーストの命、いちばん楽しいところですわよ。張り切って参りましょう！

---

アクション行は、キャラクター（アクター）の発言や演出を記述する行である。基本形は「アクター名 ： アクション内容」であり、内容には通常テキストとインライン要素を自由に組み合わせられる。

## 基本構文

```text
アクター名：アクション内容
```

インデントした行頭にアクター名を書き、コロン（`：` / `:`）の後ろにアクション内容を書く。コロンの前後の空白は無視される。

```pasta
＊会話
    ぱすた：今日はいい天気だね
    ラザニア：そうですわね、散歩に参りましょうか
```

- アクター名は識別子である（[識別子](markers.md#識別子identifier)）。空白や記号を含む任意の文字列は書けない。
- アクター名には、アクター辞書（`％名前`）で定義した名前か、pasta.toml の `[actor]` に登録した名前を使う（[アクター辞書](actor-dictionary.md)）。登録していない名前を書いたときの挙動は [登録していないアクター名](#登録していないアクター名) で扱う。
- アクター名が act（シーンの実行に使われるオブジェクト）のメソッド名・フィールド名（`talk`・`word`・`var`・`save`・`actors` など）と同じでも、アクション行ではそのアクターの発言として出力される。Lua から `act.名前` で参照するときの制限は [アクタープロキシ](../lua/script-api.md#アクタープロキシ) で扱う。
- アクション行の行末に `#` を書いても、コメントにはならず本文として出力される（[コメント](block-structure.md#コメント)）。

アクター名は会話だけでなく、さくらスクリプトによる表情指定などアクション全般を制御する。

## アクターの省略

アクター名を書かず、インデントした行頭にコロン（`：` / `:`）を置いた行は継続行になる。継続行は直前のアクション行と同じアクターの発言として扱われ、前の発言に続けて出力される。

```pasta
＊長い会話
    ぱすた：今日はね
    ：とてもいい天気なんだ
    ：だから散歩に行こうと思ってるんだ

    ラザニア：よろしくてよ！
    ：ご一緒いたしますわ！
```

継続行の規則は [行継続](#行継続) で扱う。

## 登録していないアクター名

アクター辞書にも pasta.toml の `[actor]` にも無い名前（書き間違いなど）をアクター名に書いても、実行時エラーにはならない。その行は、名前を登録しないその場限りのアクターの発言として、立ち位置 0 で出力される。

```pasta
％ぱすた

＊挨拶
    ぱすた：こんにちは
    ぱすたー：はじめまして
    ：よろしくね
```

- 発言の先頭に、目印 `【未登録アクター：名前】` がバルーンに表示される。上の例の 2・3 行目は「【未登録アクター：ぱすたー】はじめましてよろしくね」と表示される。目印は話者がその名前に切り替わるたびに 1 回付き、同じ名前の行（継続行を含む）が続く間は繰り返さない。
- ログに警告（`act:actor_proxy - unregistered actor`）が出る。立ち位置の無いアクターと同じく、立ち位置 0 で話したことを示す警告（`actor_spots fallback`）も出る。
- 行の中の単語参照・関数呼び出し・さくらスクリプトは、登録済みのアクターの行と同じく働く。アクター辞書が無いため、アクター辞書の段では見つからず、それ以外の段で探される（[アクタースコープと単語参照の統合](actor-dictionary.md#アクタースコープと単語参照の統合)）。
- 名前はアクターとして登録されない。後の `％` 行・アクション行・Lua からは、登録済みのアクターとして見えない。

## インライン要素

アクション内容には次の要素を埋め込める。

| 要素 | 構文 | 説明 |
| ---- | ---- | ---- |
| 通常テキスト | `こんにちは` | 任意の文字列 |
| 単語参照 | `＠名前` | 登録済み単語からランダム選択（[単語定義](words.md)） |
| 関数呼び出し | `＠名前（引数、引数）` | シーンの Lua 関数などを呼び出し、戻り値を出力する |
| グローバル関数呼び出し | `＠＊名前（引数、引数）` | `GLOBAL` テーブルの関数を呼び出し、戻り値を出力する |
| 動的単語参照 | `＠＄名前` | 変数の値を単語キーとして単語を選ぶ（[動的単語参照](words.md#動的単語参照)） |
| 動的関数呼び出し | `＠＄名前（引数、引数）` | 変数の値を関数名として関数を呼び出し、戻り値を出力する（[動的関数呼び出し](words.md#動的関数呼び出し)） |
| ローカル変数参照 | `＄名前` | 変数値を展開 |
| グローバル変数参照 | `＄＊名前` | グローバル変数の値を展開 |
| シーン引数参照 | `＄０`・`＄１`… | シーンが受け取った引数を展開 |
| プロパティ参照 | `＄％名前` | プロパティの値を展開 |
| ＠エスケープ | `＠＠` | リテラルの「＠」を 1 文字出力 |
| ＄エスケープ | `＄＄` | リテラルの「＄」を 1 文字出力 |
| バックスラッシュのエスケープ | `\\` | 「\」を 1 文字表示（さくらスクリプトのエスケープ） |
| パーセントのエスケープ | `\%` | 「%」を 1 文字表示（さくらスクリプトのエスケープ） |
| さくらスクリプト | `\n` `\w8` `\s[0]` | 表情・タイミング制御（[さくらスクリプト](sakura-script.md)） |

```pasta
＊いろいろ
    ぱすた：こんにちは、＄player_name　さん！\w8
    ぱすた：今日の天気は＠weather_words　ですね\n
    ぱすた：合計は＠足す（10、20）です
    ぱすた：価格は＄＄100、連絡先は info＠＠example.com です
    ぱすた：保存先は C:\\new です
    ぱすた：達成率は100\%です
```

- 関数呼び出しの括弧は全角・半角のどちらでもよい。引数は読点 `、`・全角カンマ `，`・半角カンマ `,` で区切り、書いた順に位置で渡される。`名前：値` の形も受理されるが、名前は捨てられ、値だけが位置で渡される。引数の書き方は [引数リスト](call-jump.md#引数リスト) と同じである。
- 引数が式として正しくない場合（`＠挨拶（時間：朝）` の `朝` のように、引用符の無い文字列を値に書いた場合など）は、関数呼び出しにならない。`＠挨拶` の単語参照と本文「（時間：朝）」として解釈される。動的関数呼び出しも同じで、`＠＄名前（時間：朝）` は `＠＄名前` の動的単語参照と本文「（時間：朝）」になる。
- 動的単語参照・動的関数呼び出しは、`＠` の後ろの名前の代わりに変数を書き、その時点の変数の値を単語キー・関数名に使う。変数にはグローバル変数（`＠＄＊名前`）・シーン引数（`＠＄０`）も書ける。探し方と、値が使えないときの挙動は [動的単語参照](words.md#動的単語参照) で扱う。
- `＠＠`・`＄＄` は、全角・半角を混ぜて書いても（`＠@`・`＄$`）2 文字目の 1 文字を出力する。
- `\\` は、さくらスクリプトで `\` を 1 文字表示するエスケープである。2 文字のまま出力され、ベースウェアが `\` 1 文字として表示する。直後の文字とタグにはならないため、`C:\\new` は「C:\new」と表示され、`\n` の改行にはならない。行末に書いても `\` を表示してからスクリプトが終わり、`\\\\` と重ねると `\` が 2 文字表示される。ウェイトの自動挿入や改行位置の推定で、`\\` の 2 文字の間に何かが入ることはない。
- `\%` は、さくらスクリプトで `%` を 1 文字表示するエスケープである。`\\` と同じく 2 文字のまま出力され、ベースウェアが `%` 1 文字として表示する。直後の文字とタグにはならず、2 文字の間に何かが入ることもない。
- さくらスクリプトの囲み（`\_?…\_?`）の中では、`＠`・`＄`・`\` で始まるインライン要素は展開されず、書いたとおりに出力される（[タグをそのまま表示する囲み](sakura-script.md#タグをそのまま表示する囲み)）。
- 変数の種類・プロパティ参照・シーン引数は [変数・スコープ](variables.md) で扱う。

```pasta
％ぱすた

＠果物：りんご、みかん、ぶどう

＊動的参照
    ＄種類＝「果物」
    ぱすた：今日の＄種類　は＠＄種類　です
```

この例の `＠＄種類` は、`＠果物` と書いた場合と同じく「りんご」「みかん」「ぶどう」から 1 つを選ぶ。

> **重要**: アクション内では変数の**参照**（`＄名前`）のみ可能。変数の代入（`＄名前＝式`）は専用の変数代入行で行う（[変数・スコープ](variables.md)）。

### 台詞と連結演算子

台詞（継続行を含む）に書いた `＆`／`&` は、連結演算子にならず、文字のまま出力される。一方、台詞の中の関数呼び出し（`＠名前（…）`・`＠＊名前（…）`・`＠＄名前（…）`）の引数は式であり、引数に書いた `＆` は連結演算子になる（[連結の評価](variables.md#連結の評価)）。

````pasta
％ぱすた

＊連結と台詞
    ＄a＝「りんご」
    ＄b＝「みかん」
    ぱすた：＄a＆＄b　です
    ぱすた：＠かぎ括弧（＄a＆「と」＆＄b）です

```lua
function SCENE.かぎ括弧(actor, s)
    return "「" .. s .. "」"
end
```
````

この例の 1 つ目のアクション行は、`＄a` の値・`＆`・`＄b` の値を並べて「りんご＆みかんです」と表示する。2 つ目のアクション行は、`＄a＆「と」＆＄b` をつないだ `りんごとみかん` を関数 `かぎ括弧` に渡し、「「りんごとみかん」です」と表示する。

> **注意**: 括弧の中に `＆` を含む `＠名前（…＆…）`・`＠＊名前（…＆…）`・`＠＄名前（…＆…）` は、連結演算子が加わる前の版では関数呼び出しにならず、単語参照（`＠名前` など）と本文の文字として表示されていた。現在は関数呼び出しになり、括弧の中が連結として評価される。

## インライン要素の区切り

行は左から右へ走査され、マーカー文字（`\` `＠` `＄`）で分岐して各要素が**最長一致**で切り出される。同じ位置で複数の要素に当てはまる場合は、エスケープ（`＠＠`・`＄＄`・`\\`・`\%`）→ 関数呼び出し（動的関数呼び出しを含む）→ 単語参照（動的単語参照を含む）→ 変数参照 → さくらスクリプト → 通常テキストの順に判定する。識別子の終端は、空白による区切り、または識別子に含まれない文字の出現で決まる。

### 空白による区切り

単語参照（動的単語参照を含む）・変数参照の直後の空白はトークン区切りとして認識され、空白の数に関係なく 1 つの区切りとして扱われる。区切りの空白は出力に含まれない。

```text
＠挨拶　みんな！      → 単語参照「挨拶」+ 通常テキスト「みんな！」
＠挨拶　　　みんな！  → 同じ出力（空白数は無関係）
＄name　さん         → 変数参照「name」+ 通常テキスト「さん」
＠時刻（）　です     → 関数呼び出し「時刻」+ 通常テキスト「　です」
＠＄種類　です       → 動的単語参照「＄種類」+ 通常テキスト「です」
```

関数呼び出し（`＠名前（）`・`＠＊名前（）`・`＠＄名前（）`）は閉じ括弧で終わるため、直後の空白は区切りとして消えず、本文に残る。

### 空白がない場合（最長一致）

空白で区切られない場合、識別子に含まれない文字が現れるまでを最長一致で取り込む。

```text
＠挨拶、みんな！        → 単語参照「＠挨拶」+ 通常テキスト「、みんな！」（読点は識別子外）
＄name!                → 変数参照「＄name」+ 通常テキスト「!」
＠weather_wordsですね  → 識別子「＠weather_wordsですね」として吸収（意図しない例）
```

意図せず後続が吸収されるのを防ぐには、空白で区切る（`＠weather_words　ですね`）か、読点など識別子に含まれない記号で区切る（`＠weather_words、ですね`）。

## 行継続

長い発言は、継続行（インデント＋`：`）で複数行に分けて書ける。継続行の内容は、直前のアクション行のアクターの発言として前の発言に続けて出力される。

```pasta
＊長文
    ぱすた：長い台詞は
    ：複数行に分けて
        ：記述できます
```

上の例の出力は「長い台詞は複数行に分けて記述できます」となる。

- 継続行は、インデントの後にコロン（`：` / `:`）を置いて始める。コロンを置かずにテキストだけを書いた行は継続行にならず、パースエラーになる。
- 継続行のインデントの深さは問わない。直前の行より深くても浅くてもよい。
- 継続行のアクターは、同じシーン（暗黙の開始ブロック、またはローカルシーン）の中で直前に書いたアクション行のアクターである。間に変数代入行・Call 行・空行・コメント行があってもよい。
- 同じシーンの中に先行するアクション行が無い位置（ローカルシーンの先頭など）に継続行を書くと、トランスパイルエラーになる。親のグローバルシーンのアクション行は引き継がれない。
- 継続行の行末に `#` を書いても、コメントにはならず本文として出力される。

## 改行

出力に改行を入れるには、さくらスクリプトの `\n` を使う。`\n` は常に「改行」として解釈される。

```pasta
＊改行例
    ぱすた：１行目。\n
    ：２行目。

    ：３行目。
```

上の例の出力は「１行目。」の後に改行が 1 つ入り、「２行目。３行目。」が続く。継続行の間の空行は何も出力せず、改行にもならない。空行は、継続行の間を含めてどこに置いても無視される。

細かいタイミング制御には、さくらスクリプトの `\w` 等を使うのが推奨される（[さくらスクリプト](sakura-script.md)）。
