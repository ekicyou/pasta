# リテラル型

> 【不安】書いた値が数か文字か――ここを取り違えると、思わぬところで戸惑いますわよ。

> 【アンソニー】書いたはずの数が、なぜか文字列扱いされる、というお悩みでございますね。

> 【したり顔】ええ。けれど Pasta は書かれた値を、書いた場所に応じて決まった規則で見分けますの。このルールさえ知っておけば、そんな戸惑いとは無縁ですわよ。

---

リテラル値は、変数代入の右辺・関数や Call の引数・Call の動的ターゲット（これらはすべて式）と、属性値・単語値に書く。値の型は、値を書いた場所（文脈）ごとに決まる。

## 型変換ルール

| 文脈 | 書けるもの | 値の型 |
| ---- | ---------- | ------ |
| 式（変数代入の右辺・引数・Call の動的ターゲット） | 数値、引用符で囲んだ文字列、変数参照、関数呼び出し、括弧、算術 | 数値または文字列 |
| 属性値（`＆名前：値`） | 数値、引用符で囲んだ文字列、引用なしの文字列 | 整数・小数・文字列 |
| 単語値（`＠名前：値、値`） | 引用符で囲んだ文字列、さくらスクリプト、引用なしの文字列 | 常に文字列 |

- 式に書ける文字列は引用符で囲んだものだけである。`＄x＝Hello` のような引用なしの文字列はパースエラーになる。
- 真偽値のリテラルは無い。`true`・`false` を式に書くとパースエラーになる。真偽値が必要な処理は Lua ブロックで書く。
- 属性値の数値は、小数点を含めば小数、含まなければ整数として記録される。それ以外の値は文字列として記録される。属性は現在処理に反映されない（[属性](block-structure.md#属性)）。
- 単語値は数字だけを書いても文字列になる（`＠回数：10` の値は文字列 `10`）。
- 引数の値は式である（[引数リスト](call-jump.md#引数リスト)）。

```text
＄a＝「こんにちは」  → 文字列 こんにちは
＄b＝3.14            → 数値 3.14
＄c＝42              → 数値 42
＆level：3           → 属性値 整数 3
＆mood：happy        → 属性値 文字列 happy
＠回数：10           → 単語値 文字列 10
```

## 文字列（String）

式と属性値に書く文字列は、全角の `「…」` か半角の `"…"` で囲む。囲んだ中身がそのまま値になり、空白も値に含まれる。

引用は、開始した行の中で閉じる。値に改行は含められない。閉じないまま行をまたぐとパースエラーになる。

```pasta
＊OnTalk
    ＄greeting＝「こんにちは、世界」
    ＄message＝"Hello, World!"
    ＄empty＝「」
    ＄blank＝""
    ぱすた：＄greeting
```

- `「」`・`""` は空文字列である。式・単語値・属性値・キューコマンドの引数のどこに書いても同じである（上の `＄empty`・`＄blank` の値は空文字列）。
- 同じ行に `""` を 2 つ書くと、最初の `""` から次の `""` までが 2 重の囲みの文字列になる。`＠w：""、""` の候補は `、` の 1 つである。
- `「` は 1〜4 個重ねて囲みにできる（4 重まで）。重ねた場合は、同じ個数の `」` が並んだ位置で終わる。
- `"` は何個重ねてもよく、開始と同じ個数の `"` が並んだ位置で終わる。

単語値の文字列の書き方（引用なしの値・読点区切り）は [単語定義](words.md) で扱う。属性値の引用なしの文字列には、空白・`：`・`＆`・`#` を含められない。

単語値・属性値の引用なしの文字列は、`「`・`"` で始められない。`「`・`"` で始めた値は、その行の中で引用文字列として閉じる。閉じていないとパースエラーになる。

### 文字列エスケープ

文字列にはエスケープの規則は無い。`\` は普通の文字として値に含まれ、`\n`・`\"` も変換されない。

囲みの記号を中身に含めたい場合は、囲みを重ねる（囲みの多重化）。中身に含まれない並びで閉じるように、開始の囲みの個数を選ぶ。

```pasta
＊OnTalk
    ＄a＝「「彼は「はい」と言った」」
    ＄b＝""say "yes" now""
```

- `＄a` の値は `彼は「はい」と言った` である（`」` 1 個は 2 重の囲みを閉じない）。
- `＄b` の値は `say "yes" now` である（`"` 1 個は 2 重の囲みを閉じない）。

中身に閉じの並び（開始と同じ個数の `」` や `"`）を含めることはできない。その場合はさらに囲みを重ねる。また、中身の先頭に囲みと同じ文字（`「` で囲むときの `「`、`"` で囲むときの `"`）を置くことはできない。先頭の同じ文字は囲みの一部とみなされる。中身が `「` で始まる場合は `"` で囲む（`"「セリフ」"` の値は `「セリフ」`）。

## 数値（i64 / f64）

数値は、任意の符号（`-` / `－`）、数字、任意の小数部（小数点 `.` / `．` と数字）からなる。数字は ASCII 数字（`0-9`）と全角数字（`０-９`）の両方が使える。式の中の数値は Lua の数値になる。

```pasta
＊OnTalk
    ＄count＝10
    ＄offset＝-5
    ＄pi＝3.14
    ＄delta＝－２．５
```

`＄delta` の値は `-2.5` である。小数点の前後には数字が必要で、`.5` や `5.` は数値として受理されない。算術の規則は [変数・スコープ](variables.md) で扱う。

## 単語値での引用符エスケープ

単語値でも、囲みの多重化で中身に `「」` を含められる。囲みは値に残らない。

```pasta
＠会話：「「セリフ」」、「「彼は「はい」と言った」」
```

この単語の候補は `セリフ` と `彼は「はい」と言った` である。`「「セリフ」」` の値は `セリフ` であり、括弧は値に含まれない。値に括弧ごと含めたい場合は、`"「セリフ」"` のように `"` で囲む（値は `「セリフ」`）。単語値の書き方の全体は [単語定義](words.md) で扱う。
