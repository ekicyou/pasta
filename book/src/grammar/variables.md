# 変数・スコープ

会話に「記憶」を持たせたいときは、変数の出番ですわ。
一時的なもの、永続するもの、ベースウェアと共有するもの――三種を使い分けますの。
スコープを制する者がゴーストを制する、と申しておきましょう。

---

変数は `＄`（または `$`）マーカーで宣言・参照する。Pasta には有効範囲（スコープ）の異なる 3 種類の変数がある。代入の値には式や関数呼び出しも使える。

## 変数の種類とスコープ

| スコープ | 代入 | 参照 | 有効範囲 |
| -------- | ---- | ---- | -------- |
| ローカル | `＄var_name＝値` | `＄var_name` | 一連のシーンが終わるまで |
| グローバル | `＄＊var_name＝値` | `＄＊var_name` | 永続的 |
| プロパティ | `＄％prop.path＝値` | `＄％prop.path` | SSP 共有プロパティ（ベースウェア管理） |

代入の区切りはコロン（`：`）でも代入演算子（`＝`）でも記述できる。

```pasta
＊初期化
    ＄score：100
    ＄ユーザー：太郎
    ＄is_active：true
```

### ローカル変数

一連のシーンが終わるまで有効な変数。`＄変数名` で参照する。

```pasta
＄ローカル変数＝10
Alice：値は ＄ローカル変数　です
```

### グローバル変数

`＄＊` 修飾子を付けると、永続的に有効なグローバル変数になる。Lua 側では `save.` に対応する。

```pasta
＄＊グローバル変数＝100
Bob：値は ＄＊グローバル変数　です
```

### プロパティ変数

`＄％` で SSP 共有プロパティを読み書きする。プロパティ ID はドット（`.`）を含められ、`sakura.name` や `baseware.version` などをそのまま記述できる。

```pasta
＄％sakura.name＝Alice          # プロパティへ書き込み
＄name＝＄％sakura.name          # プロパティから読み込み
さくら：＄％sakura.name           # インライン参照
```

## 変数参照の空白ルール

会話行の中で変数を展開するには、`＄変数名` の直後に**1 文字以上の空白**を置く。

```pasta
＊表示
    ＄ユーザー：太郎
    ぱすた：＄ユーザー　さん、こんにちは！
```

> **重要**: 空白がないと最長一致で変数名を解釈し、後続の文字まで変数名に取り込んでしまう。意図しない動作を避けるため、変数参照の直後には必ず空白（または識別子に含まれない記号）を置く。

## 式（Expression）のサポート

変数代入では式を記述できる。代入可能な値は次のとおり。

| 値の種類 | 構文例 | 説明 |
| -------- | ------ | ---- |
| リテラル値 | `＄score＝100` | 数値・文字列リテラル |
| 単語参照 | `＄value＝＠word_name` | 登録済み単語の参照 |
| 変数参照 | `＄new＝＄old` | 他の変数の値をコピー |
| 式 | `＄result＝＄a + ＄b * 2` | 算術式 |
| ローカル関数呼び出し | `＄r＝＠calculate()` | `SCENE.calculate(act)` の戻り値 |
| グローバル関数呼び出し | `＄r＝＠＊calculate()` | `GLOBAL.calculate(act)` の戻り値 |
| 関数呼び出し（引数付き） | `＄sum＝＠add（x：10　y：20）` | 名前付き引数で呼び出し |

```pasta
＄calc＝（＄x + ＄y）* 2   # 括弧による優先順位制御
```

対応する算術演算子は [キーワード・マーカー](markers.md) を参照。複雑な演算や条件判定は Lua ブロックで関数化できる。

### 関数スコープの展開先

| DSL 構文 | Lua 展開先 | 説明 |
| -------- | ---------- | ---- |
| `＠func()` | `SCENE.func(act)` | ローカルスコープ（シーン内） |
| `＠＊func()` | `GLOBAL.func(act)` | グローバルスコープ（永続領域） |

`＠＊` のグローバルスコープは、変数 `＄＊` → `save.` と対称の構造である。

## 式文（ExprStmt）

代入を伴わず、式の評価（副作用）だけを行うには `＄＝expr` と書く。変数名を省略し、結果を捨てる。

```pasta
＄＝＠副作用関数（）           # ローカル: SCENE.副作用関数(act)
＄＝＠＊グローバル副作用（）   # グローバル: GLOBAL.グローバル副作用(act)
```

`var_set` の全バリアント（ローカル・グローバル・式文）はすべて `＄` で始まり、変数操作のシグナルとして一貫して認識される。

## エンジンが値を入れる変数

ここまでの変数はすべて辞書側で代入するものだった。これとは別に、pasta.dll（実行時エンジン）が値を入れる変数がある。文法上は普通のローカル変数・グローバル変数と同じで、`＄変数名` で参照する。

| 種類 | 変数 | 値が入る条件 |
| ---- | ---- | ------------ |
| 日時変数 | `＄年`・`＄時１２` など（[下表](#日時変数)） | 時報シーンでは自動。それ以外は `＞transfer_date_to_var` を呼ぶ |
| リクエスト変数 | `＄ｒ０`〜`＄ｒ９`・`＄req_id` など（[下表](#リクエスト変数reference)） | 自動では入らない。`＞transfer_req_to_var` を呼ぶ |
| 予約グローバル変数 | `＄＊pasta_` で始まる名前（[下表](#予約グローバル変数pasta_-で始まる名前)） | 辞書側で代入すると、エンジンの動作が変わる |

> **注意**: 転記を呼ばずに日時変数やリクエスト変数を参照すると、会話には空文字ではなく `nil` という文字がそのまま表示される。また、転記すると同じ名前のローカル変数は上書きされる。`＄日` や `＄時` といった名前を自分の変数に使わないこと。

### 日時変数

時報シーン（`＊時報14`・`＊時報その他`・`＊OnHour14`・`＊OnHourOther`。数字は半角 2 桁）には、発火した時点の日時が自動で入る。ランダムトークやクリック反応など、それ以外のシーンで使うときは、シーンの先頭で `＞transfer_date_to_var` を呼んでから参照する。

| 変数 | 内容 | 例 |
| ---- | ---- | -- |
| `＄年` `＄月` `＄日` | 年・月・日（単位付きの文字列） | `2026年` `9月` `26日` |
| `＄時` `＄分` `＄秒` | 時（24 時間制）・分・秒（単位付きの文字列） | `14時` `5分` `0秒` |
| `＄時１２` | 12 時間制の時刻 | `午後2時` |
| `＄曜日` | 曜日 | `土曜日` |
| `＄year` `＄month` `＄day` | 年・月・日（数値） | `2026` `9` `26` |
| `＄hour` `＄min` `＄sec` | 時（0〜23）・分・秒（数値） | `14` `5` `0` |
| `＄wday` | 曜日番号（0=日曜〜6=土曜） | `6` |
| `＄week` | 曜日（英語） | `Saturday` |

`＄時１２` は、0 時が `深夜0時`、1〜11 時が `午前N時`、12 時が `正午`、13〜23 時が `午後N時` になる。`１２` は全角数字で書く。

```pasta
＊OnMouseDoubleClick
　＞transfer_date_to_var
　女の子：＠通常　今日は　＄曜日　、いまは　＄時１２　だよ。
```

### リクエスト変数（Reference）

ベースウェアはイベントごとに `Reference0`、`Reference1`… という付加情報を送ってくる（ダブルクリックされた部位、選択肢の ID など）。これらは自動では変数に入らない。シーンの先頭で `＞transfer_req_to_var` を呼ぶと、次の変数に値が入る。

| 変数 | 内容 |
| ---- | ---- |
| `＄ｒ０`〜`＄ｒ９` | `Reference0`〜`Reference9` の値（文字列）。`ｒ` と数字は全角 |
| `＄r0`〜`＄r9` | 同じ値の半角名 |
| `＄req_id` | イベント名（例: `OnMouseDoubleClick`） |
| `＄req_base_id` | リクエストの `BaseID` ヘッダの値（送られてきた場合のみ） |

```pasta
＊OnMouseDoubleClick
　＞transfer_req_to_var
　女の子：＠通常　＄ｒ４　を触ったね？
```

各 `Reference` に何が入るかはイベントごとに異なる。[UKADOC の SHIORI Event 一覧](https://ssp.shillest.net/ukadoc/manual/list_shiori_event.html)で確認できる。たとえば `OnMouseDoubleClick` では `Reference4` がダブルクリックされた部位の名前になる。`Reference10` 以降は変数に入らないため、Lua から `act.req.reference[10]` で読む（[scripts/ の記述パターン](../lua/patterns.md)を参照）。

### 予約グローバル変数（pasta_ で始まる名前）

`＄＊pasta_` で始まるグローバル変数はエンジンが予約している。辞書側で代入すると、エンジンの動作が変わる。自分の変数に `pasta_` で始まる名前を使わないこと。

| 変数 | 用途 | 既定値 |
| ---- | ---- | ------ |
| `＄＊pasta_talk_interval_min` | ランダムトークの最小間隔（秒） | `180` |
| `＄＊pasta_talk_interval_max` | ランダムトークの最大間隔（秒） | `300` |

```pasta
＄＊pasta_talk_interval_min＝60
＄＊pasta_talk_interval_max＝120
```

間隔は、この変数 → `pasta.toml` の `[ghost]` にある `talk_interval_min` / `talk_interval_max` → 既定値、の順に決まる。値は数値で代入すること（数値以外は無視される）。10 秒未満を指定したときは 10 秒になり、最小間隔が最大間隔を上回ったときは最大間隔が最小間隔にそろえられる。代入した値は、次にトーク間隔を計算するときから反映される。
