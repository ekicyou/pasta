# キーワード・マーカー

まずは Pasta DSL の「文字の意味」を覚えていただきますわ。
行頭に置く一文字――マーカー――が、その行の運命を決めるのですの。
この章は早見表として手元に置いておくとよろしくてよ。

---

Pasta DSL は行指向文法であり、行頭の文字（マーカー）によって行の種類が確定する。ここではマーカー・演算子・区切り文字・基本要素を一覧する。**すべてのマーカー・演算子・括弧は全角と半角の両方を許容し、両者は同等に扱われる**（例外: さくらスクリプトの `\` は半角のみ。ローカルシーンのマーカーは `・` と半角の `-` で、全角の `－` は使えない）。

全角・半角が同等なのはマーカーとして読むときだけであり、台詞として出力される文字は書いたとおりで、全角・半角の変換はされない。アクション行で `＠` や `＄` を文字として出力するには、同じ文字を 2 つ重ねて書く（`＠＠`・`＄＄`、`@@`・`$$`）。重ねた 2 文字目がそのまま出力される（`＠＠` → `＠`、`@@` → `@`、`＠@` → `@`）。

## マーカー一覧

| マーカー | 全角 | 半角 | 用途 |
| -------- | ---- | ---- | ---- |
| グローバルシーン | `＊` | `*` | シーン定義 |
| ローカルシーン | `・` | `-` | サブシーン定義 |
| アクター辞書 | `％` | `%` | アクター辞書の定義・アクター指定行 |
| 属性 | `＆` | `&` | シーンなどへのメタデータ（構文は受理されるが処理には反映されない） |
| 単語／関数 | `＠` | `@` | 単語定義・参照・関数呼び出し |
| 選択肢 | `＠？` | `@?` | 選択肢行（ジャンプ先＋表示テキスト） |
| 変数 | `＄` | `$` | 変数の代入・参照 |
| 代入 | `＝` | `=` | 変数代入の区切り（アクター指定行の番号指定にも使う） |
| Call | `＞` | `>` | シーン呼び出し |
| キューコマンド | `！` | `!` | 演出指示。`!select` だけが選択肢の制限時間を設定し、他のコマンドは何もしない |
| コメント | `＃` | `#` | コメント |
| コロン | `：` | `:` | キー：値の区切り |
| さくらスクリプト | （なし） | `\` | さくらスクリプトのコマンド（半角のみ） |

## 基本要素

### 改行（NEWLINE）

改行は `\r\n` / `\n` / `\r` のいずれか。行指向文法では改行により行の種類が確定し、すべての行は改行で終わる。

ファイルの最終行も改行で終わらなければならない。最終行が改行で終わっていないと、その行がパースエラーになり、ファイル全体が読み込まれない。エディタ拡張の診断は末尾の改行を補って解析するため、この誤りを報告しない。

### 空白（WHITE_SPACE）

空白として扱われる文字は次のとおり。改行（`\r` `\n`）は空白に含まれず、行の区切りとして機能する。

| 文字 | コードポイント |
| ---- | -------------- |
| 半角スペース | U+0020 |
| タブ | U+0009 |
| 全角スペース | U+3000 |
| ノーブレークスペース | U+00A0 |
| オガム文字スペース | U+1680 |
| 各種幅のスペース | U+2000〜U+200A |
| 狭いノーブレークスペース | U+202F |
| 中くらいの数学用スペース | U+205F |

上の表に無い文字は空白として扱われない。Unicode で空白に分類される文字でも、U+000B（垂直タブ）・U+000C（改ページ）・U+0085・U+2028・U+2029 は空白ではない。空白は有効なトークン区切り文字であり、自動スキップされるわけではない。

### コロン

コロン（`：` / `:`）は**キー：値の関係**を表す区切り文字である。使われるのは次の箇所。

- 単語定義の名前と値の区切り（`＠名前：値`）
- 属性の名前と値の区切り（`＆名前：値`）
- アクション行のアクター名と台詞の区切り（`アクター：台詞`）、継続行の行頭（`：台詞`）
- 引数リストの `名前：値` の形の引数
- キューコマンドのスコープ内の `アクター名:名前` の区切り

変数の代入には使わない。代入は `＝` で書く（`＄名前＝値`）。引数どうしの区切りもコロンではなく、読点・カンマ（`、` `，` `,`）を使う。

次の例では、1 行目が単語定義、`＊会話` の配下の 1 行目がアクション行、2 行目が変数代入（コロンではなく `＝`）である。

```pasta
＠word_name：value1、value2
＊会話
    アクター：こんにちは
    ＄var_name＝10
```

### 識別子（Identifier）

識別子は Unicode の XID_START または `_` で始まり、XID_CONTINUE が続く。ASCII の `a-z` `A-Z` `0-9` `_`、および平仮名・カタカナ・漢字なども使用できる。

- `__` の後に `_` を含まない文字列が続き、再び `__` が現れる形で始まる識別子（例: `__start__`）はシステム予約であり使用できない。
- **最長一致**で切り出される。空白による区切りがない場合、識別子に含まれない文字が現れるまでを一括して取り込む。

次のアクション行では、単語参照の識別子は `挨拶` までであり、続く `、みんな！` は通常のテキストとして出力される。

```pasta
＊会話
    ぱすた：＠挨拶、みんな！
```

### インデント（Indent）

行頭の 1 つ以上の連続した空白。**有無のみが判定基準**であり、深さは判定しない。

- インデントなし = グローバルレベル（グローバルシーン、グローバル単語定義など）
- インデントあり = 下層レベル（グローバルシーン・アクター辞書の配下の行）

```text
＊会話              ← インデントなし（グローバルレベル）
  ＆author：Alice   ← インデントあり（下層レベル）
  Alice：おはよう   ← インデントあり（下層レベル）
```

## 演算子

式で使える演算子は算術演算子だけであり、比較の演算子は無い（`＝` は代入、`＞` は Call、`＜` は使われない）。条件による分岐は Lua で書く。

### 算術演算子

| 演算 | 全角 | 半角 |
| ---- | ---- | ---- |
| 加算 | `＋` | `+` |
| 減算 | `－` | `-` |
| 乗算 | `＊` `×` | `*` |
| 除算 | `／` `÷` | `/` |
| 剰余 | `％` | `%` |

`＊` は乗算とグローバルシーンのマーカーで、`％` は剰余とアクター辞書のマーカーで、同じ文字を使う点に注意する（行頭か式の中かで区別される）。演算子の優先順位と評価のされ方は [変数・スコープ](variables.md) で扱う。

### 括弧

| 種類 | 全角 | 半角 |
| ---- | ---- | ---- |
| 左括弧 | `（` | `(` |
| 右括弧 | `）` | `)` |

## 単語値の区切り文字

単語定義の値リストは、全角読点（`、`）・全角コンマ（`，`）・半角カンマ（`,`）のいずれかで区切る。区切り文字の前後の空白は無視される。

```pasta
＠fruits：apple、banana、orange
＠numbers：1、2、3
```
