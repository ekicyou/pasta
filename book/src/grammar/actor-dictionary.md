# アクター辞書

キャラクターごとに表情の引き出しを用意する――それがアクター辞書ですわ。
「ぱすたの通常顔」「ラザニアの刮目」を名前で呼び出せる、なんとも優雅な仕組み。
文法リファレンスの締めくくり、しっかり仕上げて差し上げますわよ。

---

アクター辞書（ActorScope）は、キャラクター（アクター）ごとに単語辞書を定義し、会話行で参照可能にする機能である。アクターごとの表情や表現のバリエーションを、アクター名を伴った単語参照として記述できる。`％`（または `%`）マーカーで定義する。

## グローバルアクター辞書定義

ファイルレベル（インデントなし）で `％actor_name` を記述し、その直下にインデントした `＠word_name：values` 行を並べると、そのアクターに属する単語定義になる。

```pasta
＃アクター辞書
％ぱすた
  ＠通常　　　：\s[0]、\s[100]
  ＠照れ　　　：\s[1]
  ＠驚き　　　：\s[2]
  ＠ぐんにょり：\s[3]
  ＠怒り　　　：\s[4]

％ラザニア
  ＠通常　：\s[10]
  ＠刮目　：\s[11]
```

構文上の注意:

- アクター名には日本語・英語の識別子が使える。
- 単語定義は必ずインデント（全角空白 `　` または半角空白）で開始する。
- 値はカンマ（`、` / `，` / `,`）で区切り、複数のさくらスクリプト値を指定できる。

## シーンスコープ内でのアクター指定

グローバルシーン内で `％actor1、actor2` の形式でアクターを指定すると、そのシーン内の会話行でアクター名付き単語参照が有効になる。

```pasta
＊メイン
  ％ぱすた、ラザニア
  ぱすた：＠通常　こんにちは
  ラザニア：＠刮目　目を見開くラザニア
```

`actor_name：` で始まる会話行では、そのアクターの単語辞書を優先的に参照する。

## アクタースコープと単語参照の統合

`actor_name：＠word_name` の形式で参照する場合、まず `％actor_name` で定義された単語辞書から `word_name` を検索する。

- アクター辞書に該当する単語がなければ、グローバル単語辞書・ローカル単語辞書にフォールバックする。
- アクター辞書による単語参照も、グローバル・ローカル単語と同じ**前方一致検索**ルールに従う。

### シャッフル＆順次消費

アクター単語は、グローバル・ローカル単語と同一のシャッフル＆順次消費アルゴリズムに従う（共通仕様は [Call / Jump](call-jump.md) を参照）。

- 複数値が定義された単語（例: `＠通常：\s[0]、\s[100]、\s[200]`）は、ランダムにシャッフルされた後、呼び出しごとに順次消費される。
- 全候補が消費されると再シャッフルされ、再び順次消費が始まる。
- 単一値の単語（例: `＠照れ：\s[1]`）は常に同じ値を返す。

## 同一スポット共有時の外見の復旧

SSP はサーフェスと着せ替えをスポット（`\p[N]`）単位で保持する。そのため複数のアクターを同じスポット（同じ `spot` 値、または `spot` 未設定によるスポット 0 へのフォールバック）に割り当てて交代で話させると、直前に話したアクターの立ち絵が残ってしまう。pasta はアクターごとの外見を記録し、交代時に切替先アクターの外見を自動で復旧する。

### 復旧の振る舞い

- **記録**: アクターの発話中に出力されたサーフェス変更（`\s[ID]`・`\sN`。アクター辞書の単語由来も含む）と着せ替え指定（`\![bind,カテゴリ名,パーツ名,数値]`）を、そのアクターの外見として記録する。あわせて、そのスポットに表示中の外見も記録する。サーフェス ID は数値・エイリアス・`-1` のいずれも、出力されたとおりの値で扱う。
- **復旧**: アクターが切り替わったとき、切替先アクターの記録とスポットに表示中の外見が食い違えば、`\p[spot]` の直後（発話内容の前）に `\s[ID]`、続けて `\![bind-noevent,...]` を出力する。一致していれば何も出力しない。
- **着せ替えの比較単位**: 着せ替えはカテゴリ単位で比べ、食い違うカテゴリはそのアクターが記録した順に丸ごと再出力する。アクターが一度も指定していないパーツ（直前のアクターが着けたアクセサリなど）は外さない。交代時に確実に外したいパーツは、後述の `dressup` に `0` で書いておく。カテゴリ全脱衣 `\![bind,カテゴリ名,,0]` を記録したアクターへ戻るときは、全脱衣から復旧する。
- **冗長な復旧の省略**: 発話の先頭（最初の本文の文字より前）に `\s[ID]` を書いた場合、サーフェスの復旧は出力しない（直後に上書きされるため）。先頭に数値とパーツ名を明示した bind を書いた場合も、そのパーツの復旧だけを出力しない。
- **継続時は復旧しない**: 同じアクターが同じスポットで話し続ける場合は復旧しない。各アクターが専用スポットで話す従来構成では、`surface`・`dressup` を設定しない限り出力は変わらない。
- **記録の寿命**: 記録はゴースト起動中のトークをまたいで保持し、ゴーストの再読込で破棄する。セーブデータには保存しない。

```toml
[actor."女の子"]
spot = 0

[actor."男の子"]
spot = 0
```

```pasta
％女の子
  ＠通常：\s[0]

％男の子
  ＠通常：\s[10]

＊会話
  ％女の子、男の子
  女の子：＠通常　\![bind,帽子,麦わら,1]こんにちは。
  男の子：＠通常　\![bind,帽子,リボン,1]やあ。
  女の子：いい天気ね。
```

3 つ目の発言（`女の子：いい天気ね。`）で女の子に戻るとき、スポット 0 には男の子の `\s[10]` とリボンが残っている。pasta は女の子の `\p[0]` の直後に `\s[0]\![bind-noevent,帽子,麦わら,1]` を補い、女の子の外見を復旧する。

### 任意キー `surface`・`dressup`

`pasta.toml` のアクター設定に、記録がまだ無いときに使う既定の外見を書ける。

| キー | 型 | 意味 |
| ---- | -- | ---- |
| `surface` | 整数 または 文字列（エイリアス） | 既定サーフェス。そのアクターがまだサーフェス変更を出力していないときの復旧値 |
| `dressup` | テーブル（カテゴリ名 → パーツ名 → `0` または `1`） | 既定着せ替え。そのアクターがまだ指定していないパーツの復旧値（`1`=着衣 / `0`=脱衣） |

```toml
[actor."女の子"]
spot = 0
surface = 0

[actor."女の子".dressup."帽子"]
"リボン" = 1
"麦わら" = 0
```

- いずれも任意である。未設定のアクター・パーツについては、既定値による出力を一切行わない。
- `dressup` の入れ子の順（カテゴリ名 → パーツ名 → 数値）は bind タグの引数順と同じである。値は数値 `0`・`1` のみ有効で、`true` などそれ以外の値は無視される。
- 既定値は記録が無いときのフォールバックであり、発話中に出力した `\s[ID]`・bind の記録が優先される。
- pasta は起動直後の SSP の表示を知らないため、`surface`・`dressup` を設定したアクターは、起動・再読込後に最初に話すときにも既定値を出力する（専用スポットでも同様）。

### 着せ替え復旧の動作要件（SSP 2.8.23 以上）

着せ替えの復旧タグは、SSP の着せ替え変更イベント（`OnDressupChanged` など）を発生させない `\![bind-noevent,...]` で出力する。復旧は見た目の再現であり、作者が明示した着せ替え操作ではないためである。このタグは SSP 2.8.23 以上で動作し、それより古いベースウェアでは着せ替えの復旧が効かない（サーフェスの復旧は効く）。pasta はベースウェアのバージョンによって出力を切り替えない。

### 記録できない指定

pasta は自分が出力したさくらスクリプトだけから外見を記録する。結果を確定できない指定は「不明」として扱い、出力そのものは変えない。

- **スコープ切替タグ**: 発話中に `\0` `\1` `\h` `\u` `\p[N]` などを出力すると、全スポットの表示中の外見を不明とし、そのタグ以降（次にアクターが切り替わるか、次のトークが始まるまで）のサーフェス変更・bind はアクターの記録に含めない。
- **アクター未指定の生さくらスクリプト**（`act:raw_script()` など）: サーフェス変更・bind・スコープ切替タグを含むと、全スポットの表示中の外見を不明とする。アクターの記録は変えない。
- **パーツ名を明示し数値を省略した bind（トグル）**: スポットのそのパーツの状態が分かっていれば反転した値として記録し、分からなければそのカテゴリを不明とする。
- **パーツ名が空の bind（カテゴリ単位の着衣・トグル）、`0`・`1` 以外の数値の bind**: そのカテゴリを不明とする。ただしカテゴリ全脱衣 `\![bind,カテゴリ名,,0]` は記録する。

不明になったスポットでは、次にアクターが交代したとき、切替先アクターの記録があれば再出力される。ただし同じアクターが同じスポットで話し続ける場合は、不明でも復旧しない（作者がスコープ切替タグや生さくらスクリプトで直接変えた表示を巻き戻さないため）。また、トグルなどでアクター自身の記録が不明になったカテゴリには、明示指定で記録し直すまで `dressup` の既定値も使わない。

### 非対応事項

- SSP 側だけで起きた変化（ユーザーの着せ替えメニュー操作、シェル変更、起動時の既定サーフェスなど）は検知しない。
- 名前に `,` `]` `"` `\` を含むカテゴリ・パーツは追跡・復旧の対象外である（bind 引数のクォート・エスケープを解釈しないため、正しく記録されない）。`dressup` に書いた名前もエスケープせずに出力するため、これらの文字を含めないこと。
- 必ず 1 つ選択（`mustselect`）のカテゴリで最後の 1 パーツを外す指定を SSP が拒否した場合、pasta の記録と実際の表示がずれる（`descript.txt` を読まないため検知しない）。

### 副作用: トーク中の `＠surface`

`surface`・`dressup` は `spot` と同様にアクターの設定値としてアクター単語の検索対象にもなる。アクター単語の検索はアクター設定の値（キー名の完全一致）を最優先するため、そのアクターの会話行で `＠surface` と書くと、同名のアクター単語・グローバル単語よりも先に設定値（`surface = 0` なら文字 `0`）が出力される。サーフェスを変えるタグ `\s[0]` にはならない。`＠spot`・`＠dressup` も同様に設定値に解決されるため、これらの名前の単語は別の名前にすること。

## コードブロック（将来変更あり）

アクタースコープ内に Lua コードブロックを配置する構文は定義されているが、現時点では使用例がなく、将来の拡張として予約されている。

````pasta
％actor_name
  ＠word_name：value
  ```lua
  function SCENE.on_actor_event(act)
    local save, var = act:init_scene(SCENE)
    -- アクター固有のイベント処理
  end
  ```
````

> **将来変更あり**: アクタースコープ内のコードブロックは文法定義のみが存在し、未実装である。アクター固有のイベントハンドラや状態管理関数を置く用途が予定されている。仕様は将来変更され得る。
