# 行とブロック構造

Pasta の世界は、行が積み重なって「ブロック」を作りますの。
シーンという大きな器の中に、台詞や呼び出しがきちんと収まる――その仕組みを見ていきましょう。
構造を掴めば、辞書ファイル全体が手に取るように分かりますわよ。

---

Pasta は行指向文法であり、各行は改行で終わる。行頭のマーカーとインデントの有無により行の種類が決まり、それらが階層的なブロック構造を形成する。

## 行の種類

行は**インデントの有無**で大きく二分される。

### インデント不要の行

行頭にインデントを置かない行（グローバルレベル）。

| 行種 | 形 | 説明 |
| ---- | -- | ---- |
| グローバルシーン | `＊名前` / `*名前` | グローバルシーンを開始する |
| 名前なしグローバルシーン | `＊` / `*`（単独） | 直前のグローバルシーンと同じ名前の、別のグローバルシーンを開始する |
| グローバル単語定義 | `＠名前：値、値` | 全辞書ファイル共通で参照できる単語を定義する |
| アクター辞書 | `％名前` | アクター単位の単語辞書を開始する |
| ファイルレベル属性行 | `＆名前：値` | ファイル単位の属性（[属性](#属性)を参照） |
| Lua ブロックのフェンス | 3 個以上のバッククォート | グローバルシーンまたはアクター辞書に属する複数行のコード（[Lua ブロックの配置](#lua-ブロックの配置)を参照） |
| コメント行・空行 | `＃` / `#` | 処理されない（[コメント](#コメント)・[空行](#空行)を参照） |

### インデントが必要な行

行頭にインデントを置く行（下層レベル）。置ける場所が行の種類ごとに決まっている。

| 行種 | 形 | 置ける場所 |
| ---- | -- | ---------- |
| 属性行 | `＆名前：値` | グローバルシーンの初期部、アクター辞書の配下 |
| 単語定義（インデントあり） | `＠名前：値、値` | グローバルシーンの初期部（ローカル単語）、アクター辞書の配下（アクターの単語） |
| アクター指定行 | `％名前、名前` | グローバルシーンの初期部 |
| ローカルシーン | `・名前` / `-名前` | グローバルシーンの配下 |
| アクション行 | `アクター：台詞` | 暗黙の開始ブロック・ローカルシーン |
| 継続行 | `：台詞` | 暗黙の開始ブロック・ローカルシーン |
| 変数代入 | `＄名前＝式` | 暗黙の開始ブロック・ローカルシーン（アクター辞書の配下でも受理されるが、何も起きない） |
| Call | `＞シーン名` | 暗黙の開始ブロック・ローカルシーン |
| 選択肢行 | `＠？名前「表示」` | 暗黙の開始ブロック・ローカルシーン |
| キューコマンド行 | `！コマンド名(引数)` | 暗黙の開始ブロック・ローカルシーン |

グローバルシーンの**初期部**とは、グローバルシーン宣言の直後、最初のアクション行などのコンテンツ行より前の部分を指す。属性行・単語定義・アクター指定行は初期部にだけ置け、アクション行などの後に置くとパースエラーになる。各行の構文は、アクション行・継続行は [アクション行](action-line.md)、変数代入は [変数・スコープ](variables.md)、Call は [Call / Jump](call-jump.md)、単語定義は [単語定義](words.md)、アクター辞書とアクター指定行は [アクター辞書](actor-dictionary.md) で扱う。

> **Note**: コメント行と空行はインデントの有無にかかわらず、どの位置にも置ける。

## ブロック構造

ファイルは、ファイルレベルの行（ファイルレベル属性行・グローバル単語定義）・アクター辞書・グローバルシーンを任意の順に並べたものである。グローバルシーンが 0 個のファイル（単語定義やアクター辞書だけのファイル）も有効である。

### グローバルシーン

グローバルシーンは行頭が `＊`（または `*`）で始まる。シーン本体はインデントした行で記述する。

```pasta
＊挨拶
    ぱすた：こんにちは！
    ラザニア：ごきげんよう！
```

同名のグローバルシーンを複数定義できる。呼び出し時に**前方一致**で候補が列挙され、候補はシャッフルされたうえで呼び出しのたびに 1 つずつ順に使われる（全候補を使い切ると並べ直す）。詳細は [Call / Jump](call-jump.md) で扱う。

```pasta
＊挨拶
    ぱすた：おはよう！

＊挨拶
    ぱすた：こんばんは！
```

名前を書かない単独の `＊` 行は、同じファイルで直前に宣言したグローバルシーンと同じ名前の、別のグローバルシーンを開始する。前のシーンへ統合されるのではなく、同名シーンの候補が 1 つ増える。ローカル単語定義・ローカルシーンは前のシーンと共有しない。ファイルの先頭（それより前にグローバルシーンが無い位置）の単独の `＊` 行はパースエラーになる。

```pasta
＊OnTalk
    ぱすた：最初の候補です。
＊
    ぱすた：2 つめの候補です（＊OnTalk と同じ名前）。
```

### グローバルシーンの内部構造

グローバルシーンは、宣言行に続いて次の要素をこの順で持つ。

1. **グローバルシーン行**: `＊名前`（または単独の `＊`）
2. **初期部**: 属性行（`＆名前：値`）・ローカル単語定義（`＠名前：値`）・アクター指定行（`％名前`）を 0 個以上、任意の順で
3. **Lua ブロック**: 0 個以上
4. **暗黙の開始ブロック（`__start__`）**: ローカルシーン宣言なしで書くコンテンツ行（アクション行・継続行・変数代入・Call・選択肢行・キューコマンド行）を 0 個以上と、その後ろに Lua ブロックを 0 個以上
5. **ローカルシーン**: 0 個以上の明示的ローカルシーン（`・名前`）

グローバルシーンが Call の対象になると、暗黙の開始ブロック（`__start__`）が実行される。コンテンツ行が 0 個でもよい。

### ローカルシーン

ローカルシーンは親のグローバルシーンの中でのみアクセス可能で、インデント＋`・`（または `-`）で始まる。

```pasta
＊メインメニュー
    ぱすた：何をしますか？
    ＞選択肢1

    ・選択肢1
        ぱすた：選択肢1が選ばれました

    ・選択肢2
        ぱすた：選択肢2が選ばれました
```

ローカルシーンは、宣言行・コンテンツ行（アクション行・継続行・変数代入・Call・選択肢行・キューコマンド行）0 個以上・Lua ブロック 0 個以上で構成される。ローカルシーンには属性行・単語定義・アクター指定行を置けない。属性は宣言行への付記（`・名前＆名前：値`）としてだけ書ける。

### アクター辞書

アクター辞書は行頭の `％名前` で始まり、インデントした単語定義・属性行・変数代入と、Lua ブロックを配下に持つ。構文と用途は [アクター辞書](actor-dictionary.md) で扱う。

## Lua ブロックの配置

Lua ブロックは、行頭に置いた 3 個以上のバッククォート（開始フェンス）で始まり、同じ本数のバッククォート（閉じフェンス）で終わる複数行のコードである。

- 開始フェンスは行頭に置く。インデントしたフェンスはパースエラーになる。
- 開始フェンスの後ろには任意の識別子（`lua`・`text` など）を 1 つ書いてもよい。書かなくてもよい。フェンスと識別子の間、識別子の後ろには空白を置けない（```` ``` lua ```` や、末尾に空白のある ```` ```lua ```` はパースエラー）。グローバルシーンの Lua ブロックでは、この識別子は出力に影響しない。
- 閉じフェンスは開始フェンスと同じ本数のバッククォートで書く。閉じフェンスの後ろにはコメントを書ける。
- ブロックの内容には、開始フェンスの本数以上連続したバッククォートを含められない。含める必要がある場合は、より多い本数のフェンスで囲む。

````pasta
＊会話
```lua
local count = 0
function SCENE.counter(act)
    count = count + 1
    return tostring(count)
end
```
    ぱすた：＠counter（）回目の会話です。
````

Lua ブロックを置ける位置は次の 2 つである。

- グローバルシーンの初期部の後（暗黙の開始ブロックのコンテンツ行より前）。この後に暗黙の開始ブロックのコンテンツ行を続けられる（上の例）。
- 暗黙の開始ブロック・ローカルシーンの末尾。この後に同じブロックのコンテンツ行は続けられず、次に置けるのはローカルシーン宣言、または次のグローバルシーン・アクター辞書・ファイルレベルの行である。

Lua ブロックの内容は検証されず、そのまま生成される Lua コードに出力される。

- グローバルシーンの Lua ブロックは、ブロックを置いた位置にかかわらず、そのグローバルシーンのシーン関数の定義すべての後に出力され、辞書の読み込み時（ロード時）に一度評価される。シーンの実行時に評価されるのではない。
- 関数定義以外の文（`local` 変数の宣言・代入・`require` など）も書ける。これらはロード時に実行される。
- 出力先はグローバルシーンごとの Lua のブロック（`do` 〜 `end`）の中であり、`SCENE` はそのグローバルシーンを指す。`local` で宣言した変数は、同じグローバルシーンの Lua ブロックの中だけで有効である。
- Lua としての誤りは、ロード時の Lua エラーになる。

`function SCENE.名前(act)` で定義した関数は、シーンの中から `＠名前` や `＠名前（）` で呼び出せる。関数の書き方は Lua セクションで扱う。アクター辞書の配下の Lua ブロックの扱いは [アクター辞書](actor-dictionary.md) で扱う。

## 選択肢行

選択肢行は、プレイヤーに提示する選択肢を定義する。インデントした行で `＠？`（または `@?`）に続けてジャンプ先の名前を書き、必要なら表示テキストを `「」` で囲んで続ける。

```text
＠？ジャンプ先
＠？ジャンプ先「表示テキスト」
```

- `＠？` と `@?` は同等で、`＠?` や `@？` のように全角・半角を混ぜてもよい。
- 表示テキストを省略すると、ジャンプ先の名前がそのまま表示テキストになる。
- 表示テキストは 1 重の `「」` で囲む。`"` や `「「…」」` のような多重の囲みは使えず、表示テキストに `」` は含められない。
- ジャンプ先の名前は識別子である。ジャンプ先の名前と `「` の間に空白は置けない（`＠？挨拶 「挨拶する」` はパースエラー）。
- 行末にコメントを書ける。

選択肢行は、選択肢をさくらスクリプトの `\![*]\q[表示テキスト,ジャンプ先]` として、その行の位置に出力する。選択肢が選ばれると、ジャンプ先の名前を選択 ID として SHIORI イベント `OnChoiceSelectEx` が発生する。選択後に実行されるシーンの決まり方は、[SHIORI イベントとハンドラ](../lua/shiori-events.md#onchoiceselectex) で扱う。

選択肢の制限時間は、キューコマンド `!select(秒数)` で設定する（[キューコマンド行](#キューコマンド行)を参照）。

```pasta
＊メニュー
    ぱすた：何をしますか？
    ＠？挨拶「挨拶する」
    ＠？自己紹介
    !select(30)

    ・挨拶
        ぱすた：こんにちは！
    ・自己紹介
        ぱすた：私はぱすたです。
```

## キューコマンド行

キューコマンド行は、演出の指示をコマンドの形で書く行である。インデントした行で `！`（または `!`）に続けてコマンド名を書く。

```text
！コマンド名
！コマンド名＠スコープ
！コマンド名（引数、引数、…）
！コマンド名＠スコープ（引数、引数、…）
```

- マーカー（`！` / `!`）・スコープの `＠` / `@`・括弧（`（）` / `()`）・引数の区切り（`、` `，` `,`）は全角・半角のどちらでもよい。
- マーカー・コマンド名・スコープ・引数リストの間には空白を入れない（`!select (10)` はパースエラー）。
- コマンド名は識別子である。
- スコープは `＠名前` または `＠アクター名:名前`（コロンは全角・半角どちらでもよい）の形で書く。
- 行末にコメントを書ける。

引数には次の型のトークンを書ける。

| 型 | 例 |
| -- | -- |
| 識別子（区切り文字・括弧・空白を含まない文字列） | `normal`、`actor:さくら`、`morning.ogg` |
| 文字列 | `「はい」` |
| 整数 | `30`、`-5` |
| 浮動小数点数 | `10.0`、`-5.5` |
| ＠参照 | `＠名前` / `@名前` |

構文として受理されるのはすべてのコマンド名だが、生成される Lua コードに反映されるのは `select` だけであり、他のコマンドは何もしない。

| コマンド | 動作 |
| -------- | ---- |
| `!select(秒数)` | 選択肢の制限時間を設定する。最初の引数が数値なら、その秒数をミリ秒に換算した `\![set,choicetimeout,ミリ秒]` をその行の位置に出力する |
| `!select`（引数なし、または最初の引数が数値でない） | `\![set,choicetimeout,0]` を出力する |
| `select` 以外 | 何もしない（何も出力されない） |

```pasta
＊起動挨拶
    !emote@普通(normal)          # 構文は受理されるが何もしない
    さくら：こんにちは！
    ＠？はい「はい」
    ＠？いいえ「いいえ」
    ！select（10）               # 選択肢の制限時間 10 秒
```

## 属性

属性は `＆名前：値` の形で、シーンなどにメタデータを書く構文である。構文は受理され、内部に記録されるが、シーンの選択・Lua コードの生成・出力には影響しない（処理には反映されない）。

### 構文

- 1 つの属性は `＆名前：値`（`＆` / `&`、`：` / `:` は全角・半角どちらでもよい）。
- 1 行に複数の属性を並べられる（`＆作者：Alice＆ジャンル：comedy`）。
- 値は整数・小数・引用文字列（`「…」` / `"…"`）・引用なし文字列のいずれか。引用なし文字列には `：`・`＆`・`＃`（半角の `:`・`&`・`#` も同じ）と空白を含められない。

### 置ける場所

| 置き方 | 例 |
| ------ | -- |
| グローバルシーンの初期部の属性行 | `    ＆作者：Alice` |
| ファイルレベルの属性行（インデントなし・シーンの外） | `＆作者：Alice` |
| アクター辞書の配下の属性行 | `    ＆作者：Alice` |
| グローバルシーン宣言行への付記 | `＊会話＆作者：Alice` |
| ローカルシーン宣言行への付記 | `    ・選択肢＆優先：3` |

ローカルシーン宣言の次の行に属性行を置くこと、アクション行・変数代入などのコンテンツ行の後に属性行を置くことはできず、パースエラーになる。ローカルシーンに属性を書くには、宣言行に付記する。

```pasta
＆作者：Alice
＊会話＆ジャンル：comedy
    ＆温度：暑い
    ぱすた：こんにちは！

    ・選択肢＆優先：3
        ぱすた：どれにしますか？
```

### 処理

属性は解析され、シーンの登録情報として内部に記録される。ファイルレベルの属性は、そのファイルで後に続くグローバルシーンの属性と統合される。いずれの場合も、属性はシーンの選択・呼び出し・出力に影響しない。

## コメント

`#` または `＃` から行末までがコメントとして扱われ、構造・セマンティクスに影響しない。行全体がコメントの行（コメント行）は、インデントの有無にかかわらずどの位置にも置ける（Lua ブロックの内容の中を除く）。

```pasta
＊テスト
    # これはコメントです
    ぱすた：これは実行されます
    ＃ 全角シャープでもOK
```

行の後ろに置く行末コメントは、次の行で書ける。

- グローバルシーン宣言・単独の `＊` 行・ローカルシーン宣言
- アクター辞書の宣言（`％名前`）・アクター指定行（`％名前、名前`）
- 属性行・変数代入・Call・キューコマンド行・選択肢行
- 値を `「」` または `"` で囲んだ単語定義
- Lua ブロックの閉じフェンス

アクション行と継続行では行末コメントを書けない。`#`・`＃` 以降も台詞として出力される。

```pasta
＊OnTest ＃ 行末コメント
    ＄回数＝1 ＃ 行末コメント
    さくら：本文 ＃これも台詞として出力される
```

## 空行

空行（空白だけの行を含む）はどの位置にも置け、無視される。アクション行の継続（`：` で始まる継続行）の途中に空行を挟んでも、改行などは出力されない。

## 文字コード

辞書ファイル（`.pasta`）は BOM なしの UTF-8 で保存する。

- 先頭に BOM（U+FEFF）がある UTF-8 のファイルは、ファイル先頭（1 行 1 列目）でパースエラーになる。
- UTF-8 として読めないファイル（Shift_JIS など）は読み込めない。

## インデントの判定

インデントは「有るか・無いか」のバイナリ判定のみで扱われ、**深さは判定されない**。インデントレベルが一貫している必要もない。インデントに使える文字は [キーワード・マーカー](markers.md) の空白の文字である。

```text
＊会話              ← インデントなし（グローバルレベル）
  ＆author：Alice   ← インデントあり（下層レベル）
  ・選択肢1         ← インデントあり（下層レベル）
  Alice：こんにちは ← インデントあり（下層レベル）
```
