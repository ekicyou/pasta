> 【したり顔】百聞は一見にしかず、ですわ。説明は後回しにして、まずは完成したゴーストに会っていただきますの。

> 【アンソニー】お嬢様、準備の章を飛ばしてしまって、よろしいのでございますか。

> 【にっこり】よろしいのよ。ファイルを 1 つ落として、ぽとりと置くだけですもの。5 分後には、あの子があなたの書いた台詞をしゃべっていますわ。

---

## 会う

1. [ダウンロード](../download.md#サンプルゴースト) のページから `hello-pasta.nar` を落とす。
2. 落とした `hello-pasta.nar` を、SSP に出ているゴーストの上へドロップする。
3. ゴーストを右クリックし、メニューの「ゴースト切り替え」から hello-pasta を選ぶ。

- 成功の目印: 女の子と男の子が出てきて、吹き出しであいさつする。
- そのまま置いておくと、2 人は 45〜75 秒おきにおしゃべりをする。
- SSP がまだ無いときは、先に [SSP の配布サイト](https://ssp.shillest.net/) から Windows 用の SSP を入れて起動する。

> 【アンソニー】お嬢様、あの 2 人の台詞は、どなたが書いたのでございましょう。

> 【クローディア】辞書という、ただのテキストファイルですわ。ですから、あなたにも今すぐ書き換えられますのよ。

## 書き換える

1. [ダウンロード](../download.md#pasta-recipe) のページから `pasta-recipe.x64.zip` を落として、好きなフォルダに展開する。
2. SSP を入れたフォルダの中の `ghost\hello-pasta` フォルダを、展開した `pasta-recipe.exe` の上へドロップする。
3. 開いた窓の左のツリーで、`dic` の下の `01-boot.pasta` を押す。
4. `女の子：` の後ろの台詞を、好きな言葉に書き換える。
5. `＊OnBoot` の行のすぐ上に出ている「▶ シーンを実行」を押す。

```text
＊OnBoot
　女の子：いらっしゃいませ！　本日のおすすめは、わたしです。
　　　　　└─ ここから後ろを書き換える
```

- 成功の目印: 女の子が、書き換えたとおりにしゃべる。
- 保存と読み込み直しは ▶ が行うので、SSP を再起動しなくてよい。
- 初めての起動で「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押す。
- `ghost\hello-pasta` の場所が分からないときは、SSP のエクスプローラ（`Ctrl+E`）で hello-pasta を右クリックし、「フォルダを開く」を選ぶ。
- VS Code で書きたいときは、[VS Code で書く](../debug/vscode-setup.md) の 3 手で同じことができる。

## この先

- hello-pasta は遊び場である。SSP でネットワーク更新をすると、書き換えたファイルは元に戻ることがある。
- `dic` の中には、このガイドの 13 段ぶんの辞書が全部入っていて、どのシーンも ▶ で鳴らせる。
- 自分のゴーストは、次の章の [自分のゴーストを始める](setup.md) で作る。
