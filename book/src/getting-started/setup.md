# 自分のゴーストを始める

> 【クローディア】器はもう用意してありますわ。見本で遊んだ次は、あなた自身のゴーストをお迎えする番ですのよ。

> 【アンソニー】お嬢様、フォルダを作ったり、設定を書いたりは、いたしませんので。

> 【したり顔】いたしませんわ。ファイルを 1 つ、ぽとりと置けば、もうあなたのゴーストですもの。

---

## 入れる

1. [ダウンロード](../download.md#スターター) のページから `pasta-starter.nar` を落とす。
2. 落とした `pasta-starter.nar` を、SSP に出ているゴーストの上へドロップする。
3. ゴーストを右クリックし、メニューの「ゴースト切り替え」から my-ghost を選ぶ。

- 成功の目印: 立ち絵が出て、女の子の吹き出しに「いらっしゃいませ！　本日のおすすめは、わたしです。」と出る。
- 入っている台詞は、このひとことだけである。

> 【アンソニー】お嬢様、見本の 2 人と、姿がそっくりでございますが。

> 【にっこり】絵は見本から借りていますの。けれど台詞は、ここから全部あなたが書きますのよ。

## エディタで開く

1. SSP を入れたフォルダの中の `ghost\my-ghost` フォルダを、`pasta-recipe.exe` の上へドロップする。
2. 左のツリーで、`dic` の下に `01-boot.pasta` があることを確かめる。

- 成功の目印: 窓の題名が `my-ghost - pasta-recipe` で始まり、ツリーに `dic` と `pasta.toml` が並ぶ。
- pasta-recipe は、[まず会ってみる](hello.md) で入れたものを使う。
- VS Code で書くときは、VS Code で `ghost\my-ghost` フォルダを開く（[VS Code で書く](../debug/vscode-setup.md)）。

## 中に入っているもの

| 入っているもの | 役目 |
| -------------- | ---- |
| `install.txt` | このフォルダがゴーストであることと、入れる先のフォルダの名前 |
| `ghost/master/descript.txt` | ゴーストの名前と、作者の名前 |
| `ghost/master/pasta.toml` | pasta の設定。2 人の名前と、▶ を働かせる `[debug]` が書いてある |
| `ghost/master/pasta.dll` | ゴーストの頭脳。辞書を読んで台詞を返す（隣の `THIRD_PARTY_LICENSES.txt` は、そのライセンス表示） |
| `ghost/master/dic/01-boot.pasta` | 最初の辞書。1 段目で読んで書き換える |
| `shell/master/` | 見た目（立ち絵）の一式。hello-pasta と同じ絵 |

- これから書く辞書は、`ghost/master/dic` に足していく。
- my-ghost はネットワーク更新をしないので、書いたものが元に戻ることは無い。
- それぞれの中身は、[付録：フォルダの中身と文字コード](prerequisites.md) にある。

## 名前のこと

- ゴーストの名前は、今は `my-ghost` である。
- 自分の決めた名前には、配る前に [14 段目](14-nar.md) で付け替える。
- それまでは、フォルダの名前も、`install.txt` と `descript.txt` の名前も変えない。

> 【考え中】あの子にふさわしい名前は、育てながらゆっくり考えればよろしいわ。

> 【アンソニー】名付けは最後のお楽しみ、でございますね。
