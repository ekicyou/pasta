# 8 段目：触ったら反応してほしい

> 【不安】撫でられても知らん顔では、可愛げがありませんわね……。あの子たち、いまは触られても何も返しませんのよ。

> 【アンソニー】お嬢様は、お帽子を直して差し上げるだけで、たいそう驚かれますが。

> 【照れ怒り】あ、あれは不意を突かれただけですわ！ 今日は、あの子たちにも、触られたら応えることを教えますのよ。

---

## 叶えたいこと

> 【クローディア】この章で叶えるのは「触ったら反応する」ですわ。あの子たちをダブルクリックすると、驚いたり照れたりしますの。どこを触られたのかまで、台詞に入れてみせますわよ。

- この章で足すファイル: `ghost/master/dic/08-touch.pasta`
- 叶うこと: キャラクターをダブルクリックすると、女の子と男の子が反応する。触られた部位の名前が、台詞に入る

## 新しく覚える表現

### ダブルクリックで呼ばれるシーン

> 【したり顔】7 段目で覚えた仕組みが、さっそく役に立ちますわ。キャラクターをダブルクリックすると、ベースウェアは `OnMouseDoubleClick` を送ってきますの。同じ名前のシーンを書いておけば、それが触られたときの反応になりますのよ。

```pasta
＊OnMouseDoubleClick
　＞transfer_req_to_var
　女の子：＠驚き　ひゃっ！
　男の子：＠通常　いま触られたのは……＄ｒ４　？
```

- キャラクターをダブルクリックすると、ベースウェアから `OnMouseDoubleClick` が来る
- `＊OnMouseDoubleClick` — `OnMouseDoubleClick` と同じ名前のシーンである。[7 段目](07-greeting.md#イベントと同じ名前のシーンを書く) で覚えたとおり、pasta はイベントと同じ名前のシーンを呼ぶ
- 2 行目の `＞transfer_req_to_var` と、台詞の中の `＄ｒ４` は、次の節で扱う
- `OnMouseDoubleClick` の出典は、次の表のとおりである

| イベント | いつ来るか（UKADOC より） | この段で使う Reference（UKADOC より） |
| -------- | ------------------------- | ------------------------------------- |
| [`OnMouseDoubleClick`](https://ssp.shillest.net/ukadoc/manual/list_shiori_event.html#OnMouseDoubleClick) | 「左・右ボタンでダブルクリックされた際に発生。」 | `Reference4` —「当たり判定の識別子。」 |

### 触られた部位の名前を台詞に入れる

> 【考え中】では、どこを触られたのかは、どうやって知るのでしょう。`OnMouseDoubleClick` の付加情報のうち、`Reference4` に、触られた部位の名前が入っていますの。7 段目と同じく `＞transfer_req_to_var` を呼べば、`＄ｒ４` で取り出せますわ。

- `　＞transfer_req_to_var` — [7 段目](07-greeting.md#付加情報を変数に取り出す) と同じく、シーンの先頭で呼んで、付加情報を `＄ｒ０`〜`＄ｒ９` に入れる
- `＄ｒ４` — `Reference4` の値が入る変数である。`OnMouseDoubleClick` では、触られた部位の名前が入る
- 当たり判定 — シェルが立ち絵の上に決めている領域である。シェルは、領域ごとに名前を付ける
- 触られた部位の名前は、シェルが当たり判定に付けた名前である。頭の当たり判定に `Head` と付けているシェルでは、頭を触ったときの `＄ｒ４` は `Head` になる
- `＄ｒ４` を台詞に入れると、触った場所によって台詞が変わる
- 上の男の子の台詞は、`＄ｒ４` が `Head` のときは「いま触られたのは……Head？」になる

> 【アンソニー】お嬢様、当たり判定の無いところを触られますと、どうなるのでございましょう。

> 【不安】そこが気をつけどころですの。当たり判定の外を触ったときは、`＄ｒ４` は空になりますわ。ですから、空でも台詞が読めるように、`＄ｒ４` は言葉の切れ目に置きますのよ。

```pasta
＊OnMouseDoubleClick
　＞transfer_req_to_var
　女の子：＠照れ　えへへ……＄ｒ４　なでなで？
　男の子：＠笑顔　ぼくにもやってほしいなあ。
```

- 当たり判定の外を触ったときの `＄ｒ４` は、空になる
- 空でも読めるように、`＄ｒ４` は言葉の切れ目に置く
- 上の女の子の台詞は、`＄ｒ４` の値によって次のようになる

| `＄ｒ４` の値 | 女の子の台詞 |
| ------------- | ------------ |
| `Head` | えへへ……Headなでなで？ |
| 空 | えへへ……なでなで？ |

- 変数の後ろには空白を置いて、続く台詞と区切る。6 段目の `＄時１２` と同じである

## 辞書ファイルを足す

`ghost/master/dic/08-touch.pasta` を作り、次の内容を UTF-8 で保存する。

```pasta
＃ 8 段目：触ったら反応してほしい
＃ キャラクターをダブルクリックすると、ベースウェアから OnMouseDoubleClick が来る。
＃ 7 段目と同じく、シーンの先頭で ＞transfer_req_to_var を呼んで付加情報を取り出す。
＃ ＄ｒ４ には、触られた部位の名前（シェルが当たり判定に付けた名前。頭に Head と付けていれば Head）が入る。
＃ ＄ｒ４ を台詞に入れると、触った場所によって台詞が変わる。
＃ 当たり判定の外を触ったときの ＄ｒ４ は空になる。空でも読めるよう、＄ｒ４ は言葉の切れ目に置く。

＊OnMouseDoubleClick
　＞transfer_req_to_var
　女の子：＠驚き　ひゃっ！
　男の子：＠通常　いま触られたのは……＄ｒ４　？

＊OnMouseDoubleClick
　＞transfer_req_to_var
　女の子：＠照れ　えへへ……＄ｒ４　なでなで？
　男の子：＠笑顔　ぼくにもやってほしいなあ。

＊OnMouseDoubleClick
　＞transfer_req_to_var
　女の子：＠驚き　わっ！\w9＠困惑　……え、いまの＄ｒ４　？
　男の子：＠笑顔　びっくりしすぎだよ。
```

- 1〜7 段目のファイルは書き換えない。新しいファイルを `dic/` に足すだけで、この段になる
- このファイルの 3 つのシーンは、どれも `OnMouseDoubleClick` という名前である。4 段目で覚えたとおり、ダブルクリックのたびにどれか 1 つが選ばれる
- 3 つ目のシーンの `\w9＠困惑` は、3 段目で覚えた、少し間を置いてから表情を変える書き方である
- 台詞の頭の `＠驚き`・`＠通常`・`＠照れ`・`＠笑顔` は、3 段目で付けた表情名である

## 起動して確かめる

> 【にっこり】さあ、触ってごらんなさいまし。ダブルクリックですわよ。3 回触れば、3 つの反応がひととおり見られますわ。

1. SSP を終了し、もう一度起動する。
2. 自分のゴーストが出ていなければ、メニューから切り替える。
3. 女の子の頭をダブルクリックする。
4. 反応を見たら、手順 3 をあと 2 回繰り返す。

- 成功の目印: ダブルクリックのたびに、次の表の 3 つの反応のどれか 1 つが出る。3 回のダブルクリックで、3 つが 1 回ずつ出る。出る順は決まっていない
- `＄ｒ４` の場所に出る言葉は、触った場所で決まる。頭の当たり判定に `Head` と付けているシェルで頭を触ったときは「`Head` のとき」の列、当たり判定の外を触ったときは「空のとき」の列の台詞になる

| 反応 | `＄ｒ４` が `Head` のとき | `＄ｒ４` が空のとき |
| ---- | ------------------------- | ------------------- |
| 1 つ目のシーン | 女の子「ひゃっ！」、男の子「いま触られたのは……Head？」 | 女の子「ひゃっ！」、男の子「いま触られたのは……？」 |
| 2 つ目のシーン | 女の子「えへへ……Headなでなで？」、男の子「ぼくにもやってほしいなあ。」 | 女の子「えへへ……なでなで？」、男の子「ぼくにもやってほしいなあ。」 |
| 3 つ目のシーン | 女の子「わっ！……え、いまのHead？」、男の子「びっくりしすぎだよ。」 | 女の子「わっ！……え、いまの？」、男の子「びっくりしすぎだよ。」 |

- 部位の名前が出ないときは、触った場所が当たり判定の外である。「空のとき」の列の台詞が出ていれば、辞書は読み込まれている
- 3 つ目のシーンでは、女の子が驚いた顔で「わっ！」と話し、少し間を置いて困った顔に変わる
