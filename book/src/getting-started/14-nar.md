## 叶えたいこと

- 叶うこと: 自分のゴーストを、配れる形のファイル（`.nar`）にする
- この章で足すファイル: 無い

## 辞書を書く

この段で足す辞書は無く、配る前に次の 3 つを整える。

### 名前を自分のものにする

| 直す場所 | 今の値 | 直し方 |
| -------- | ------ | ------ |
| ゴーストのフォルダの名前 | `my-ghost` | 自分の決めた名前にする |
| `install.txt` の `name` | `my-ghost` | ゴーストの名前にする |
| `install.txt` の `directory` | `my-ghost` | フォルダの名前と同じにする |
| `ghost/master/descript.txt` の `name` | `my-ghost` | ゴーストの名前にする |
| `ghost/master/descript.txt` の `craftman`・`craftmanw` | `your-name`・`あなたの名前` | 作者の名前にする |

- `my-ghost` のまま配ると、同じ名前のほかのゴーストとぶつかる。
- フォルダの名前は、SSP を終了してからエクスプローラーで変える。変えたあとは SSP を起動し、メニューの「ゴースト切り替え」から選び直す。
- `install.txt` は `ghost/master` の外にあるので、メモ帳で開いて上書き保存する。
- `descript.txt` をエディタで直したときは、`Ctrl+S` で保存する。
- それぞれのファイルの中身は、[付録：フォルダの中身と文字コード](prerequisites.md) にある。

### デバッグを切る

`ghost/master/pasta.toml` の `[debug]` を、次のとおりに直す。

```toml
[debug]
enabled = false
```

- `false` にすると、エディタの ▶ は働かなくなる。配る前の最後に直し、続きを書くときは `true` に戻す。

### 同梱するものを確かめる

- `ghost/master/` に、`pasta.dll` と `THIRD_PARTY_LICENSES.txt` が並んでいる。`THIRD_PARTY_LICENSES.txt` は `pasta.dll` が含むソフトウェアのライセンス表示で、`pasta.dll` と一緒に配る。
- `ghost/master/dic/` に 13 個の辞書が、`ghost/master/` に `calendar.csv` がある。
- エディタの「診断・検査」の一覧に、誤りが出ていない。

> 【アンソニー】お嬢様、ライセンスの文書まで包むのでございますか。

> 【クローディア】ええ、大切な礼儀ですわ。`pasta.dll` は、多くのソフトウェアの力を借りていますのよ。

## 確かめる

1. ゴーストを右クリックし、メニューの「設定」から本体設定を開いて、「一般」の「開発者用機能を有効にする」を ON にする（[6 段目](06-hour.md) で済ませていれば、そのままでよい）。
2. 本体設定の「開発/その他」で、「フォルダをドロップした際に更新ファイルやNARを作成」を ON にする。
3. 自分のゴーストのフォルダを、画面に出ているゴーストへドロップする。

- 成功の目印: 自分のゴーストの `.nar` ファイルができる
- ドロップするのは、`install.txt` のあるフォルダである。SSP を入れたフォルダの中の `ghost` の下にある。
- ドロップしたときに動作を選ぶ表示が出たら、NAR の作成を選ぶ。
- `.nar` ができる場所は、「開発/その他」の「NAR作成位置」で決まる。
- 「開発/その他」は、開発者用機能を有効にしていないと出ない。
- できた `.nar` は、`hello-pasta.nar` と同じく、SSP にドロップして入れられる。
