# 6 段目：時刻を知らせたい

> 【目閉じ】鐘を鳴らす役目を授けますわ。時の移ろいを告げるのは、古くから由緒あるお役目ですのよ。

> 【アンソニー】お嬢様のお茶の時刻でしたら、私が毎日お知らせしておりますが。

> 【冷笑】あなたの時報は小言つきですもの。あの子たちには、もっと愛らしく告げさせますわよ。

---

## 叶えたいこと

> 【クローディア】この章で叶えるのは「正時になったら、時刻を知らせる」ですわ。足す辞書は今回も 1 枚。それから、確かめるための道具を SSP から借りますのよ。

- この章で足すファイル: `ghost/master/dic/06-hour.pasta`
- この章で使いはじめる道具: SSP の開発者用機能と、開発用パレット
- 叶うこと: 正時（毎時 0 分 0 秒）になると、女の子と男の子が時刻を知らせる

## 新しく覚える表現

### 時報のシーン

> 【したり顔】正時になると、pasta は時報のシーンを呼びますの。`＊時報12` のように時刻を付けた名前は、その時刻だけのシーンになりますわ。

```pasta
＊時報12
　女の子：＠笑顔　お昼だよ！お腹すいた～。
　男の子：＠笑顔　もうお昼か、ご飯にしよう。
```

- 正時（毎時 0 分 0 秒）になると、pasta は時報のシーンを呼ぶ
- `＊時報12` — 12 時（正午）だけの時報のシーンである
- 時刻は、`時報` の後ろに半角 2 桁で付ける。24 時間制で、`00`〜`23` のどれかになる

> 【アンソニー】お嬢様、24 の時刻すべてにシーンを書くのでございますか。

> 【にっこり】ご安心なさいまし。その時刻のシーンが無いときは、`＊時報その他` が呼ばれますの。書いていない時刻は、すべてここが引き受けますわ。

- `＊時報その他` — その時刻のシーンが無いときに呼ばれる、時報のシーンである
- この章の辞書では、12 時に `＊時報12` が、ほかの時刻に `＊時報その他` が呼ばれる
- この章の辞書には、`＊時報その他` が同じ名前で 3 つある。4 段目で覚えたとおり、呼ばれるたびにどれか 1 つが選ばれる

### 時刻を台詞に入れる

> 【考え中】では、いまが何時なのかを、どうやって台詞に入れましょうかしら。そこで使うのが `＄時１２` ですの。時報のシーンでは、ここに「午後3時」のような時刻が入っていますわ。

```pasta
＊時報その他
　女の子：＠通常　＄時１２　になったよ。
　男の子：＠通常　もうそんな時間か。
```

- `＄` で始まる名前は変数である。台詞の中に書くと、その場所に変数の値が入る
- `＄時１２` — 12 時間制の時刻が入る変数である。日時が入る変数を、日時変数と呼ぶ
- 時報のシーンでは、日時変数に値が自動で入っている
- `１２` は全角数字で書く
- 変数の後ろには空白を置いて、続く台詞と区切る。この空白は吹き出しには出ない
- 上の女の子の台詞は、午後 3 時の時報なら「午後3時になったよ。」になる

| 時刻 | `＄時１２` の値 |
| ---- | --------------- |
| 0 時 | `深夜0時` |
| 1〜11 時 | `午前1時`〜`午前11時` |
| 12 時 | `正午` |
| 13〜23 時 | `午後1時`〜`午後11時` |

## 辞書ファイルを足す

`ghost/master/dic/06-hour.pasta` を作り、次の内容を UTF-8 で保存する。

```pasta
＃ 6 段目：時刻を知らせたい
＃ 正時になると、pasta は時報のシーンを呼ぶ。＊時報12 のように時刻（半角 2 桁）を付けた名前は、その時刻だけのシーンになる。
＃ その時刻のシーンが無いときは ＊時報その他 が呼ばれる。
＃ 時報のシーンでは、＄時１２ に「午後3時」のような時刻が入っている。変数の後ろには空白を置いて区切る。

＃ 正午だけの時報
＊時報12
　女の子：＠笑顔　お昼だよ！お腹すいた～。
　男の子：＠笑顔　もうお昼か、ご飯にしよう。

＃ ほかの時刻の時報（3 通りから 1 つが選ばれる）
＊時報その他
　女の子：＠通常　＄時１２　になったよ。
　男の子：＠通常　もうそんな時間か。

＊時報その他
　女の子：＠キラキラ　＄時１２　をお知らせします！
　男の子：＠困惑　え、誰に向けて？

＊時報その他
　男の子：＠通常　いま　＄時１２　だって。
　女の子：＠眠い　……もうちょっとだけ寝かせて。
```

- 1〜5 段目のファイルは書き換えない。新しいファイルを `dic/` に足すだけで、この段になる
- 台詞の頭の `＠笑顔`・`＠通常`・`＠キラキラ`・`＠困惑`・`＠眠い` は、3 段目で付けた表情名である

## 起動して確かめる

### 開発者用機能を有効にする

> 【不安】ただ、時報は正時にしか鳴りませんの。確かめるたびに次の正時を待つのでは、日が暮れてしまいますわ。

> 【アンソニー】では、お嬢様は時計の前で 1 時間お待ちになるのでございますね。

> 【したり顔】待ちませんわよ。SSP の開発者用機能を借りて、時刻のほうを進めてしまいますの。

1. SSP を終了し、もう一度起動する。
2. 自分のゴーストが出ていなければ、メニューから切り替える。
3. ゴーストを右クリックし、メニューの「設定」から「本体設定」を開く。
4. 本体設定の「一般」で、「開発者用機能を有効にする」を ON にする。

- 開発者用機能は、ゴーストを作る人のための SSP の機能である。有効にすると、次の節で使う開発用パレットを開けるようになる
- 初めて ON にするときにダイアログが出たら、先へ進める
- この設定は、[13 段目](13-nar.md) で `.nar` を作るときにも使う
- 手順の正本は、SSP ヘルプの [開発者向けヘルプ](https://ssp.shillest.net/ukadoc/ssphelp/dev.html) である

### 時刻を進めて時報を確かめる

> 【クローディア】開発用パレットの「現在時刻の仮想的変更」を使いますわ。SSP が見ている時刻だけを、好きな日時に置き換えられますのよ。

1. 自分のゴーストが出ている状態で `Ctrl+Shift+D` を押し、開発用パレットを開く。
2. 開発用パレットの「現在時刻の仮想的変更」を開く。
3. 入力ボックスの日時を、明日の日付の 12 時 0 分 0 秒に書き換えて、Apply ボタンを押す。
4. 時報を見たら、入力ボックスの日時を、同じ日付の 15 時 0 分 0 秒に書き換えて、Apply ボタンを押す。
5. 時報を見たら、Reset ボタンを押して、時刻を元に戻す。
6. SSP を終了し、もう一度起動する。

- 成功の目印（手順 3 の後）: 女の子の吹き出しに「お昼だよ！お腹すいた～。」と出て、続いて男の子の吹き出しに「もうお昼か、ご飯にしよう。」と出る
- 成功の目印（手順 4 の後）: 次の 3 つの掛け合いのどれか 1 つが出る
  - 女の子「午後3時になったよ。」、男の子「もうそんな時間か。」
  - 女の子「午後3時をお知らせします！」、男の子「え、誰に向けて？」
  - 男の子「いま　午後3時だって。」、女の子「……もうちょっとだけ寝かせて。」
- 「現在時刻の仮想的変更」は、SSP が認識している現在の日時を、設定した日時に仮想的に置き換える。OS の時計はそのままである
- 画面の Present Time が SSP の中の仮想の日時、System Time が OS の実際の日時である
- 日時は、いまより先へ進める。pasta は次の正時を覚えていて、時刻がその正時を過ぎると時報を出す。日付を明日にするのは、いまが何時でも先へ進むようにするためである
- 時報は、おしゃべりの途中には出ない。途中だったときは、おしゃべりが終わってから出る
- 時刻を先へ進めると、次のおしゃべりの時刻も過ぎたことになる。時報のすぐ後に、`＊会話` の掛け合いが続けて出ることがある
- 時刻を元に戻したあとは、SSP を終了し、もう一度起動する。pasta が覚えている次の時報とおしゃべりの時刻が、進めた先の日時のまま残っているためである
- 仮想の時刻を使わなくても、実際の時計が正時になれば、同じ時報が出る
- 開発用パレットの操作の正本は、SSP ヘルプの [開発用パレット](https://ssp.shillest.net/ukadoc/ssphelp/dev-palette.html) である
