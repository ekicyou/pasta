## 動作環境

> 【クローディア】ゴーストは、ひとりでは動けませんの。**ベースウェア**という土台のソフトの上に入れて、はじめて画面に立ちますわ。このガイドでは、Windows で動く SSP を土台にいたしますのよ。

| 項目 | 推奨 | 備考 |
| ---- | ---- | ---- |
| OS | **Windows** | 本マニュアルは Windows を対象とする |
| ベースウェア | **SSP**（推奨） | 最も広く使われている伺か互換ベースウェア |
| その他のベースウェア | 概ね動作 | 他の伺か互換ベースウェアでも概ね動作する |

- ベースウェア — ゴーストを画面に表示し、会話を進行させる土台のソフト。ゴースト単体では動かず、必ずベースウェアの上にインストールして使う
- SSP（Sakura Script Player） — ベースウェアの代表格である
- このガイドの手順は、SSP を前提に書く
- SSP は伺か関連サイトから入手する。インストールと初期設定は SSP の案内に従う

## 必要なもの

> 【したり顔】そろえる道具は、たった 2 つですわ。文字を書くテキストエディタと、ゴーストの頭脳になる `pasta.dll` ですのよ。

1. **テキストエディタ** — `.pasta` ファイルやプレーンテキストの設定ファイルを編集する。UTF-8 で保存できるエディタであれば何でもよい（Visual Studio Code、メモ帳など）
2. **`pasta.dll`** — pasta の SHIORI。ゴーストの「頭脳」にあたる。自分で書くものではなく、pasta が配布するファイルを置いて使う

- SHIORI（しおり） — ベースウェアからの問い合わせ（「起動した」「クリックされた」など）を受け取り、ゴーストの返事を組み立てるモジュール。pasta では `pasta.dll` がこの役割を担い、`.pasta` 辞書に書いた会話を解釈して返す

> 【アンソニー】お嬢様、その `pasta.dll` は、どちらで手に入るのでございましょう。

> 【クローディア】リリースページの `hello-pasta.nar` をお取りなさいまし。完成したゴーストがまるごと 1 体入っていて、`pasta.dll` もその中にありますわ。

- 入手先: [リリースページ](https://github.com/ekicyou/pasta/releases) の `hello-pasta.nar`
- `hello-pasta.nar` — 完成版のゴースト一式。`pasta.dll`・`THIRD_PARTY_LICENSES.txt`・シェル（ゴーストの見た目）を含む
- `hello-pasta.nar` から自分のゴーストへファイルを写す手順は、次の章の [hello-pasta から写す](setup.md#hello-pasta-から写す) で行う
- `pasta.dll` だけを入れ替えるときは、同じリリースページの `pasta.dll.zip` を使う

> 【クローディア】`scripts/` というフォルダを見かけても、慌てることはありませんわ。Lua を動かす仕組みは `pasta.dll` の中に入っていますの。`scripts/` は、あなたが自分で書いたスクリプトを置く場所ですのよ。

- Lua ランタイム（Lua のスクリプトを動かす仕組み）は、`pasta.dll` の中にある。別に入手して置くものは無い
- `scripts/` は、自分で書いた Lua スクリプトを置く場所である

## 文字コードは必ず UTF-8

> 【不安】ここが、最初のつまずきどころですの。辞書も設定ファイルも、必ず **UTF-8** で保存なさいまし。これだけは、いちばん大切な約束ですわ。

- 辞書ファイル（`.pasta`）と設定ファイルは、必ず UTF-8 で作成・保存する。最も重要な約束事である
- 辞書本文には日本語を多用する。文字コードを誤ると、起動時に文字化けしたり、辞書が読み込めずゴーストが動かなくなる
- 設定ファイルの `install.txt` と `descript.txt` は、先頭に `charset,UTF-8` を明記し、中身も UTF-8 で保存する
- 辞書ファイル（`.pasta`）の先頭に付いた BOM（バイト順マーク）は読み飛ばされる。エディタの保存形式は「UTF-8（BOM 付き）」と「UTF-8」のどちらでもよい
- 文字コード — 文字をコンピュータ上の数値に対応づける方式。同じ「あ」でも方式が違えば別の数値になり、食い違うと文字化けする。UTF-8 は世界中の文字を扱える現代の標準的な方式である
- 辞書ファイルの文字コードの規則は、[文字コード](../grammar/block-structure.md#文字コード) にある

### Shift_JIS の辞書から移行するときの注意

> 【クローディア】里々や YAYA で書きためた辞書をお持ちなら、もうひと手間かかりますわ。昔の辞書は、たいてい **Shift_JIS** という古い文字コードで書かれていますの。

> 【アンソニー】そのまま貼り付けてはいけない、ということでございますね。

> 【にっこり】ええ。UTF-8 に変換してから保存すれば、何の心配もいりませんわ。

- 旧来の伺か辞書（里々や YAYA など）は、Shift_JIS という古い文字コードで書かれていることが多い
- pasta の辞書は UTF-8 で書く前提である。Shift_JIS のまま `.pasta` に貼り付けると、文字化けしたり、辞書が読み込めなくなったりする
- 既存の Shift_JIS テキストを再利用するときは、エディタの「文字コードを指定して開く / 保存する」機能で UTF-8 に変換してから保存する
- 変換後は、機種依存文字や半角・全角の取り違えがないか、実際に表示して確認するとよい
