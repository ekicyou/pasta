# 13 段目：季節の行事でしゃべらせたい

> 【にっこり】暦をめくる楽しみを授けますわ。バレンタインにハロウィン、あの子たちにも季節の行事を祝わせてさしあげましょう。

> 【アンソニー】お嬢様、行事が来るたびに、辞書を書き換えるのでございますか。

> 【したり顔】いいえ、行事の日付を表に並べておくだけですの。あとは、その日の行事の名前で、話の行き先を決めますわ。

---

## 叶えたいこと

- 叶うこと: 今日が行事の日ならその行事の掛け合いを、行事の無い日ならふだんの掛け合いをする
- この章で足すファイル: `ghost/master/calendar.csv`・`ghost/master/dic/13-calendar.pasta`

## 辞書を書く

`ghost/master/calendar.csv` を作り、次の内容を書く。

```csv
# 行事の表。1 行に「日付,行事の名前」を書くと、その日は ＄行事 に行事の名前が入る（どの行にも当たらない日は「なし」）。
# 日付の書き方は 3 つ。
#   MMDD       毎年その日（例 0214）
#   MMDD-MMDD  毎年その期間（例 1224-1225。年をまたいでもよい）
#   YYYYMMDD   その年のその日だけ（例 20270101）
# 「#」で始まる行と空行は読み飛ばす。
0214,バレンタイン
0314,ホワイトデー
0401,エイプリルフール
1031,ハロウィン
1224-1225,クリスマス
1231,大晦日
```

`ghost/master/dic/13-calendar.pasta` を作り、次の内容を書く。

```pasta
＃ 13 段目：季節の行事でしゃべらせたい
＃ ghost/master/calendar.csv に行事の日付と名前を書いておくと、その日は ＄行事 に行事の名前が入る。どの行事にも当たらない日は「なし」が入る。
＃ ＞「行事_」＆＄行事 は、「行事_」と ＄行事 をつないだ名前のシーンを呼ぶ。バレンタインの日は ＊行事_バレンタイン、ふだんの日は ＊行事_なし が呼ばれる。
＃ 表に行事を足したら、同じ名前の ＊行事_… も足す。

＊会話
　＞「行事_」＆＄行事

＊行事_バレンタイン
　女の子：＠照れ　はい、チョコあげる。
　男の子：＠驚き　えっ、ぼくに？
　女の子：＠笑顔　お返しは三倍でいいよ。
　男の子：＠困惑　……先に言うんだ、それ。

＊行事_ホワイトデー
　男の子：＠照れ　はい、この前のお返し。
　女の子：＠キラキラ　やった！三倍？
　男の子：＠困惑　……気持ちは三倍だよ。

＊行事_エイプリルフール
　女の子：＠通常　わたし、今日からおやつをやめるね。
　男の子：＠通常　今日はエイプリルフールだもんね。
　女の子：＠怒り　もう、少しは信じてよ！

＊行事_ハロウィン
　女の子：＠キラキラ　トリックオアトリート！お菓子をくれないと、いたずらするよ！
　男の子：＠困惑　お菓子はないけど、かぼちゃのパスタならあるよ。
　女の子：＠笑顔　……それで手を打ちます。

＊行事_クリスマス
　女の子：＠キラキラ　メリークリスマス！サンタさん、来るかな。
　男の子：＠笑顔　いい子にしてたら来るよ。
　女の子：＠困惑　……今からでも間に合う？

＊行事_大晦日
　男の子：＠笑顔　年越しパスタ、できたよ。
　女の子：＠困惑　……そばじゃなくて？
　男の子：＠通常　細くて長ければ、だいたい同じだよ。

＃ どの行事にも当たらない日は、ふだんの台詞
＊行事_なし
　女の子：＠通常　今日って、なにかの日だっけ？
　男の子：＠通常　ふつうの日だよ。
　女の子：＠笑顔　じゃあ、ふつうの日のお祝いに、おやつにしよう。
```

| 行 | 意味 |
| -- | ---- |
| `0214,バレンタイン`（`calendar.csv`） | 毎年 2 月 14 日を、`バレンタイン` の日にする |
| `＄行事` | 今日の行事の名前が入る変数。表のどの行にも当たらない日は `なし` が入る |
| `　＞「行事_」＆＄行事` | `行事_` と `＄行事` の値をつないだ名前のシーンを呼ぶ。`「` `」` で囲むと文字列になり、`＆` は前と後ろをつなぐ |
| `＊行事_なし` | 行事の無い日に呼ばれるシーン。書かないと、行事の無い日に Call が失敗する |

- `calendar.csv` は、`ghost/master` の直下に、`pasta.toml` と並べて置く。
- pasta-recipe では、`calendar.csv` はツリーのいちばん上の行を、`13-calendar.pasta` は `dic` を右クリックして、「新しいファイル」を選ぶ。
- `calendar.csv` は、書いたら `Ctrl+S` で保存する。▶ が保存するのは `.pasta`・`.lua`・`pasta.toml` だけである。
- 1〜12 段目のファイルは書き換えない。
- 表に行事を足したら、同じ名前の `＊行事_…` も足す。

## 確かめる

1. `13-calendar.pasta` の `＊会話` の行のすぐ上に出ている「▶ シーンを実行」を押す。
2. pasta-recipe なら、同じ場所の「値を入れて実行…」を押し、「組を足す」で名前に `行事`、型に「文字列」、値に `バレンタイン` を入れて「鳴らす」を押す。

- 成功の目印（手順 1・行事の無い日）: 女の子「今日って、なにかの日だっけ？」、男の子「ふつうの日だよ。」、女の子「じゃあ、ふつうの日のお祝いに、おやつにしよう。」と出る
- 成功の目印（手順 2）: 女の子「はい、チョコあげる。」、男の子「えっ、ぼくに？」、女の子「お返しは三倍でいいよ。」、男の子「……先に言うんだ、それ。」と出る
- 今日が表の行事の日なら、手順 1 でその行事の掛け合いが出る。
- 手順 2 は、`＄行事` に値を入れてから鳴らしている。値をほかの行事の名前に替えると、その行事の掛け合いが出る。
- `＊行事_バレンタイン` などの行のすぐ上の ▶ を押すと、そのシーンだけを鳴らせる。

### 日付で切り替わることを確かめる

1. 本体設定の「一般」で、「開発者用機能を有効にする」を ON にする（[6 段目](06-hour.md) で済ませていれば、そのままでよい）。
2. 自分のゴーストを選んで `Ctrl+Shift+D` を押し、開発用パレットの「現在時刻の仮想的変更」を押す。
3. 開いたダイアログの日付の欄を全部選んでから `2026/02/14` と打ち、Apply を押す。
4. この章の `＊会話` の「▶ シーンを実行」を押すか、そのまま待って、おしゃべりでこの章の掛け合いが出るのを見る（会話の候補が多いので、待つと数分かかることがある）。
5. 確かめ終えたら、ダイアログの Reset を押す。

- 成功の目印: バレンタインの掛け合い（手順 2 と同じ 4 つの台詞）が出る
- `＄行事` は、SSP の仮想の日付で決まる。Reset を押すと、実際の日付に戻る。
- おしゃべりの間隔は、仮想の時刻を進めても早まらない。
- 開発用パレットの操作の正本は、SSP ヘルプの [開発用パレット](https://ssp.shillest.net/ukadoc/ssphelp/dev-palette.html) である。
